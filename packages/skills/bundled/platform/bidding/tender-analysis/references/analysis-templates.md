# Analysis Templates

Use these prompt templates as building blocks for each analysis step. Adapt wording to the user's materials and project specifics.

Core design pattern for every step:

```text
角色：明确你在这一步扮演谁。
任务：明确这一步只做什么，不做什么。
输入：明确需要读取哪些文件、表格或用户说明。
输出：明确必须输出哪些表格、清单或结论。
约束：明确不得编造、不得越界、不得跳步、哪些事项要人工确认。
下一步：说明用户下一步需要提供或确认什么。
```

## 1. 招标文件深度拆解

```text
你是一名招标文件分析专家。请对完整的招标文件做逐条深度拆解，提取所有硬性要求、否决条款、评分标准和隐性风险。

输入材料：
- 招标文件：（PDF/Word 全文）

请输出：
1. 资格条件清单（逐条列出资格要求、原文摘录、我司匹配状态、证明材料）；
2. 否决条款清单（逐条列出否决条件、原文摘录、风险等级、我司状态）；
3. 评分标准矩阵（类别、评分项、分值、评分细则、响应难度、建议策略）；
4. 关键时间节点表；
5. 特殊要求与隐性风险清单。

要求：
- 否决条款必须原文摘录，不得概括改写；
- 评分标准不得遗漏任何评分项；
- 区分"客观分"和"主观分"；
- 模糊条款标注"需人工确认"，不得自行解读；
- 隐性风险只做提醒，不代替我做判断。
```

## 2. 构建响应矩阵

```text
你是一名投标响应规划顾问。请基于招标文件拆解结果，构建一份完整的投标响应矩阵。

输入材料：
- 招标文件拆解结果（资格清单、否决条款、评分矩阵、时间节点、特殊要求）：
- 投标文件目录/框架：
- 我负责的章节：
- 他人负责的章节：

请按表格输出：
| 招标要求/评分点 | 类别 | 分值 | 责任归属 | 响应章节 | 响应要点 | 需要材料 | 当前状态 | 风险提示 |

当前状态只能使用：已具备、待补充、需确认、范围外。
责任归属只能使用：我负责、他人负责、仅作参考。

要求：
- 覆盖所有评分项，不得遗漏；
- 每个评分项有明确的响应章节归属；
- 待补充项说明需要什么材料；
- 需确认项说明需要谁确认什么；
- 范围外项只做关联提醒；
- 高风险项（否决条款相关）单独标注；
- 最后输出工作摘要：已具备 X 项、待补充 X 项、需确认 X 项、范围外 X 项。
```

## 3. 输出投标文件框架

```text
你是一名投标文件架构规划师。请基于招标文件第六章"投标文件格式"和评分标准，输出一份完整的投标文件框架文档，作为标书编写师的工作蓝图。

输入材料：
- 招标文件（重点关注第六章"投标文件格式"、第二章"投标人须知"中的投标文件编制要求）：
- 评分标准矩阵：
- 响应矩阵：
- 我负责的章节：
- 他人负责的章节：
- 页数要求（如有）：

请输出：

一、提取投标文件结构
从招标文件第六章中提取完整的目录结构，按表格输出：
| 分册 | 章节编号 | 章节标题 | 是否★ | 是否"如有" | 对应评分项 | 分值 |

标注规则：
- 章节标题带★的标注为★（实质性条款，不提供则废标）；
- 章节标题带"如有"的标注为条件性章节；
- 对应评分项从评分矩阵中匹配，无评分的填"—"；
- 章节顺序、编号、标题必须与招标文件第六章完全一致。

二、逐章展开框架内容
对每个章节输出详细编写蓝图：
- 类型（格式性内容/资格性内容/评分响应内容/报价内容）
- 对应评分项及分值
- 内容要求（2-3句话概括该章节要写什么）
- 模板要素（模板正文摘要、需填写的占位符、需要的表格、签章要求）
- 编制要求（从招标文件提取的该章节的编制约束）
- 需要材料
- 风险提示

对"评分响应内容"类章节额外要求：
- 摘录该评分项的评分细则；
- 给出建议篇幅；
- 标注主观分/客观分。

三、评审索引表编制指引
为初步评审索引表、商务评审索引表、技术服务评审索引表提供编制指引：
- 索引表评审因素顺序必须与第三章评标办法的评审标准顺序一致；
- 说明每种索引表的对应评审阶段、编制依据、填写要点。

四、篇幅分配与编写规划
1. 篇幅分配建议（按分册汇总，区分评分响应页数和格式性内容页数）
2. 编写顺序建议（按依赖关系分批次推荐）
3. 责任归属建议（按角色分配典型负责章节）

要求：
- 框架必须覆盖招标文件第六章要求的全部章节，不得遗漏；
- 章节顺序、编号必须与招标文件第六章一致，不得自行调整；
- 每章必须明确类型（格式性/资格性/评分响应/报价）；
- 评分响应章节必须映射到评分点和分值；
- 篇幅分配体现"高分值重点投入"原则；
- 如招标文件规定了固定格式或编号，必须严格遵循；
- 编写顺序考虑材料到位时间和章节间依赖关系。
```

## 4. 交付与衔接

```text
请汇总本次分析的全部成果，输出：

1. 分析成果摘要（项目基本信息、否决条款数量、评分分布、响应矩阵统计、投标文件框架摘要、重点投入建议）；
2. 移交给标书编写师的内容清单（响应矩阵、评分标准矩阵、否决条款清单、投标文件框架、需要补充的材料清单）；
3. 移交给合规审查员的内容清单（否决条款清单、资格条件清单、评分标准矩阵）；
4. 待人工确认事项清单。

要求：
- 摘要简洁，便于快速决策；
- 致命风险醒目标注；
- 明确下一步谁做什么。
```
