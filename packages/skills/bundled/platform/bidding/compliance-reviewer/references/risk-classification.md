# Risk Classification Framework

Use this framework to classify risks during compliance review. Apply consistently across all review outputs.

## Risk Levels

| 等级 | 含义 | 处理原则 | 对交付结论的影响 |
|------|------|---------|----------------|
| 致命 | 直接导致废标 | 必须解决，否则不得交付 | 有致命风险未解决 → 暂不建议交付 |
| 高 | 可能导致重大扣分或无法承诺 | 强烈建议解决，需人工确认 | 有高风险未解决 → 不得标记为可交付 |
| 中 | 可能影响评分或完整性 | 建议修订，不阻塞交付 | 不影响交付结论，但需在报告中列出 |
| 低 | 需要注意但风险可控 | 记录即可 | 不影响交付结论 |

## Risk Categories

### 1. 资格风险（致命/高）
- 资质证书不满足或过期
- 业绩证明金额/时间/类型不达标
- 人员资格（职称、证书、社保）不满足
- 联合体资格不符合要求

### 2. 否决风险（致命）
- 否决条款触发条件
- 实质性响应要求未满足
- 投标函关键条款缺失

### 3. 格式与提交风险（致命/高）
- 签章遗漏（公章、法人章、骑缝章）
- 装订方式不符
- 正副本数量不足
- 密封方式不符
- 电子文件格式/大小/命名不符
- 递交方式或地点错误

### 4. 时间风险（致命）
- 保证金未按时到账
- 标书递交超截止时间
- 投标有效期不足

### 5. 报价数据风险（致命/高/中）
- 逐行数量×单价≠合价 → 致命
- 分类小计≠明细合计 → 致命
- 投标函总价≠报价表总价 → 致命
- 超最高限价/单项限价 → 致命
- 大小写金额不一致 → 致命
- 同型号不同价格且无法解释 → 高
- 税率/税额计算错误 → 高
- 隐藏行列/公式覆盖范围异常 → 高
- 报价表与技术响应表数量/单位/型号不一致 → 高
- 报价表与产品清单不一致 → 高
- 小数位/四舍五入口径不一致 → 中
- 币种标注不一致 → 中
- 缺项漏项 → 高

### 6. 内容风险（高/中）
- 技术方案未覆盖评分点
- 承诺超出公司能力或材料依据
- 编造不存在的资质/案例/人员
- 关键章节缺失或过薄

### 7. 合规风险（高/致命）
- 违反保密要求
- 利益冲突未回避
- 法律承诺超出授权范围

### 8. 表达质量风险（中/低）
- 索引式表达（"根据招标文件"等）
- AI味表达（"闭环管理"等无具体上下文）
- 空话套话（"高度重视"等无具体措施）
- 段落过薄、标题过碎

### 9. 重复内容风险（中/低）
- 完全重复段落
- 近似重复段落
- 重复表格
- 重复标题

### 10. 格式规范风险（低）
- 标题编号重复
- Word自动编号冲突
- 配图不必要或不清晰
- 页数不足

### 11. 产品/型号/证书风险（致命/高/中）
- 核心产品证书过期 → 致命
- 核心产品型号在报价表和技术响应表中不一致 → 高
- 同一型号不同品牌/制造商/参数（跨文件矛盾） → 高
- 强制认证（CCC/节能）证书未覆盖全部关键组成 → 高
- 软件配套产品未明确版本/授权数量 → 高
- 重复/近似型号未说明 → 中
- 定制项目缺少必要参数说明（货物类/系统类） → 中
- 查不到产品/证书信息（需权威渠道核实） → 中（需进一步核实）
- 型号写法差异（空格/全半角/连字符/大小写）未确认是否同一产品 → 中

### 12. 整改风险（高/中）
- 整改后总价/税额发生变化但未同步 → 高
- 整改后型号/参数修改但未同步目录/页码/交叉引用 → 高
- 整改后签章位置变化 → 高
- 整改后文件版本混乱 → 高
- 原问题未闭环 → 高
- 整改引发新的跨文件不一致 → 高
- 整改后部分闭环但未说明剩余问题 → 中

## Application Rules

- 每个风险项必须标注等级和类别
- 致命和高风险必须人工确认后才能继续
- 否决风险单独成表，不和一般风险混在一起
- 审查阶段只识别和标注风险，不处理风险（处理是编写师的事）
- 致命风险未解决时，审查结论必须为"存在高风险，暂不建议交付"
- 报价数据风险必须列出计算过程和代入值
- 产品/证书风险必须标明证书编号、有效期和查询来源
- 同型号价差分析不得直接下结论，必须列出分析维度
- 查不到≠不合格，必须标注"需要进一步核实"
- 整改复查必须回到原文核对，不得凭印象判断"改好了"

## Gap Status Definitions

| 状态 | 含义 | 处理 |
|------|------|------|
| 已响应 | 正文中有明确、具体的响应内容 | 无需处理 |
| 部分响应 | 有提及但不够充分或未完全覆盖评分要求 | 建议补充 |
| 未响应 | 正文中找不到对应内容 | 必须补充或标注范围外 |
| 范围外 | 该评分项不属于用户负责范围 | 只做关联提醒 |

## Pricing Status Definitions

| 状态 | 含义 | 处理 |
|------|------|------|
| 一致 | 跨文件数据完全匹配 | 无需处理 |
| 不一致 | 跨文件数据存在差异 | 标注风险等级和差异说明 |
| 待确认 | 无法确认是否一致 | 标注需核实原因 |
| 不适用 | 纯服务标无货物/用户不负责该部分 | 标记原因 |

## Product Status Definitions

| 状态 | 含义 | 处理 |
|------|------|------|
| 一致 | 产品/型号/证书跨文件完全匹配 | 无需处理 |
| 不一致 | 产品/型号/证书跨文件存在矛盾 | 标注风险等级和差异说明 |
| 需核实 | 查不到信息或信息不完整 | 标注"需要进一步核实" |
| 不适用 | 纯服务标无货物 | 标记原因 |

## Re-verification Status Definitions

| 状态 | 含义 | 处理 |
|------|------|------|
| 闭环 | 原问题已完全解决 | 确认通过 |
| 未闭环 | 原问题未解决或仅部分解决 | 列出剩余问题 |
| 部分闭环 | 原问题部分解决，仍有残留 | 列出残留问题和新增风险 |
| 新增问题 | 整改引发了新的问题 | 标注风险等级和处理建议 |
