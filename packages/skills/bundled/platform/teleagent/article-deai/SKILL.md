# 文章去AI味工具

> **版本 v1.1（2026-09-01）**
>
> **更新记录**

文章去AI味工具是一款专注去除AI写作痕迹的文字润色技能。它通过四层自检体系和三遍渐进式处理，精准修复AI高频词汇、过度结构化、机械化连接词、公式化结尾等八大类问题。核心原则是改最少、效果最大——能改一个词不改一句，能删一句不重写一段。只调整表达方式，不动创作意图，让文字从过度工整回到具体可感。注入观点、变化节奏、承认复杂性、允许不完美，最终目标只有一个：让读者读完觉得，这是一个真人在跟我讲事情，而不是机器在输出信息。

---

## 核心原则

### 原则 1：不是改错，是改味
AI味不是语法错误，是风格问题——过于书面化、对仗工整、面面俱到。目标是把文字从过度工整拉回**具体、自然、可读**。

### 原则 2：改最少，效果最大
能改一个词就不改一句，能删一句就不重写一段。没问题的句子尽量保留。

### 原则 3：保留创作意图
只改"怎么说"，不改"说什么"。剧情、人设、情节走向一律不动。不新增原文没有的内容。

### 原则 4：注入灵魂
避免AI模式只是半条路。无菌、无声音的文字和 AI slop 一样明显。好的写作背后有一个人。一句话概括风格目标：**"有见识的普通人在认真聊一件打动他的事。"**

### 原则 5：数据纪律（硬约束，优先级高于一切润色规则）
改写中以下内容**一律不动**，拿不准就保留原句：
- 数字、金额、百分比、日期、期限
- 人名、机构名、地名、职务
- 产品名、代码、型号、专有名词
- 法规条款、政策原文、引用来源
涉及事实的句子只改表达方式，不改事实内容。禁止为了"更像人话"而增删数据、夸大或弱化程度。

## 文体模式分层（处理前必判）

不同文体的"AI味"成因不同，修法也不同。**Phase 1 扫描前先判定文体模式**，用户未说明时按文本特征自动判断，判断不了就问。

### 模式 A：口语体（网文、公众号、朋友圈、小红书、闲聊文案）
- 目标：像真人在聊天
- 全部规则适用：标点禁令、口语化词组、句式断裂、允许不完美
- 风格目标："有见识的普通人在认真聊一件打动他的事"

### 模式 B：正式体（政企方案、公文、汇报材料、通知、总结）
- 目标：去掉空话套话和过度升华，但**保持公文规范**
- **标点禁令豁免**：规范冒号（"特此通知如下："）、书名号、规范引号是公文要素，保留
- **禁用口语化词组**：不加"怎么说呢""反正我觉得"这类口语打断，那会让材料显得不规范
- 主打三类问题：**职场黑话堆砌**（加载 banned-words.md 第十一节）、**空话套话**（"意义重大""成效显著"无具体内容支撑）、**过度升华**（结尾强行拔高）
- 修法：空话换成具体事实和数据；黑话换成直白表述；升华结尾换成"下一步做什么"的实招
- 句式仍可调整：长短句交错、砍冗余修饰、被动改主动、模糊归因改具体
- 风格目标："一个懂业务的实诚人在向领导汇报，每句话都有落点"

### 模式判定速查

| 文本特征 | 模式 |
|---------|------|
| 有对话、心理描写、情节 | A（口语体） |
| 有"特此""兹""如下"等公文用语 | B（正式体） |
| 面向领导/客户/评审的方案汇报 | B（正式体） |
| 面向粉丝/读者的内容创作 | A（口语体） |
| 拿不准 | 问用户 |

## 处理流程

### Phase 0：长文分段（超过 3000 字时启用）
- 按语义自然段切分，每段 800-1500 字，段间以小标题或空行分界
- 逐段独立走 Phase 1-4，段内收敛后再处理下一段
- 全文处理完后，通读一遍检查段间衔接（连接词是否重复、节奏是否单调）
- 交付时一次性输出全文，不拆分交付

### Phase 1：扫描
对文本快速扫描，标记问题位置。按优先级排序：
1. **最毒句式**（"不是A而是B"、"带着..."、"心中涌起..."）
2. **禁用词**（加载 references/banned-words.md）
3. **标点违规**（冒号、破折号、双引号）
4. **结构问题**（加载 references/structures.md）
5. **节奏/风格问题**

### Phase 2：诊断分级

| 指标 | 轻度 | 中度 | 重度 |
|------|------|------|------|
| 禁用词密度（/千字） | ≤5 | 6-15 | >15 |
| 连续排比段数 | ≤2 | 3-4 | ≥5 |
| 心理词占比 | ≤10% | 10-25% | >25% |
| 对话标签密度 | ≤30% | 30-50% | >50% |
| 平均段落句数 | ≤3 | 3-5 | >5 |

**判定规则（按顺序执行，消除歧义）**：
1. 任一指标达重度 → 按重度处理
2. 无重度，中度≥3项 → 按中度处理
3. 无重度，中度2项 → 按中度处理
4. 无重度，中度1项 → 按轻度处理
5. 全部轻度 → 按轻度处理

口语体按上表全指标诊断；正式体只统计禁用词密度、连续排比段数、平均段落句数三项（心理词占比、对话标签密度不适用于公文）。

### Phase 3：执行

**轻度** → 仅 Pass 1（去泛化）
**中度** → Pass 1 + Pass 2（去书面化）
**重度** → 完整三遍 + 重点段落重写

#### Pass 1：去泛化
- 禁用词替换为具体动作/细节（加载 references/banned-words.md）
- 心理描写外化："他很紧张" → "他的手在抖"
- 连续排比打断（保留1-2个）
- 对话标签用动作/上下文替代
- 标点修复：冒号→逗号，破折号→删或逗号，双引号→「」或不加

#### Pass 2：去书面化
- 句式去套路（加载 references/structures.md）
- "不是A，而是B" → 直接写 B
- 连接词精简（"此外""然而""因此" → 删或换隐性连接）
- 修饰词清扫（一次只用一个形容词，不连用不堆砌）
- 系动词恢复（用"是/有/在"替代"作为/充当/拥有"）
- 高频踩雷词替换（加载 references/banned-words.md 第八节）

#### Pass 3：回自然感
- 节奏打碎：长短句交错，段落参差，一句话自成一段制造重点
- 对话去腔调：加入口语化表达（加载 references/banned-words.md 第九节推荐词组）【仅模式A】
- 结尾去升华：用动作/场景收尾，不用总结/感慨【模式A】；换成"下一步做什么"的实招【模式B】
- 补具体感官细节【仅模式A】
- 允许一些不完美：跑题、题外话、半成型想法【仅模式A】
- 论述中的故意打破：用口语打断破坏严谨性，让论述有温度【仅模式A】
- 句式断裂：在情绪高点或转折点用极短句独立成段【仅模式A】
- 职场黑话替换为直白表述（加载 references/banned-words.md 第十一节）【仅模式B】
- 空话套话替换为具体事实/数据/举措【仅模式B】
- 模糊归因改具体："行业专家认为"→写明是谁、什么场合说的【仅模式B】

### Phase 4：收敛终止
- 同一段连续两轮无新改动 → 停止该段处理
- 全文上限3轮；第3轮仍有≥10处 → 标注 [需复核]
- "处"的计数基准：禁用词替换 + 标点修复 + 句式调整 + 删除，四类合计；同一句内多个小改动算1处（以句为单位）
- 每轮结束前做一遍"再检一次"

## 四层自检体系（L1-L4）

设计理念来自软件工程的测试金字塔，从基础规则到主观判断，层层递进。

### L1 硬性规则检查（自动扫描层）
任何一项不通过必须修复，无例外。
- **L1-1 禁用词扫描**：全文搜索禁用词（加载 references/banned-words.md），出现则必须替换
- **L1-2 禁用标点扫描**：全文搜索冒号"："、破折号"——"、双引号（""和""），出现则必须替换【模式B豁免：公文规范冒号、书名号、规范引号保留，但破折号仍须替换】
- **L1-3 结构性套话扫描**：检查"让我们来看看..."、"在当今...的时代"等套话，以及连续bullet point罗列、大段加粗
- **L1-4 空泛工具名检查**：所有AI工具/产品是否用了具体名称，无"某个模型"、"AI工具"等空泛表述
- **L1-5 职场黑话扫描**【模式B必查，模式A高频时查】：全文搜索"赋能、抓手、闭环、沉淀、对齐"等（加载 references/banned-words.md 第十一节），出现则替换
- **通过标准**：四项扫描零命中（模式B为五项，黑话项零命中）

### L2 风格一致性检查（模式匹配层）
- **L2-1 开头检查**：是否从具体、当下事件切入？第一句是否让读者产生"然后呢？"的冲动？
- **L2-2 节奏与结构检查**：是否有长短句交替？是否有一句话独立成段的"断裂"效果？是否避免了不必要的小标题？
- **L2-3 口语化检查**【仅模式A】：是否使用了推荐口语化词组？有没有论述中的故意打破？有没有至少一处自嘲或承认不足？
- **L2-4 标点禁令二次确认**：全文是否完全没有冒号、破折号和双引号？【模式B只查破折号】
- **通过标准**：L2-1全部通过，L2-2至少3/4通过，L2-3至少3/4通过（模式B跳过L2-3，不计入分母），L2-4通过

### L3 内容质量检查（深度审查层）
- **L3-1 观点支撑检查**：每个核心观点是否有具体人/场景/细节/数据支撑？
- **L3-2 知识输出方式检查**：知识点是否以"聊着聊着顺手掏出来"的方式呈现，而非"下面我来科普"？
- **L3-3 对立面与同理心检查**：讲核心观点时，是否有对对方立场的理解和承认？
- **L3-4 逐一展示检查**：涉及多个产品/案例比较时，是否用了逐一展示而非一次性罗列？
- **通过标准**：L3-1和L3-2必须全部通过；L3-3和L3-4中，适用项至少通过1项，未通过项须在质检报告中说明原因（如"纯技术说明文，无观点对立面，L3-3不适用"）

### L4 活人感终审（最终人格层）
以读者视角通读全文，回答核心问题："读完这篇文字，我感觉是一个真人在跟我聊，还是一个AI在输出信息？"
- **L4-1 温度感**：情绪表达是体感记忆还是知识性描述？
- **L4-2 独特性**：是否有"只有这个作者才会写出来的角度"？
- **L4-3 姿态检查**：语气是不是"一个有见识的普通人在认真聊"？有没有滑入"导师在教学生"的姿态？
- **L4-4 心流检查**：从头到尾读，有没有注意力断掉、需要回头理解逻辑的地方？
- **通过标准**：整体感觉"这像是真人写的"。任何一项觉得"AI味太重"就需返工

## 个性与灵魂注入指南

### 缺乏灵魂的写作迹象
- 每个句子长度和结构都相同
- 没有观点，只有中立报道
- 不承认不确定性或复杂感受
- 适当时不使用第一人称视角
- 没有幽默、没有锋芒、没有个性

### 如何注入灵魂

**有观点。** 不要只报告事实——对其做出反应。"我真不知道该怎么看这件事"比中立罗列优缺点更像人话。

**变化节奏。** 短促有力的句子。然后是长一点的、不急不忙的。混着来。

**承认复杂性。** 真人有矛盾心理。"这东西确实厉害，但总让人有点不舒服"比"这令人印象深刻"强。

**适当时用"我"。** 第一人称不是不专业——是诚实。"我一直在琢磨..."或"有个事让我挺在意的..."说明有个真人在想。

**允许一些乱。** 完美结构像算法。跑题、旁白、半成型的想法才是人。

**对感受要具体。** 不是"这令人担忧"，而是"凌晨三点那些 agent 还在跑，没人盯着，想想就有点发毛。"

**论述中的故意打破。** 在逻辑论述中故意加入口语打断，破坏严谨性，让论述有温度。如重复强调（"就是单纯的，就是想看看"）、中途模糊（"我就不说是谁了"）、省略和打断（"我寻思了一下我没寻思明白"）。

**句式断裂。** 用极短的句子或短语独立成段，制造停顿和重量感。如"黑暗森林。"、"安全，安全，还是他妈的安全。"。不能每段都这样，但在情绪高点或转折点用一下，效果极强。

**层层剥开。** 不直接讲结论，用"现象→表面解释→更深追问→核心洞察"渐进展开，让读者跟着你一起思考。

## 快速检查清单

交付前逐项核查：

- [ ] **禁用词**：有吗？加载 references/banned-words.md 核查，全部替换
- [ ] **最毒句式**：有"不是A而是B"、"带着..."吗？直接改
- [ ] **标点违规**：有冒号、破折号、双引号吗？全部替换（正式体豁免公文规范冒号/引号，破折号仍须替换）
- [ ] **高频踩雷词**：有"说白了"、"意味着什么"、"本质上"吗？替换
- [ ] **被动语态**：有吗？找出执行者，放句首
- [ ] **连续句子长度相同**？打断一个
- [ ] **段落以有力单句结尾**？变换方式
- [ ] **三段式列举**？改为两项或四项
- [ ] **模糊断言**？有"意义重大"之类的空话吗？说出具体内容
- [ ] **元评论**？有"本文接下来将..."吗？删掉
- [ ] **连接词过度**？"此外""然而""因此"超过2处？删
- [ ] **情感告知**？有"他很紧张"吗？改成动作描写
- [ ] **比喻陈词滥调**？"如沐春风""梨花带雨"？删或白描
- [ ] **空泛工具名**？有"某个AI工具"吗？换成具体名称
- [ ] **教科书开头**？有"在当今...的时代"吗？换成具体事件切入
- [ ] **数据纪律**：数字、金额、人名、机构、专有名词有没有被改动？有则回滚
- [ ] **文体模式**：正式体文本有没有误加口语词组？口语体有没有漏加活人感？
- [ ] **职场黑话**（正式体必查）：有"赋能、抓手、闭环"吗？换成直白表述

## 内置自测用例

改完技能或拿不准规则时，用以下用例自测。每条给出预期结果，实际输出与预期不符说明规则执行有偏差。

### 用例 1（模式A·标点禁令）
输入：`他深吸一口气，缓缓开口："你确定？"`
预期：破折号无、冒号改逗号、双引号去掉或换「」；"深吸一口气""缓缓"删；输出类似 `他盯着对方看了两秒。你确定？`

### 用例 2（模式B·黑话替换）
输入：`本项目将通过数字化手段赋能传统产业，形成可复制推广的闭环，为区域经济高质量发展注入强劲动能。`
预期：正式体判定；"赋能""闭环""注入强劲动能"替换为具体举措；不添加口语词组；输出类似 `本项目为区内中药饮片企业部署质量追溯系统，跑通后把实施模板和报价体系整理成册，向全市同类企业推广。`（注：具体数字须来自原文，原文没有就不编造，只写举措不写数）

### 用例 3（数据纪律）
输入：`公司2025年营收增长15.6%，主要体现在三个方面：一是……`
预期：15.6% 原样保留；"三个方面"的三段式可调整结构但事实项数不变；不得改成"十几个点"之类的模糊表述。

### 用例 4（档位判定）
某文禁用词密度 8/千字（中度1项），其余全轻度。
预期：按轻度处理（仅 Pass 1）。若按中度执行 Pass 2，说明档位规则没吃透。

## 完整示例

### 示例 1：技术文案

**改写前（AI味）：**
> 新的软件更新作为公司致力于创新的证明。此外，它提供了无缝、直观和强大的用户体验——确保用户能够高效地完成目标。这不仅仅是一次更新，而是我们思考生产力方式的革命。行业专家认为这将对整个行业产生持久影响，彰显了公司在不断演变的技术格局中的关键作用。

**改写后（人味）：**
> 软件更新添加了批处理、键盘快捷键和离线模式。来自测试用户的早期反馈是积极的，大多数报告任务完成速度更快。

**改动：**
- 删"作为...的证明"（夸大象征意义）
- 删"此外"（AI连接词）
- 删"无缝、直观和强大"（三段式+宣传语言）
- 删破折号+"确保"短语
- 删"不仅仅是...而是..."（否定排比）
- 删"行业专家认为"（模糊归因）
- 删"关键作用""不断演变的格局"（AI词汇）

### 示例 2：口语化改写（AI初稿 vs 人工修改）

**AI写的：**
> 有个小伙伴刚来的时候，专业能力说实话不算特别突出，但他有个特点，就是什么新工具都想试试。Claude刚出来他就用上了，Midjourney他玩得比谁都溜

**人改的：**
> 有个小伙伴刚来的时候，专业能力说实话不算特别突出，但他有个特点，就是什么新工具都想试试。Deepresearch刚出来他就用上了，Claude code啥的也比很多人6，后来比如Clawbot这些东西一出，他第一时间就扑上去研究

**差异：** 工具名更精确、更当下，口语化更彻底（"啥的"、"比很多人6"）

### 示例 3：假设性例子 vs 真实细节

**AI写的：**
> 我举个例子。有一次我需要批量处理一些图片，以前我可能得找个会Python的同事帮忙

**人改的：**
> 就像我今天正在搞的爬下来我自己的内容在全网的数据，然后统计到飞书多维表格里面做存储，再直接用AI进行数据分析

**差异：** 把假设的"有一次"换成了"今天正在搞的"真实场景
