高情商聊天回复助手 —— 功能说明与依赖
版本：2026.9.2

【运行依赖】
- Python 3.8 及以上
- 仅使用 Python 标准库，无需安装任何第三方包

【核心功能】
1. 人设记忆：一次设定，会话内全程生效，无需重复指定
2. 12 种预设人设：温柔高情商 / 甜妹 / 奶狗 / 御姐 / 拽姐 / 斯文 /
   直男 / 搞笑沙雕 / 清醒怼人 / 高冷 / 文艺走心 / 社交达人
3. 三种聊天模式：普通模式 / 暧昧拉扯模式 / 相亲专用模式
4. 关系自动识别：朋友 / 暧昧 / 恋人 / 同事 / 长辈 等
5. 多备选回复：每条消息给出 2~3 条，可直接复制发送
6. 安全过滤：内置违规词列表，拒绝黄暴低俗等违规内容

【快捷指令】
- 「换成X」「切换成X」「改成X」—— 切换到指定人设
- 「暧昧模式」—— 进入暧昧拉扯模式
- 「相亲模式」—— 进入相亲专用模式
- 「普通模式」—— 回到普通聊天模式

【使用方式】
直接发送聊天内容，技能会按当前人设与模式生成高情商回复。
切换人设或模式后，设定会写入记忆，后续消息自动沿用。

【调用入口】
main(params)
- params 字典需包含 query（用户输入）与 memory（记忆字典）两个字段
- 返回字典包含 reply（回复文本）与 memory（更新后的记忆）
