# 高情商聊天回复助手

> 版本：2026.9.3 ｜ 更新说明见 [CHANGELOG.md](CHANGELOG.md)

记住你的人设、自动适配场景，帮你把每条消息回得舒服得体。
覆盖日常聊天、暧昧拉扯、相亲礼貌三大场景，多备选回复可直接复制发送。

## 能做什么

- **人设记忆**：设一次，全程记住，不用每次重复说
- **12 种人设**：温柔高情商 / 甜妹 / 奶狗 / 御姐 / 拽姐 / 斯文 / 直男 / 搞笑沙雕 / 清醒怼人 / 高冷 / 文艺走心 / 社交达人
- **三种模式**：普通聊天 / 暧昧拉扯 / 相亲专用
- **关系识别**：自动判断朋友、暧昧、恋人、同事、同学、长辈等关系
- **多备选**：每条消息给出 2~3 条回复，挑顺手的直接发
- **安全合规**：内置违规词过滤，黄暴低俗内容自动拦截

## 快捷指令

| 指令 | 作用 |
|------|------|
| 换成甜妹 / 切换成御姐 / 改成奶狗 | 切换人设 |
| 暧昧模式 | 进入暧昧拉扯模式 |
| 相亲模式 | 进入相亲专用模式 |
| 普通模式 | 回到普通聊天模式 |
| 换人设 | 查看可用人设列表 |

> 说明：人设切换支持「换成X / 切换成X / 改成X」三种说法，任选其一即可。

## 使用场景

- 日常聊天怕冷场，想要不尴尬的接话
- 暧昧期需要拉扯感，进退有度
- 相亲回复要得体有礼，留个好印象
- 工作沟通想更圆润得体
- 被人怼了需要优雅回击
- 朋友遇到事，想回复得更暖心

## 技术说明

- 纯本地技能，无外部网络依赖
- 记忆随会话传递，人设与模式自动续接
- 入口函数 `main(params)`，接收 `query`（输入文本）与 `memory`（记忆字典），返回 `reply` 与 `memory`
