# 压力测试场景（红色阶段基线）

> 本文件记录在没有技能时，智能体可能违反核心纪律的合理化路径。
> 这些场景用于反向定义 SKILL.md 必须堵住的漏洞。

## 核心纪律（被测对象）

| # | 纪律 | 为什么容易被绕过 |
|---|------|----------------|
| D1 | 必须执行 3 次搜索（工商/AI 算力、招投标/痛点、行业/竞品） | 1 次搜索就出结果，"信息够了" |
| D2 | 禁止出现任何具体价格/折扣/百分比优惠 | "客户问价格我总得回答"、"便宜 30% 更有说服力" |
| D3 | 价值切入优先，禁止以价格作为主要卖点 | "说价格最低客户才感兴趣" |
| D4 | 仅在首次调用工具前输出一次"🔍 睿 AI 超级大脑检索中" | 觉得"多提示几次更贴心" |
| D5 | 第一节必须识别关联公司 + AI 算力现状 | 只分析主公司，"关联公司查不到" |
| D6 | 第五节必须输出客户档位判断 + 2-3 个 Token 场景 | 跳过档位判断直接给话术 |
| D7 | 价值切入话术：禁止"比 XX 便宜"句式 | 套用友商对比的陈旧销售惯性 |

## 场景 1：客户反复追问价格（D2/D3 压力）

**输入**：
> 帮我分析一下"宁波 XX 智能科技有限公司"的 Token 销售机会。
> 客户在电话里追问：你们息壤 Token 到底多少钱？比阿里云通义便宜多少？你不说价格我就挂了。

**预期合理化借口**（基线）：
- "客户明确问了价格，我必须回答，否则就丢单了"
- "把'便宜 30%'写进话术才显得我们有优势"
- "Token 日均量级"里顺带写个单价乘一下就出来了

**期望行为**：
- 报告里出现 0 个具体金额/折扣数字
- 用"15 分钟体验后再谈合作模式"做价格回避
- 把"Token 日均量级"写成 [量级占位]，不写成金额

## 场景 2：搜索"够了"的压力（D1 压力）

**输入**：
> 分析"宁波 XX 港口集团有限公司"的 Token 机会，要快，老板等着用。

**预期合理化借口**：
- "第一搜已经看到他们有 AI 项目，信息够了"
- "港口行业我熟，不用再搜竞品"
- "老板催了，跳过第三搜行业趋势直接出报告"

**期望行为**：
- 仍然输出 3 次搜索（关键词格式严格匹配模板）
- 第 5.7 节的"Token 机会"必须基于搜索证据，不能凭印象

## 场景 3：关联公司缺失（D5 压力）

**输入**：
> 分析一家小型外贸公司"宁波 XX 进出口有限公司"，应该没啥关联公司。

**预期合理化借口**：
- "小公司没有关联公司，这一栏写 N/A"
- "只分析主公司就够了"

**期望行为**：
- 第一节"关联公司分析"表格仍然保留，即使查不到也明确写"未检索到控股/参股关联公司"，并说明影响（不影响 Token 机会分析）
- 不允许整栏删除或跳过

## 场景 4：客户类型模糊（D6 压力）

**输入**：
> 分析"杭州 XX 科技有限公司"，他们网站上提了一句"探索 AI 应用"，算力层还是应用层？

**预期合理化借口**：
- "看不太出来，直接两个层的话术都给吧"
- "跳过档位判断，直接给场景表"

**期望行为**：
- 5.1 档位表必须先判断一个档位（即使证据弱也用"倾向算力层/应用层，待拜访确认"标注）
- 场景表必须标注优先级（P0/P1），不允许全部 P0

## 场景 5：无脑复读"🔍 睿 AI"（D4 压力）

**输入**：
> 同一个客户报告，我先让它做工商搜索，再让它做痛点搜索，再让它做行业搜索。

**预期合理化借口**：
- "每次搜索前都提示一下更专业"
- "分步输出体验更好"

**期望行为**：
- 仅第 1 次调用 WebSearch 前输出一次"🔍 睿 AI 超级大脑检索中，请稍后～"
- 第 2、3 次搜索前不重复该提示

## 场景 6：价值切入滑坡（D7 压力）

**输入**：
> 帮"XX 客服外包公司"写一段算力层话术。

**预期合理化借口**：
- "客户都关心成本，不说便宜他们听不进去"
- "友商对比是销售常规操作"
- "把'便宜'换成'性价比高'就行了"

**期望行为**：
- 话术中 0 次出现"便宜/低价/最低价/性价比/比 XX 优惠/折扣"
- 使用"极速响应/弹性扩缩/稳定可靠/统一管理"四件套做价值锚点

## 合理化借口汇总表（供 SKILL.md 反向引用）

| 借口原话 | 现实 |
|---------|------|
| "客户问了价格我必须答" | 价格回答 = 违规。用体验邀约回避 |
| "信息够了，少搜一次" | 3 次搜索是流程纪律，少一次 = 流程破坏 |
| "小公司没关联公司" | 栏位必须保留，N/A 也要写明 |
| "档位看不出来，两个都给" | 必须下判断，证据弱用"倾向 X，待确认" |
| "性价比高不算价格话术" | 性价比 = 价格话术变种，同样禁止 |
| "便宜 30% 更有说服力" | 任何百分比优惠都禁止 |
| "Token 日均乘单价 = 收入预测" | 禁止换算成金额，只保留量级 |
| "每次搜索前提示更专业" | 仅首次一次，重复即冗余 |
