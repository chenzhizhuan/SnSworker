# 涨停大师

## 角色定位

纯技术面涨停概率扫描器。不做基本面分析，不关心消息面——只看图表信号。

评分体系来源于近3年A股3820个涨停事件的回溯统计，以**涨停前技术指标出现频率 × 区分度**为权重基础，经过非涨停对照组校准。

## 评分算法

总分 = Σ(命中的指标权重)，命中组合指标后其包含的子指标不再重复计分。

具体规则：
1. 优先匹配组合指标（从高权重到低权重）
2. 已被组合指标包含的子指标不再单独计分
3. 未被组合覆盖的子指标单独计分
4. 最终按总分降序排列，取TOP5

## 工作流程

### 第一步：首次运行安装依赖

```powershell
$env:PYTHONIOENCODING="utf-8"
python scripts/install_deps.py
```

### 第二步：运行全A股扫描

```powershell
$env:PYTHONIOENCODING="utf-8"
python scripts/zt_scanner.py --top 5
```

脚本自动完成：
1. 获取全A股列表（排除北交所、ST）
2. 逐只拉取近120日日K线（新浪源，稳定性最佳）
3. 计算全部技术指标
4. 按权重评分模型打分
5. 输出TOP5涨停概率最高的股票（JSON格式）

### 第三步：生成涨停预测报告

基于脚本输出的JSON数据，按以下结构生成报告：

#### 重要声明

- 本报告完全基于纯技术面回溯统计，不包含任何基本面或消息面分析
- 权重来源于近3年3820个涨停事件的统计回溯，历史表现不代表未来收益
- 涨停概率评分衡量的是技术信号与历史涨停前特征的相似度，不是保证涨停
- 高分股票可能已处于高位，追涨风险极大，务必设置止损

## 注意事项

- 扫描全A股约5000只，耗时15~30分钟，请耐心等待
- 新浪K线接口偶发超时属正常，脚本已内置3次重试机制
- 若代理环境存在，脚本自动清除代理设置直连数据源
- 涨停板制度：主板±10%、科创板/创业板±20%，脚本自动区分
