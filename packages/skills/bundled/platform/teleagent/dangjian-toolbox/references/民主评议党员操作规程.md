# 民主评议党员操作规程

> 本工具箱补充能力。覆盖民主评议党员全流程操作规范及配套表格模板。

## 一、评议依据

民主评议党员是对党员进行经常性教育、管理和监督的重要方法。每年开展一次，一般结合组织生活会进行。

## 二、评议等次

| 等次 | 标准 | 比例要求 |
|------|------|----------|
| 优秀 | 模范履行党员义务，正确行使党员权利，在本职岗位和社会生活中先锋模范作用突出 | 一般不超过党员总数的三分之一 |
| 合格 | 按照党员标准履行义务，基本符合党员要求 | 不设比例限制 |
| 基本合格 | 在某些方面存在不足，但尚不具备不合格条件 | 不设比例限制 |
| 不合格 | 不履行党员义务，不具备党员条件 | 实事求是评定 |

## 三、评议流程（6步）

### 第1步：学习教育（评议前）
- **内容**：组织党员学习党章党规、最新理论成果
- **目的**：统一思想、提高认识、打牢评议基础
- **材料**：学习记录
- **注意**：学习不少于1次

### 第2步：自我评价
- **方式**：党员对照党员标准，总结个人在政治、思想、学习、工作、纪律、作风等方面的情况
- **材料**：党员个人总结（书面）
- **注意**：自我评价要实事求是，既讲成绩也讲不足

### 第3步：民主测评
- **方式**：发放民主测评表，无记名投票
- **参评人员**：全体党员（有表决权的正式党员），可吸收部分群众代表参加
- **材料**：民主测评表
- **注意**：测评结果作为评定等次的重要依据，但不以票取人

### 第4步：组织评定
- **主体**：支部委员会
- **方式**：综合党员自我评价、民主测评结果、平时表现，集体研究确定评议等次
- **材料**：支委会评定记录
- **注意**：评定须集体研究，不得由个人决定

### 第5步：反馈与谈话
- **对象**：全体党员（重点与"基本合格""不合格"党员谈话）
- **方式**：个别谈话反馈评议意见
- **材料**：谈话记录
- **注意**：对"不合格"党员，应指出问题、限期改正

### 第6步：上报与归档
- **上报**：评议结果报上级党委
- **归档**：评议材料存入支部党建档案
- **材料**：民主评议党员情况汇总表

## 六、评议结果运用

| 等次 | 结果运用 |
|------|----------|
| 优秀 | 评先评优优先推荐；作为"两优一先"评选依据 |
| 合格 | 正常参加组织生活 |
| 基本合格 | 支部指定专人帮带，限期改正（一般不超过1年） |
| 不合格 | 限期改正（1年）或劝退/除名（按程序报批） |

## 七、常见问题与易错点

1. **以票取人**：民主测评票数是参考，不是唯一依据——须结合平时表现综合评定
2. **轮流坐庄**："优秀"轮流当——优秀须有突出表现，不是排资论辈
3. **走过场**：测评表发下就收，无学习教育和自我评价环节——6步缺一不可
4. **比例突破**：优秀等次超过三分之一——须严格控制比例
5. **不敢评"不合格"**：怕得罪人——实事求是是原则，不合格的必须评定
6. **程序倒置**：先评定后测评——须先测评后评定
7. **缺少群众参与**：仅党员内部评议——应吸收部分群众代表参加

## 八、安全提醒

- 测评表须无记名，保护测评人隐私
- 不合格党员的评定和处理涉及个人权益，须严格按程序执行
- 评议材料不得在公开场合展示个人具体评定等次
