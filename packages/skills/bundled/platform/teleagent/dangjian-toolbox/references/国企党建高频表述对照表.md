# 国企党建高频表述对照表

> "错误表述→规范表述"速查。输出材料终检时逐条比对，确保表述不出政治问题。

## 一、政治表述类

| 错误/不当表述 | 规范表述 | 说明 |
|--------------|----------|------|
| 习近平总书记说/讲 | 习近平总书记指出/强调/重要论述 | "说""讲"不够庄重 |
| 二十大报告说 | 党的二十大报告指出/强调 | 须用"指出"等正式动词 |
| 中央认为 | 党中央指出/强调 | 不得用"中央"代替"党中央" |
| 两个维护 | 坚定拥护"两个确立"、坚决做到"两个维护" | 通常成对出现，不拆用 |
| 四个意识 | 切实增强"四个意识"、坚定"四个自信" | 通常成组使用 |
| 新时代中国特色社会主义思想 | 习近平新时代中国特色社会主义思想 | 不得省略"中国" |
| 党要管党 | 坚持党要管党、全面从严治党 | 通常成对出现 |
| 高质量发展 | 推动高质量发展 / 以高质量发展为主题 | 须有动作动词 |
| 新发展理念 | 完整、准确、全面贯彻新发展理念 | 前缀不可省 |
| 中国式现代化 | 全面推进中国式现代化 | 须有动作动词 |

## 二、国企党建类

| 错误/不当表述 | 规范表述 | 说明 |
|--------------|----------|------|
| 国企党建 | 国有企业党建工作 / 国企党的建设 | "国企党建"可用于口语化标题，正式表述用全称 |
| 党的领导融入公司治理 | 把党的领导融入公司治理各环节 | 须有"各环节"限定 |
| 党建进章程 | 将党建工作总体要求写入公司章程 | 不得简化为"党建进章程" |
| 两张皮 | 党建与经营"两张皮"（加引号） | 须加引号表示特定概念 |
| 一肩挑 | 党组织书记和董事长"一肩挑"（加引号） | 须加引号 |
| 党建考核 | 党建工作责任制考核 | 须用全称 |
| 三重一大 | "三重一大"决策制度（加引号） | 须加引号 |
| 国企改革三年行动 | 国有企业改革深化提升行动 | 注意最新表述，"三年行动"已过时 |
| 公司制改革 | 中国特色现代企业制度 | 语境不同，不可混用 |

## 三、组织生活类

| 错误/不当表述 | 规范表述 | 说明 |
|--------------|----------|------|
| 过组织生活 | 严格执行组织生活制度 / 认真开展组织生活 | "过"不够正式 |
| 民主生活会开了 | 召开民主生活会 | 须用"召开" |
| 批评和自我批评开展得不扎实 | 批评和自我批评"辣味不足" | 用规范表述 |
| 三会一课制度 | "三会一课"制度（加引号） | 须加引号 |
| 谈心谈话 | 谈心谈话制度 / 开展谈心谈话 | 作为制度表述 |
| 主题党日 | 主题党日制度 / 开展主题党日活动 | 区分制度与活动 |
| 双重组织生活 | 领导干部双重组织生活制度 | 须加"领导干部"限定 |
| 组织生活会 | 组织生活会和民主生活会 | 两者不同，不可混用 |

## 四、发展党员类

| 错误/不当表述 | 规范表述 | 说明 |
|--------------|----------|------|
| 培养联系人 | 培养联系人（正式表述） | 无不当，但须区分"培养联系人"和"入党介绍人" |
| 介绍人 | 入党介绍人 | 须用全称 |
| 预备期一年 | 预备期为一年 | 须加"为" |
| 转正 | 按期转为正式党员 | 正式表述 |
| 吸收为党员 | 吸收为预备党员 | 发展党员是先成为预备党员 |
| 考察期满 | 培养考察期满 / 预备期满 | 须区分两种考察 |
| 入党志愿 | 入党志愿书（表） | 须用全称 |
| 党龄从预备期算 | 党龄从预备期满转为正式党员之日算起 | 常见错误 |

## 五、巡察整改类

| 错误/不当表述 | 规范表述 | 说明 |
|--------------|----------|------|
| 巡察组指出的问题 | 巡察反馈问题 / 巡察反馈意见 | 须用"反馈" |
| 整改完了 | 整改完成 / 按期完成整改 | "完了"不正式 |
| 举一反三 | 坚持举一反三、标本兼治 | 通常成对使用 |
| 建章立制 | 建章立制、堵塞漏洞 | 通常成对使用 |
| 销号管理 | 实行台账销号管理 | 须有"台账"限定 |
| 真改实改 | 真改实改、全面整改 | 通常成对使用 |

## 六、纪律作风类

| 错误/不当表述 | 规范表述 | 说明 |
|--------------|----------|------|
| 八项规定 | 中央八项规定及其实施细则精神 | 须用全称 |
| 四风 | "四风"问题（加引号） | 须加引号 |
| 走过场 | 力戒形式主义 / 确保取得实效 | 不得出现"走过场"（即使否定句也不建议） |
| 作风建设永远在路上 | 作风建设永远在路上，必须以钉钉子精神一抓到底 | 须加上下文 |
| 反腐败斗争 | 一体推进不敢腐、不能腐、不想腐 | 须用规范表述 |
| 纪律规矩 | 党的纪律和规矩 / 纪律规矩意识 | 须有"党的"限定或后缀"意识" |
| 红线底线 | 坚守底线、不越红线 | "底线""红线"各有含义，不可混用 |

## 七、数字化/AI类（国企特有）

| 错误/不当表述 | 规范表述 | 说明 |
|--------------|----------|------|
| AI取代人工 | AI赋能一线 / AI辅助决策 | 不得用"取代"表述 |
| 数字化转型完成 | 持续推进数字化转型 | 转型是持续过程 |
| 智能化改造 | 数智化转型升级 | 注意最新表述 |
| 大数据分析 | 数据驱动决策 | 语境不同 |
| 人工智能应用 | 人工智能赋能业务场景 | 须有具体场景 |

## 使用方法

1. **终检时全文搜索**：搜索左列关键词，发现即替换为右列规范表述
2. **预检时场景标注**：根据材料类型，预标注高频踩坑点
3. **不是所有左列表述都有"错"**：部分是口语化或不够正式，在非正式场合可酌情使用，但在正式公文/材料中须用规范表述
