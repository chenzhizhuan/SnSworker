# 安全红线总纲

> 党建材料安全红线双检总纲。整合源技能8项通用检查 + 国企经营特有4项 + 程序合规3项，共3类15项。

## 双检机制

```
预检（输出前）→ 根据场景标注本次需检查的红线项
终检（输出后）→ 逐项对照，在文末以表格附自检结果
```

### 预检级别对照

| 级别 | 适用场景 | 检查项 |
|------|----------|--------|
| 标准8项 | 党课/组织生活会/三会一课/主题党日 | 通用政治安全红线1-8 |
| 标准8项+国企4项 | 党建总结述职/党建融入中心/巡察整改 | 通用+国企经营特有 |
| 标准8项+程序3项 | 发展党员/民主评议 | 通用+程序合规 |
| 标准8项+国企4项+程序3项 | 巡察整改（涉及三重一大） | 全量15项 |
| 免检 | 考试客观题 | 无需检查 |

---

## 一、通用政治安全红线（8项）

### 1. 政治表述

| 项目 | 内容 |
|------|------|
| 红线 | 引用领导人讲话必须准确完整，不得断章取义；不得自行概括领导人讲话精神；重大会议表述必须用官方通稿原文 |
| 正向替换 | 用官方通稿原文，标注出处和日期 |
| 检查方法 | 全文搜索领导人姓名，逐句核对引文是否完整 |
| 高频踩坑 | "习近平总书记指出"后跟自己概括的话——必须改为原文引用或标注"精神实质是" |

### 2. 反腐相关

| 项目 | 内容 |
|------|------|
| 红线 | 不得涉及具体反腐案例、落马官员姓名；不得在材料中分析腐败原因 |
| 正向替换 | 只讲正面要求（"要严守廉洁底线"），不点名不举例 |
| 检查方法 | 全文搜索已公开通报的落马官员姓名，确认未出现 |
| 高频踩坑 | 党课讲稿中"大家可能看到了XX被查的通报"——必须改为"近年来各级纪检监察机关通报的案例给我们敲响了警钟" |

### 3. 人事评价

| 项目 | 内容 |
|------|------|
| 红线 | 不得对个人晋升、处分做判断或暗示；不得在对照检查中点名批评具体同事 |
| 正向替换 | 只做组织层面要求表述；用"个别同志""少数干部"等泛指 |
| 检查方法 | 检查批评内容是否指向可识别的具体个人 |
| 高频踩坑 | "XX同志在XX问题上存在不足"——必须改为"个别同志在XX方面还有提升空间" |

### 4. 信访维稳

| 项目 | 内容 |
|------|------|
| 红线 | 不得涉及信访案例、维稳细节；不得描述具体群体性事件 |
| 正向替换 | 只讲制度要求（"健全矛盾排查化解机制"），不碰具体 |
| 检查方法 | 检查是否出现具体信访事件描述 |
| 高频踩坑 | "去年XX群体上访事件"——必须改为"面对复杂维稳形势" |

### 5. 集体决策

| 项目 | 内容 |
|------|------|
| 红线 | 涉及三重一大事项必须体现集体研究过程；不得以个人意见代替组织决定 |
| 正向替换 | "经支委会研究决定""经党委会讨论通过" |
| 检查方法 | 凡涉及人事、资金、项目的内容，检查是否有集体决策表述 |
| 高频踩坑 | "决定安排XX经费用于XX"——必须改为"经支委会研究，安排XX经费用于XX" |

### 6. 形式主义

| 项目 | 内容 |
|------|------|
| 红线 | 不得出现"走过场""搞形式""做样子"等承认形式主义的表述 |
| 正向替换 | 强调"注重实效""务求实效""力戒形式主义" |
| 检查方法 | 全文搜索"走过场""搞形式"等词 |
| 高频踩坑 | "不能走过场"虽然是否定句，但仍含敏感词——改为"确保取得实效"更安全 |

### 7. 宗教敏感

| 项目 | 内容 |
|------|------|
| 红线 | 不得出现任何宗教相关表述；不得将宗教术语用于党建语境 |
| 正向替换 | 严格使用"理想信念""党性修养"表述 |
| 检查方法 | 全文搜索宗教相关词汇 |
| 高频踩坑 | "要有信仰"——在党建语境中应改为"坚定理想信念" |

### 8. 涉密信息

| 项目 | 内容 |
|------|------|
| 红线 | 不得出现具体涉密内容、涉密项目代号；不得在公开材料中引用涉密数据 |
| 正向替换 | 用"相关工作""相关项目"代称 |
| 检查方法 | 检查是否出现未公开的项目名称、未公开的数据 |
| 高频踩坑 | 直接写未公开的经营数据或战略部署——确认所有数据是否已公开 |

## 二、国企经营特有红线（4项）

### 9. 经营数据

| 项目 | 内容 |
|------|------|
| 红线 | 未经公开披露的经营数据不得出现在可外传材料中；内部材料标注密级；同比/环比数据须注明口径 |
| 正向替换 | 已公开数据注明来源（如"据年报披露"）；未公开数据用"XX"占位并标注"内部数据，注意管控" |
| 检查方法 | 检查每处经营数据是否已公开或已标注密级 |
| 高频踩坑 | 党建经验交流材料中直接写"实现收入XX亿元"——需确认是否可对外披露，或改为"收入实现稳步增长" |

### 10. 商业秘密

| 项目 | 内容 |
|------|------|
| 红线 | 不得在材料中披露具体客户信息、资费策略、网络架构细节、技术方案等商业秘密 |
| 正向替换 | 用"重点客户""差异化策略""技术保障"等概括表述 |
| 检查方法 | 检查是否出现可识别的客户名称、具体资费方案、技术细节 |
| 高频踩坑 | "为XX公司提供了XX元/月的专属方案"——必须改为"为重点客户提供差异化服务方案" |

### 11. 关联交易

| 项目 | 内容 |
|------|------|
| 红线 | 涉及关联方的内容不得在党建材料中披露交易细节；不得暗示利益输送 |
| 正向替换 | 不涉及；如必须提及关联方，用"相关单位" |
| 检查方法 | 检查是否出现子公司/关联公司交易细节 |
| 高频踩坑 | 党建共建方案中写"与XX子公司联合开展"——确认是否需隐藏关联方身份 |

### 12. 安全生产

| 项目 | 内容 |
|------|------|
| 红线 | 不得在材料中披露未公开的安全事故细节；安全生产表述须与实际口径一致 |
| 正向替换 | "持续抓好安全生产""守住安全底线" |
| 检查方法 | 检查是否出现具体事故描述、伤亡数字 |
| 高频踩坑 | "吸取XX事故教训"——如事故未公开通报，必须改为"强化安全风险管控" |

---

## 三、程序合规红线（3项）

### 13. 三重一大

| 项目 | 内容 |
|------|------|
| 红线 | 重大决策、重要人事任免、重大项目安排、大额资金使用必须体现集体决策程序 |
| 正向替换 | "经党委会/支委会研究决定" |
| 检查方法 | 材料中涉及三重一大事项的，检查是否有集体决策表述 |
| 高频踩坑 | 整改方案中"安排XX万元用于党建阵地建设"——须加"经党委会研究" |

### 14. 请示报告

| 项目 | 内容 |
|------|------|
| 红线 | 重大事项必须体现请示报告程序；不得越权表态 |
| 正向替换 | "按规定向上级党组织请示报告" |
| 检查方法 | 涉及重大事项的，检查是否体现请示报告程序 |
| 高频踩坑 | "支部决定开展XX活动"——如属于需上级批准的事项，须改为"拟开展XX活动，已向上级党组织请示" |

### 15. 发展党员程序

| 项目 | 内容 |
|------|------|
| 红线 | 发展党员必须严格按5阶段25环节执行；不得简化、跳过或倒置程序 |
| 正向替换 | 按《发展党员全流程操作手册》逐环节执行 |
| 检查方法 | 对照全流程手册，检查时间节点是否合规、材料是否齐全 |
| 高频踩坑 | "确定为积极分子后即安排参加组织生活"——积极分子可参加部分活动，但不等同于党员权利 |

## 结尾原则

党建材料结尾落在"担当作为"或"履职尽责"，不落在个人得失。国企党建材料结尾须同时体现政治站位和经营意识（如"以高质量党建引领保障高质量发展"）。
