# 党建公文规范表述手册

> 本工具箱补充能力。覆盖8类法定公文 + 国企党建常见公文的格式规范和表述要求。与 `国企党建高频表述对照表.md` 配合使用——对照表管"用词"，本手册管"格式"。

## 一、法定公文8类

### 1. 请示

**适用**：向上级党组织请求指示、批准。

**格式规范**：
```
关于XX的请示

XX党委：

（正文：请示事项的背景、理由、具体请求）
（结尾用语：妥否，请批示。/ 当否，请批复。）

XX支部（委员会）
2026年X月X日
```

**写作要点**：
- 一文一事：一份请示只请示一件事项
- 不得越级：一般不得越级请示，确需越级的须抄报被越过机关
- 不得多头请示：不得同时向多个机关请示同一事项
- 结尾用语固定：用"妥否，请批示"或"当否，请批复"
- 涉及三重一大的，须写明"经党委会/支委会研究"

**党建场景示例**：
- 关于设立XX党支部的请示
- 关于XX同志任党支部书记的请示
- 关于开展XX党建活动的请示（涉及经费须写明金额，经集体研究）

### 2. 报告

**适用**：向上级党组织汇报工作、反映情况、回复询问。

**格式规范**：
```
关于XX的报告

XX党委：

（正文：报告事项的基本情况、主要做法、成效、问题、下一步打算）
（结尾用语：特此报告。/ 专此报告。）

XX支部（委员会）
2026年X月X日
```

**写作要点**：
- 报告不得夹带请示事项（如需请示须另行行文）
- 结尾用语：用"特此报告"
- 汇报性报告：按"做了什么→怎么做的→效果如何→下步打算"结构
- 反映情况报告：按"基本情况→分析研判→意见建议"结构

**党建场景示例**：
- 关于2026年度党建工作情况的报告
- 关于巡察整改情况的报告
- 关于组织生活会召开情况的报告

### 3. 通知

**适用**：发布、传达要求下级党组织执行的事项。

**格式规范**：
```
关于XX的通知

各支部/各党小组：

（正文：通知事项的背景、具体要求、时间安排、工作要求）
（结尾用语：请认真贯彻执行。/ 请按要求抓好落实。）

XX支部（委员会）
2026年X月X日
```

**写作要点**：
- 事项明确：时间、地点、人员、要求写清楚
- 要求具体：不说"高度重视""认真组织"等空话，写具体动作
- 时限清晰：明确截止时间

**党建场景示例**：
- 关于召开组织生活会的通知
- 关于开展主题党日活动的通知
- 关于开展纪律教育学习月活动的通知

### 4. 通报

**适用**：表彰先进、批评错误、传达重要精神或情况。

**格式规范**：
```
关于XX的通报

各支部/各党小组：

（正文：通报事项的事实经过、性质认定、处理决定、工作要求）
（结尾用语：各单位要从中吸取教训，引以为戒。/ 全体党员要向XX同志学习。）

XX支部（委员会）
2026年X月X日
```

**写作要点**：
- 表彰通报：事实+贡献+表彰决定+学习要求
- 批评通报：事实+性质认定+处理决定+教训要求
- 安全提醒：批评通报不得点名涉及具体人事矛盾（参考安全红线第3项）

### 5. 决定

**适用**：对重要事项作出决策和部署。

**格式规范**：
```
关于XX的决定

（正文：决定的背景依据、具体内容、执行要求）

XX党委
2026年X月X日
```

### 6. 批复

**适用**：答复下级党组织请示事项。

**格式规范**：
```
关于XX的批复

XX支部：

你支部《关于XX的请示》收悉。经研究，批复如下：

一、同意XX。
二、XX。

此复。

XX党委
2026年X月X日
```

**写作要点**：
- 必须针对请示内容逐一答复，不答非所问
- 态度明确：同意/不同意/部分同意

### 7. 纪要

**适用**：记载会议主要情况和议定事项。

**格式规范**：
```
XX支部X届X次委员会会议纪要

时间：2026年X月X日X时
地点：XX会议室
主持人：XX（支部书记）
出席人员：XX、XX、XX
记录人：XX

议题一：XX
（讨论情况要点+议定事项）

议题二：XX
（讨论情况要点+议定事项）

（结尾：会议要求各委员按分工抓好落实。）
```

**写作要点**：
- 忠于会议实际：讨论情况简要记录，议定事项明确准确
- 不得事后篡改：纪要须在会后及时整理，经主持人审签
- 涉及三重一大的会议，纪要须体现讨论过程和表决情况

### 8. 函

**适用**：不相隶属党组织之间商洽工作、询问和答复问题。

**格式规范**：
```
关于XX的函

XX党支部：

（正文：函询/商洽事项的具体内容）
（结尾用语：请予支持为盼。/ 请研究函复。）

XX支部
2026年X月X日
```

## 二、国企党建非法定常见公文

### 1. 工作方案

**结构**：
```
# XX工作方案

## 一、指导思想
## 二、工作目标（量化）
## 三、组织领导（领导小组+分工）
## 四、主要任务（分条列明，每条含做法+时限+责任）
## 五、实施步骤（时间表）
## 六、保障措施
```

### 2. 总结报告

**结构**：
```
# XX工作总结

## 一、基本情况
## 二、主要做法及成效（用数据支撑）
## 三、存在问题（不超过3条）
## 四、下一步打算（对应问题逐条回应）
```

### 3. 述职报告

**结构**：
```
# 2026年度XX述职报告

## 一、履职情况（按"党建+经营"融合逻辑，见融入中心写作指南）
## 二、存在问题
## 三、原因分析
## 四、下一步打算
```

### 4. 经验交流材料

**结构**：
```
# 以XX为XX，推动XX

## 一、基本情况和总体思路
## 二、主要做法（3-4条，每条"做法+成效"）
## 三、工作体会
## 四、存在问题及下一步打算
```

## 三、公文通用格式规范

### 版面要求（参照GB/T 9704-2012）
- 页面：A4
- 标题：二号方正小标宋简体（或宋体加粗）
- 正文：三号仿宋
- 一级标题：三号黑体（"一、")
- 二级标题：三号楷体（"（一）")
- 三级标题：三号仿宋加粗（"1.")
- 行距：28-30磅

### 行文规则
- 党的公文使用党组织的名义行文，不用行政名义
- 联合行文：同级党组织可联合行文
- 抄送：不得抄送个人
- 数字：年份用全称（"2026年"不写"26年"）

### 安全提醒
- 所有公文须经分管领导审签后方可发出
- 涉密公文按密级管理要求处理
- 公文中的数据须与实际一致，不得"造数据"
