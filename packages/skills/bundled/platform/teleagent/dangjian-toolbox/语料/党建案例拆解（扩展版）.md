## 案例六：国企书记项目方案

**场景**：电信党支部围绕经营痛点立项的书记项目
**字数**：约2200字
**结构**：

1. **立项背景（300字）**：用数据说痛点
   - 示例："XX年1-X月，我支部覆盖的XX区域宽带激活率仅为XX%，低于全市均值XX个百分点，客户流失率XX%"
   - 要点：痛点必须量化，不能只说"存在不足"

2. **项目概况（200字）**：一表概览
   - 项目名称：红色引擎·宽带提质
   - 责任领导：党支部书记XX
   - 目标：宽带激活率提升至XX%，流失率降至XX%

3. **实施举措（900字）**：3条，每条"做法+党员作用+成效"
   - 党员突击队攻坚：XX名党员包干XX个难点小区
   - 党员示范岗引领：在XX岗位设示范岗，带动服务提升
   - 党建共建合力：与社区/物业党支部共建

4. **保障措施（300字）**
5. **预期成效（300字）**：党建+经营双线量化
6. **安全红线自检表**

**写作禁忌**：
- 没有数据的用「XX」占位，不得编造
- 经费须写"经支委会研究"
- 不得泄露客户名单、资费方案等商业秘密

## 案例七：党建经验交流材料

**场景**：在省公司党建经验交流会上发言
**字数**：约3000字
**结构**：

1. **基本情况+总体思路（400字）**
   - 一句话概括做法："坚持'四融'模式，以高质量党建引领保障高质量发展"
   - 3个关键数据领先

2. **主要做法（1500字，4条）**
   - 融心：理论武装凝聚转型共识
   - 融建：支部建在项目一线
   - 融合：党建经营同频共振
   - 融创：党员先锋攻克痛点
   - 每条：痛点→做法→成效（数据）

3. **工作体会（500字，3条）**
   - 体会升华到方法论层面
   - 金句收尾

4. **存在问题及下一步打算（400字）**

**写作禁忌**：
- 不是纯党建总结，核心是"融合"
- 数据注意密级
- 不夸大成绩

## 案例八：巡察整改报告

**场景**：收到巡察反馈后集中整改完成的报告
**字数**：约2800字
**结构**：

1. **总体情况（300字）**
   - 反馈问题XX项，完成XX项
   - 建章立制XX项

2. **逐条整改情况（1800字）**
   - 每条：反馈原文→整改措施→整改成效→整改状态
   - 用数据说话（注意密级）
   - 不处理人的只写"对相关责任人依规依纪进行了处理"

3. **长效机制建设（400字）**
4. **存在不足及下一步打算（300字）**

**写作禁忌**：
- 反馈问题原文引用，不得"消化"
- 处理情况不点名
- 资金数据确认密级

## 案例九：抓党建述职报告

**场景**：年度抓基层党建工作述职
**字数**：约3500字
**结构**：

1. **履职情况（2000字，4-5条）**
   - 每条：党建做法→经营成效→融合逻辑
   - 示例：抓政治建设→理论学习XX次→转化为XX举措→推动XX指标提升XX%

2. **存在问题（500字，3条）**
   - 问题要有融合视角
   - "党建与经营'两张皮'问题仍未根本解决"

3. **原因分析（300字）**
   - 思想根源+方法路径+机制保障

4. **下一步打算（700字，4条）**
   - 每条对应问题
   - 每条都要有融合措施

5. **安全红线自检表**

**写作禁忌**：
- 不能只讲党建不讲经营
- 不能只讲成绩不讲问题
- 数据注意密级

## 案例十：党建+数字化/AI经验材料

**场景**：党建引领数字化转型经验材料
**字数**：约2500字
**结构**：

1. **背景（300字）**
   - 数字化转型痛点：人不会用/不愿用/用不好
   - 党建切入点

2. **做法（1200字，4条）**
   - 党员带头学：数智大讲堂XX期，党员授课率XX%
   - 党员带头用：党员数字化工具使用率XX%
   - 党员带头教：1+N帮扶机制
   - 党员带头创：提出数字化建议XX条

3. **成效（500字）**
   - 数字化覆盖率提升XX%
   - 经营效率提升XX%
   - 党员先锋示范效应

4. **体会（300字）**
   - "技术是工具，人是关键，党员是关键中的关键"

5. **安全红线自检表**

**写作禁忌**：
- 不得泄露AI模型参数、数据源等商业秘密
- 不夸大技术效果（如"AI取代人工"）
- 数字化成效数据注意密级

## 通用写作方法论速查

| 方法 | 适用场景 | 核心公式 |
|------|----------|----------|
| 痛点→做法→成效 | 经验材料、书记项目 | 每条必须三个要素齐全 |
| 数据/对比/案例 | 总结报告 | 用数据说话、用对比显效、用案例支撑 |
| 问题+表现+根源+措施 | 对照检查 | 辣味公式 |
| 做法标题对仗 | 经验交流 | 四字/六字对仗，如"聚焦融心""聚焦融建" |
| 逐条对应 | 巡察整改 | 反馈一条→整改一条→报告一条 |
| 双线呈现 | 述职报告 | 党建做法→经营成效，每条双线 |
