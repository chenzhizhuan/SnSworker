# 政企客户部招投标助手

## Overview

面向政企客户部的招投标信息搜索与商机跟踪技能。基于「招投标助手」能力扩展，聚焦政企客户部业务场景：搜索全国公开招标采购平台上与政企信息化、数字化相关的项目公告，整理为结构化商机信息，生成网页(HTML)形式展示，辅助客户拜访、项目跟踪与投标决策。

## 与通用「招投标助手」的区别

- **场景聚焦**: 搜索时优先关注政企信息化相关关键词（智慧政务、政务云、行业数字化、AI平台、系统集成、ICT服务等）
- **输出强化**: 在网页汇总中增加"商机价值"标注（金额规模、行业、区域），便于政企客户部按区域/行业快速筛选目标客户
- **跟踪提醒**: 汇总结果中包含项目关键节点（截止时间、开标时间），便于跟进投标窗口

## Workflow

### Step 1: 确定搜索参数

确认以下搜索参数（缺失时向用户询问或使用合理默认值）：

- **关键词**: 用户指定搜索词；未指定时默认围绕政企信息化领域（如"智慧政务"、"政务信息化"、"数字化"、"AI平台"、"系统集成"、"云计算"等）
- **时间范围**: 默认最近7天，可调整为最近30天/半年/一年
- **地区**: 默认全国，可限定省市（政企项目常按区域划分，如"河北省""成都市"）
- **公告类型**: 招标公告 / 中标公告 / 中标候选人公示 / 竞争性磋商 / 谈判采购 / 更正公告（默认全部）
- **关键词变体**: 对核心关键词做扩展搜索（如"智慧政务"同时搜索"政务数字化"、"数字政府"），不同变体覆盖不同项目

### Step 2: 多轮搜索采集

使用 `online_search` 工具进行多轮搜索，确保覆盖面：

1. 以"关键词 + 招标公告 + 采购 + 年月"组合搜索
2. 以"关键词 + 中标公告 + 采购 + 年月"组合搜索
3. 以"关键词 + 竞争性磋商 + 询价 + 年月"组合搜索
4. 以"关键词 + 中标候选人公示 + 年月"组合搜索
5. 如有特定地区需求，追加"关键词 + 地区名 + 招标/采购"搜索
6. 使用 `site:ccgp.gov.cn` 限定中国政府采购网进行精准搜索（信息最权威、结构最规范）
7. 对核心关键词进行变体扩展搜索，不同变体可覆盖不同项目
8. 设置 `search_recency_filter` 为 week/month/semiyear/year 对应时间范围

每轮搜索并行发起2个请求以提高效率。

### Step 3: 获取详细信息

对搜索结果中的重要项目，使用 `webfetch` 获取公告详情页内容，提取以下字段：

> **⚠️ 已知限制**: 部分省级招标平台（如 `okcis.cn`、`bidcenter.com.cn`）存在人机验证/反爬机制，`webfetch` 可能返回验证码页面或乱码。遇到此类情况应跳过该链接，改用搜索摘要中已获取的信息。优先抓取 `ccgp.gov.cn`（中国政府采购网）的链接，该平台无反爬限制且信息结构最规范。

| 字段 | 说明 |
|------|------|
| 项目名称 | 公告标题 |
| 项目编号 | 官方编号 |
| 公告类型 | 招标/中标/磋商/谈判/更正 |
| 采购单位 | 招标人/采购人（政企客户） |
| 预算/中标金额 | 金额（万元） |
| 中标供应商 | 中标公告时填写 |
| 截止时间 | 投标/响应截止时间 |
| 代理机构 | 招标代理机构 |
| 项目内容 | 简要描述 |
| 来源链接 | 公告原文URL |
| 公告日期 | 发布日期 |
| 所属地区 | 省/市 |
| 所属行业 | 行业分类 |

### Step 4: 数据去重与整理

- 按公告日期倒序排列
- 同一项目有多个公告类型时，保留信息最完整的一条
- 统计汇总数据：项目总数、各类型数量、总金额、覆盖地区数

### Step 5: 生成网页

在 Working directory 生成 HTML 文件，文件名格式：`{关键词}政企招标信息汇总.html`

#### 网页结构要求

1. **头部区域**: 标题 + 副标题 + 数据来源/日期范围/更新时间
2. **统计面板**: 4个统计卡片（项目总数、中标公示数、已知金额合计、覆盖地区数）
3. **筛选栏**: 按公告类型筛选的按钮组（含JS交互）
4. **项目卡片列表**: 每个项目一张卡片，包含标题、标签、日期、关键信息、来源链接
5. **页脚**: 数据采集说明

#### 样式要求

- 使用渐变色头部（政企商务主题深蓝/藏青色）
- 卡片左侧边框按公告类型着色区分
- 响应式布局适配移动端
- 统计卡片悬浮上浮动画
- 筛选按钮点击筛选项目卡片

### Step 6: 交付

使用 `report_final_files` 报告生成的 HTML 文件路径，并在回复中简要说明采集结果概况。
