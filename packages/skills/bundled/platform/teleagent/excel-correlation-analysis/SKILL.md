# Excel表格数据关联性分析及可视化输出

## 交互式收集阶段

### 步骤0：首次回复

技能触发后的**第一条回复**，无论用户说了什么或上传了什么文件，只输出以下内容，并**无视第一条上传的所有文件**：

```markdown
## 使用说明

本技能用于分析Excel表格数据的字段关联性，生成结构化数据字典并可视化输出。

你只需完成以下 **3步** 交互，之后即可等待网页可视化程序自动运行：
1. 告知分析目标（【特定内容】）
2. 上传完整数据文件
3. 选择并上传辅助文件（3选1）

### 完整流程概览

| 步骤 | 操作 | 运行方式 | 涉及文件 |
|---|---|---|---|
| 0~3 | 收集：告知分析目标 → 上传数据文件 → 选辅助文件 | 用户交互 | 数据文件、辅助文件 |
| 4 | 提取表头，创建数据字典骨架（A、F列） | Python本地 | 数据文件 |
| 5 | 统计类别个数与枚举值（C、H列） | Python本地 | 数据文件 |
| 6~8 | 填充字段说明（G列）：选A本地匹配，选B/C含LLM语义分析 | Python本地/LLM | 选A：辅助文件；选B：辅助文件（LLM）；选C：辅助文件（字典本地+示例LLM）、数据字典 |
| 9 | 字段分类（B列）+ 数值标签（E列） | LLM | 数据字典 |
| 10 | 关联度判断（D列） | LLM | 数据字典 |
| 11 | 输出完整数据字典 | Python本地 | 数据字典 |
| 12 | 启动Flask可视化，自动打开浏览器 | Python本地 | 数据字典 |
| 13~14 | 【可选】上传JSON，LLM分析原因，按格式输出 | 用户+LLM | JSON文件 |

### 第1步：告知分析目标

请告诉我：**你要分析和什么的关联度？**
```

### 步骤1：用户回答【特定内容】→ 询问上传数据文件

用户回答后：
1. 确认收到分析目标
2. 询问上传数据文件：

```markdown
分析目标已收到（第1步完成）。接下来是第2步：上传数据文件。

请上传你的**完整数据文件**（仅支持 `.xlsx` / `.xls`）：
- 要求：第一行为表头，不存在任何合并单元格
- 重要：数据文件的所有操作均在本地通过Python完成，不上传、不进行语义分析

请上传数据文件。
```

### 步骤2：用户上传数据文件 → 询问辅助文件类型

用户上传数据文件后：
1. 确认收到数据文件
2. 向用户展示3选1选项，询问选择哪种辅助文件：

```markdown
数据文件已收到（第2步完成）。接下来是第3步：提供辅助文件，用于解释字段含义，请选择一种：

| 选项 | 说明 | 格式 | 注意事项 |
|---|---|---|---|
| A. 数据字典 | 含数据文件各字段的中文解释 | Excel/TXT/Word等 | — |
| B. 示例文件 | 与数据文件表头一致，含1~3行示例数据 | Excel | 需脱敏或使用假数据 |
| C. 数据字典+示例文件 | 部分字段有字典，其余靠示例推断 | 各自对应格式 | 示例数据需脱敏 |

> 选项B、C涉及示例数据：示例数据可能泄露敏感信息，请进行脱敏处理，或修改为假数据，仅用于分析数据逻辑。

请选择（A/B/C）并上传对应文件。
```

### 步骤3：用户选择并上传辅助文件 → 进入执行阶段

用户选择并上传辅助文件后，所有用户输入收集完毕，进入执行阶段。

## 自动执行阶段

所有用户输入收集完毕后，按步骤4~12顺序执行，用户无需再次交互。

### 步骤4：Python本地 — 创建数据字典骨架

通过Python在本地操作数据文件，不上传、不进行语义分析：

1. 读取数据文件第一行表头
2. 新建Excel文件 `数据字典_Tele.xlsx`，表头结构：
   - A列：编号（按表头顺序，从1开始）
   - B列：字段分类（步骤9填充）
   - C列：类别个数（步骤5填充）
   - D列：关联度（步骤10填充）
   - E列：数值标签（步骤9填充）
   - F列：字段名（填入数据文件的表头）
   - G列：字段说明（步骤6~8填充）
   - H列：枚举值（步骤5填充）

### 步骤5：Python本地 — 统计类别个数与枚举值

对数据文件每一列统计不同类别的数量：

- **C列只能填以下4个值之一**：`1`、`2`、`3`、`n`，不允许填入其他任何数值
- **类别数 > 30**：H列留空，C列填 `n`
- **类别数 ≤ 30**：
  - H列填入所有枚举值，用顿号（`、`）分隔
  - 若原内容中含顿号，将原顿号替换为下划线 `_`
  - NULL 视为一个类别，计入统计和枚举值
  - C列规则（只填4选1）：
    - 实际类别数 = 1 → 填 `1`
    - 实际类别数 = 2 → 填 `2`
    - 实际类别数 = 3 → 填 `3`
    - 实际类别数 > 3 → 填 `n`（无论4、5、6…30，一律填 `n`）

### 步骤6~8：填充G列（字段说明）

根据用户在步骤3选择的辅助文件类型：

| 辅助文件类型 | 处理方式 | 运行方式 |
|---|---|---|
| A. 数据字典 | Python本地匹配字段中文含义写入G列 | Python本地 |
| B. 示例文件 | LLM语义分析字段及内容含义写入G列 | **LLM（非本地，需告知用户）** |
| C. 数据字典+示例文件 | 先Python本地匹配数据字典中已有中文含义，剩余字段通过LLM语义分析示例数据补充 | Python本地 + LLM |

**重要**：若涉及LLM语义分析（选项B或C），需告知用户"此步骤非本地完成，涉及AI语义分析"。

### 步骤9：LLM语义分析 — 字段分类与数值标签

分析G列（字段说明）和H列（枚举值）：

- **B列（字段分类）**：将所有字段归入若干大类（如"用户基本信息"、"消费行为"等），由LLM自行判断分类粒度和名称
- **E列（数值标签）**：判断每个字段是否为数值字段
  - 数值字段定义：非0/1布尔变量、非文本变量、非类型值、类别数>5
  - 数值=填 `1`，非数值=填 `0`

### 步骤10：LLM语义分析 — 关联度

使用用户在步骤1提供的【特定内容】，判断数据字典中G列每个字段与【特定内容】的语义关联度：

- 等级：0（最低）~ 4（最高）
- 填入D列

### 步骤11：输出数据字典

A~H列全部填写完毕，将 `数据字典_Tele.xlsx` 输出给用户。

### 步骤12：启动可视化工具

1. 运行本地Flask脚本 `scripts/excel_visualization_tool_with_summary.py`，通过命令行参数**仅预加载数据字典**：
   ```
   python excel_visualization_tool_with_summary.py --dictionary "数据字典_Tele.xlsx的绝对路径"
   ```
   - 依赖：`pip install flask pandas numpy openpyxl`
   - 若用户无Python，帮助安装Python及依赖包
   - **必须在后台启动Flask服务**（如使用 `start` 命令或子进程），确保Flask持续运行不会因AI回复结束而关闭
   - 脚本启动后自动打开浏览器 `http://127.0.0.1:5000`
2. 告知用户：
   - 脚本在本地运行，数据不外传
   - 浏览器中**数据字典已预加载**，用户只需上传数据文件，然后点击"生成可视化"
   - 查看可视化报告后，点击"下载JSON"按钮下载JSON文件
   - 若要继续分析【特定内容】的可能原因，将JSON文件上传回对话

## 数据安全原则

- 对数据文件的所有操作（步骤4、5）均在本地通过Python完成，不上传、不语义分析
- 步骤6~8涉及LLM语义分析时，明确告知用户此步骤非本地完成
- 引导用户对示例数据进行脱敏处理
