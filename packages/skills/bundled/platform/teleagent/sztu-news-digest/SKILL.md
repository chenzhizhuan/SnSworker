# 深技大热点新闻

## 概述

从深圳技术大学官网「技大焦点」（校园新闻、媒体聚焦）与「科研实训」（科学研究）三个栏目抓取最新新闻，按时间窗口筛选后生成单文件响应式 HTML 网页，包含数据可视化、时间线、快捷入口、科研动态等丰富板块，便于浏览、分享与归档。

## 触发场景

- 用户说「深技大今天有什么新闻」「深技大官网热点」「生成深技大新闻网页」等
- 需要定期汇总某高校官网新闻并生成可视化页面

## 工作流程

1. **抓取新闻**：运行 `scripts/fetch_sztu_news.py` 抓取三个栏目
   ```powershell
   $env:PYTHONIOENCODING='utf-8'; $env:PYTHONUTF8='1'
   python scripts/fetch_sztu_news.py --days 1 --max-pages 3 --output sztu_news.json
   ```
   - `--days`：目标时间窗口天数（默认 1，即"最近一天"）
   - `--max-pages`：每栏目最多翻页数（默认 3，约覆盖最近 15-18 条/栏目）
   - 脚本会自动放宽窗口：若窗口内无新闻，每轮 +7 天，最多放宽到 `days+35` 天
   - 输出 JSON 含 `total`、`effective_window_days`、`items[]`
   - 三个栏目：校园新闻(`jdjd/xyxw`)、媒体聚焦(`jdjd/mtjj`)、科学研究(`kysx/kxyj`)

2. **渲染 HTML**：运行 `python scripts/build_html.py --input sztu_news.json --output sztu_news.html`

3. **交付**：将生成的 `.html` 文件作为最终交付物交给用户，并在回复中说明：
   - 共抓到 N 条新闻（校园新闻 x 条 / 媒体聚焦 y 条 / 科学研究 z 条）
   - 实际生效的时间窗口（如"最近 7 天"，因为当天无新闻自动放宽）

4. **维护关注事项面板**：上部左栏「关注事项」面板的「开学季 · 近期安排」分组含具体日期（如学宿费缴纳、报到注册、选课时间），这些日期会随学期推进过期。每次生成日报时，若当前日期临近新学期或已过期，用 `online_search` 搜索该校最新校历/通知（关键词如「深圳技术大学 报到 选课 通知」），更新该分组条目与底部紧急提示条，保持信息不过期。

5. **维护静态板块**：下部三栏中的竞赛信息（我爱竞赛网 52jingsai.com）和大学生在线热点（中国大学生在线 dxs.moe.gov.cn）为静态写入模板的内容。若用户反馈竞赛已过期或需要更新，用 `online_search` 搜索最新竞赛榜单和大学生在线活动，更新 `build_html.py` 模板中对应板块的 HTML 内容。同样关注快捷入口、校园日历时间线等静态板块的新鲜度。

6. **维护新生报到指南板块**：该板块含报到流程、线上注册、线下报到、校园卡、宿舍入住、南区宿舍宽带、校园星卡、高频问答、联系电话等时效性内容。每年开学季前（8-9 月），用 `online_search` 搜索该校最新迎新通知（关键词如「深圳技术大学 新生报到 2026」），更新 `build_html.py` 中对应板块的日期、流程步骤、联系电话和 FAQ。南区宿舍宽带和校园星卡套餐内容如有变更，搜索最新资费说明更新。

## 关键实现细节

- 站点为静态 HTML，无反爬，直接 `requests + BeautifulSoup(lxml)` 抓取
- 校园新闻条目：`<a href="info/xx/xx.htm"><div class="yy-ifo"><span>日期</span><h3>标题</h3><p>摘要</p>...`
- 媒体聚焦条目：`<a href="外部链接">`，`<h3>` 内含 `<span>媒体名</span>`，无摘要
- 科学研究条目：与校园新闻结构相同（`.yy-ifo`），`key="kyyx"` 且不是 `mtjj`，故不过滤媒体前缀
- 日期格式：列表页显示 `2026/08/08`，脚本转为 ISO 格式 `2026-08-08`
- 三个栏目均支持翻页（第1页 `xyywb.htm`/`mtjj.htm`/`kxyj.htm`，后续 `xyywb/125.htm`/`mtjj/36.htm`/`kxyj/11.htm`）
- 媒体聚焦页有大量导航外链干扰，脚本只保留 `.yy-ifo` 区块内的链接，天然过滤
- 跨栏目去重：同一标题(前40字)+URL 在多个栏目出现时只保留首条
- 抓取失败自动重试（默认 2 次重试 + 递增退避 2s/4s）
- Windows 下运行必须设置 `PYTHONIOENCODING=utf-8` 避免 GBK 编码报错

## 动效开发约束

修改 `build_html.py` 中 CSS/JS 动效时需注意以下约束：

- **背景动效透明度上限**：背景数字雨等底层动效透明度不得超过 25%，避免干扰正文阅读
- **打字机效果与子元素 DOM 顺序**：打字机 JS 逐字写入 `.sub` 容器时，会覆盖容器内已有子元素。若 `.sub` 内有 LIVE 徽章等子元素，必须在打字机写入后重新 `appendChild` 恢复其位置，否则子元素会丢失
- **模板占位符**：`build_html.py` 使用 `str.replace("@@key@@", value)` 注入动态数据，禁止使用 `.format()`（花括号与 CSS/JS 语法冲突）
- **动效数量与性能**：当前约 26 种动效，新增动效优先用 CSS animation 实现；JS 动效需注意 `IntersectionObserver` 只观察首屏可见元素，避免全页同时触发

## 输出 HTML 特性

- 深蓝+活力橙渐变 Hero 头，展示总条数/窗口天数/三栏目统计，带扫描线 + 30 彩虹粒子动效
- 顶部加载进度条：页面加载时青色光条从 0% 填满到 100% 后淡出
- 背景数字雨：页面底层 0/1 数字竖流缓慢下落（25% 透明度，不干扰阅读）
- 每日鸡汤横幅（根据日期确定性选取，同一天同一条），支持鸡汤轮播 + 茶杯热气 + 高光流动动效
- **快捷入口导航**：8 个常用入口卡片（概况/招生/研究生院/就业/图书馆/校历/国际交流/活力技大），图标渐变动效 + 鼠标跟随光晕
- **上部三栏布局**（桌面）：左(230px)关注事项 sticky / 中(1fr)新闻主列表 / 右(290px)数据速览
  - ≤1100px 三栏堆叠为单栏
  - 关注事项面板支持手动折叠/展开（标题旁按钮，收起时隐藏内容与对齐中间栏）
- **数据速览面板**（右）：环形图（conic-gradient 按真实占比动态生成，0 值栏目自动跳过）+ 栏目占比进度条，环形图带旋转入场动画
- **科研动态横条**：消费抓取的「科学研究」栏目，最多展示 3 条科研新闻卡片
- **校园日历时间线（横向卡片式）**：5 个关键节点横排展示，每个节点为胶囊日期标签 + 卡片内容，节点脉冲发光、hover 上浮，移动端横向滑动
- **下部三栏**：热门行业(6卡片) / 竞赛(6卡片+展开折叠) / 在线热点(5条)
- **成长规划全宽板块**：四卡片（四六级/奖学金/实习/考研）
- **新生报到指南（全宽）**：报到流程 5 步、线上注册（迎新服务网+3 项必做任务）、线下报到（时间/地点/携带材料）、校园卡、宿舍入住、南区宿舍宽带（认证流程+套餐）、校园星卡（电信套餐+融合套餐）、高频问答（9条）+ 联系电话栏
- **新闻列表筛选**：「全部 / 校园 / 媒体 / 科研」四按钮纯前端 JS 过滤
- 卡片式新闻：日期、栏目徽章(蓝/橙/紫对应三类)、媒体来源、标题、摘要、外链跳转
- 过期条目自动灰显：关注事项和竞赛卡片带 `data-deadline`，JS 对比今天日期自动加 `.expired`
- 静态板块底部自动显示「最后更新：YYYY-MM-DD」时间戳
- 右上角明暗主题切换按钮（localStorage 持久化，默认亮色）
- 页面渐入动画 + 移动端响应式（媒体查询）
- 综合动效：标题光泽扫描、数字 hover 放大发光、LIVE 呼吸徽章、卡片光边扫描、新闻卡片滚动入场（IntersectionObserver）、时间线节点脉冲、打字机光标、标题竖线生长等约 26 种 CSS/JS 动效
- 加载进度条 + 顶部 Hero 标题扫描光泽 + 数字滚动计数器（0→目标值）

## 失败降级

- 网络异常/站点结构变更导致抓取为空：报告用户"官网暂时无法访问或栏目结构变化"，给出官网地址让用户手动查看
- 窗口内无任何新闻（自动放宽后仍无）：输出提示文案说明"最近无新闻发布"
- 科研栏目为空时：科研动态横条整块隐藏（`research-strip:empty`），不显示占位，避免页面留白
