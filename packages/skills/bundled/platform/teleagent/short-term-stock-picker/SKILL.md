# 短线股票精选

以量化 + 基本面双轮驱动的短线选股策略，帮助用户在 A 股市场中筛选 T+1 至 T+5 交易日的短线机会。

## 核心准则：保守优先

**宁可漏、不可错。** 短线交易风险极高，推荐错误的股票比漏掉一支股票危害大得多：

1. **双源验证必做**：所有财务/行情数据必须通过 pywencai（问财）和 akshare 两个来源交叉验证，单源数据不得作为选股依据
2. **数据不一致不推荐**：若双源数据的同一指标差异超过阈值（价格>1%、量比>10%、换手率>1%），该股票标记为"数据存疑"并排除出推荐
3. **风控一票否决**：第五层风控筛选中任一指标触发红色警示，无论前四层表现多好，一律排除

**禁止**：凭直觉推荐股票、只用单一数据源、忽略退市风险标记、推荐 ST/\*ST 股票、在未验证数据的情况下给出买入价位

## 触发条件

当用户消息包含以下关键词时触发本技能：
- 短线 / 选股 / 股票推荐 / T+1 / 量化选股
- 涨停 / 连板 / 量比 / 换手率 / 主力资金
- 选股器 / 股票筛选 / 短线机会

## 五层筛选流程（顺序执行，逐层淘汰）

### 第一层：趋势层（市场大势过滤）

**目标**：排除处于下降趋势或无明确趋势的股票

| 筛选指标 | 条件 | 数据源 |
| --- | --- | --- |
| 均线排列 | MA5 > MA10 > MA20（多头排列） | akshare 日K线 |
| 均线斜率 | MA5 斜率 > 0，MA10 斜率 ≥ 0 | 计算得出 |
| 收盘价位置 | 收盘价 > MA20 | akshare 日K线 |
| 周线趋势 | 周线 MA5 > MA10 | akshare 周K线 |

**淘汰率**：约 60-70%

### 第二层：量价层（量价配合确认）

**目标**：确认资金正在流入，股价上涨有量能支撑

| 筛选指标 | 条件 | 数据源 |
| --- | --- | --- |
| 量比 | 1.5 ≤ 量比 ≤ 5（放量但非天量） | pywencai + akshare |
| 换手率 | 3% ≤ 换手率 ≤ 15%（活跃但非过热） | pywencai + akshare |
| 量价配合 | 近3日放量且涨幅>0的交易日≥2天 | akshare 日K线 + 成交量 |
| 涨幅区间 | 1% ≤ 日涨幅 ≤ 7%（不追涨停，不买跌股） | akshare 日K线 |

**淘汰率**：约 50%（累计淘汰约 85%）

### 第三层：资金层（主力资金确认）

**目标**：确认有主力资金持续流入

| 筛选指标 | 条件 | 数据源 |
| --- | --- | --- |
| 主力净流入 | 最近1日主力净流入 > 0 | akshare 个股资金流 |
| 连续流入 | 最近3日主力净流入合计 > 0 | akshare 个股资金流 |
| 大单占比 | 大单成交占比 > 30% | akshare 个股资金流 |
| 北向资金 | 北向持股变化 ≥ 0（可选，仅沪股通/深股通标的） | akshare 北向资金 |

**淘汰率**：约 40%（累计淘汰约 91%）

### 第四层：技术层（技术形态确认）

**目标**：确认技术面存在短线爆发临界点

| 筛选指标 | 条件 | 数据源 |
| --- | --- | --- |
| MACD | MACD 金叉或 MACD 柱状体由负转正 | 计算得出 |
| KDJ | K 线 > D 线 且 J < 100（非超买区金叉） | 计算得出 |
| RSI | 50 < RSI(6) < 80（多头但非极端超买） | 计算得出 |
| 布林带 | 股价突破中轨且中轨斜率 > 0 | 计算得出 |

**淘汰率**：约 50%（累计淘汰约 95.5%）

### 第五层：风控层（风险过滤，一票否决）

**目标**：排除存在重大风险的股票

| 风控指标 | 红色警示（直接排除） | 黄色警示（标注但不排除） | 数据源 |
| --- | --- | --- | --- |
| ST 标记 | ST / \*ST / SST | — | akshare 股票信息 |
| 退市风险 | 退市风险警示 | — | akshare 股票信息 |
| 停牌状态 | 当前停牌 | — | akshare 实时行情 |
| 涨跌幅异常 | 近5日曾跌停 | 近5日最大跌幅>5% | akshare 日K线 |
| 流动性 | 日成交额 < 5000万 | 日成交额 < 1亿 | akshare 日K线 |
| 股价区间 | 股价 < 3元 | 股价 < 5元 | akshare 实时行情 |
| 市值规模 | 总市值 < 30亿 | 总市值 < 50亿 | akshare 股票信息 |
| 限售股解禁 | 近5日有限售股解禁且解禁市值 > 流通市值5% | 近10日有限售股解禁 | akshare 限售解禁 |
| 大股东减持 | 近5日有大股东减持公告 | 近20日有减持公告 | pywencai 公告查询 |

**淘汰率**：约 10-20%（累计淘汰约 96-97%）

### 汇总示意

```
全A股 ≈5000 只
  │
  ├─ 第一层 趋势层  → 淘汰 60-70%  → 剩余 ~1500-2000
  │
  ├─ 第二层 量价层  → 淘汰 50%    → 剩余 ~750-1000
  │
  ├─ 第三层 资金层  → 淘汰 40%    → 剩余 ~450-600
  │
  ├─ 第四层 技术层  → 淘汰 50%    → 剩余 ~225-300
  │
  └─ 第五层 风控层  → 淘汰 10-20% → 剩余 ~180-270
```

最终输出 Top 10-20 只，按综合评分排序。

## 双源数据交叉验证规则（强制）

### 数据获取

| 数据源 | 获取方式 | 主要用途 |
| --- | --- | --- |
| pywencai（问财） | `pip install pywencai` → `pywencai.get(query, date)` | 量比、换手率、涨幅排名、概念板块、公告查询 |
| akshare | `pip install akshare` → 对应接口 | 日K线、资金流、北向资金、股票基本信息、限售解禁 |

### 交叉验证阈值

| 指标 | 允许偏差 | 超偏差处理 |
| --- | --- | --- |
| 最新价 | ≤ 1% | 标记"数据存疑"，排除推荐 |
| 量比 | ≤ 10% | 标记"数据存疑"，排除推荐 |
| 换手率 | ≤ 1个百分点 | 标记"数据存疑"，排除推荐 |
| 日涨幅 | ≤ 0.5个百分点 | 标记"数据存疑"，排除推荐 |
| 主力净流入 | ≤ 20%（金额>1000万时） | 标记"数据存疑"，排除推荐 |

### 数据不一致时的处理流程

1. 记录双源数据差异
2. 尝试第三次查询（择时数据以 akshare 实时为准，排名数据以 pywencai 为准）
3. 仍不一致 → 排除出推荐列表，在报告中标注「⚠️ 数据源不一致，已排除」

## 五维投资评估报告

对最终入选的每只股票，生成五维评估：

### 维度一：趋势得分（0-100）

- 均线排列完整度（30分）
- 均线斜率强度（30分）
- 周线趋势确认（20分）
- 中长期趋势定性（20分）

### 维度二：量价得分（0-100）

- 量比合理性（25分）
- 换手率合理性（25分）
- 量价配合度（25分）
- 涨幅合理性（25分）

### 维度三：资金得分（0-100）

- 主力净流入规模（30分）
- 连续流入天数（25分）
- 大单占比（25分）
- 北向资金态度（20分）

### 维度四：技术得分（0-100）

- MACD 状态（25分）
- KDJ 状态（25分）
- RSI 状态（25分）
- 布林带位置（25分）

### 维度五：风控得分（0-100）

- ST/退市风险（一票否决，有则0分）
- 流动性（20分）
- 股价合理性（20分）
- 市值规模（20分）
- 解禁/减持风险（20分）
- 近期异常波动（20分）

### 综合评分

```
综合评分 = 趋势得分×0.25 + 量价得分×0.20 + 资金得分×0.25 + 技术得分×0.15 + 风控得分×0.15
```

### 报告输出格式

每只入选股票按以下格式输出：

```

 ┃ 趋势 85  ┃ 量价 78  ┃ 资金 88  ┃ 技术 75  ┃ 风控 80

```
用户发起选股请求
      │
      ▼
 ┌─────────────┐
 │ 环境检查     │ ──→ 检查 pywencai/akshare 是否已安装
 │ 缺失则安装   │     网络连接是否正常
 └──────┬──────┘
        │
        ▼
 ┌─────────────┐
 │ 第一层筛选   │ ──→ 趋势层：均线排列+周线趋势
 │ akshare K线  │     获取全A股日K/周K数据
 └──────┬──────┘
        │
        ▼
 ┌─────────────┐
 │ 第二层筛选   │ ──→ 量价层：量比+换手率+涨幅
 │ pywencai     │     双源交叉验证
 │ + akshare    │
 └──────┬──────┘
        │
        ▼
 ┌─────────────┐
 │ 第三层筛选   │ ──→ 资金层：主力流入+大单占比
 │ akshare      │     个股资金流数据
 │ 资金流接口   │
 └──────┬──────┘
        │
        ▼
 ┌─────────────┐
 │ 第四层筛选   │ ──→ 技术层：MACD+KDJ+RSI+BOLL
 │ 本地计算     │     基于已有K线数据计算
 └──────┬──────┘
        │
        ▼
 ┌─────────────┐
 │ 第五层筛选   │ ──→ 风控层：ST/退市/解禁/减持
 │ akshare      │     一票否决制

        ▼
 ┌─────────────┐

## 环境依赖

### Python 包

| 包名 | 用途 | 安装命令 |
| --- | --- | --- |
| pywencai | 问财数据查询 | `pip install pywencai` |
| akshare | A股行情数据 | `pip install akshare` |
| pandas | 数据处理 | `pip install pandas` |
| numpy | 数值计算 | `pip install numpy` |
| tabulate | 表格格式化 | `pip install tabulate` |

### 网络要求

- 需要稳定的互联网连接（查询问财/akshare API）
- 如遇 akshare 接口限流，自动降级为 pywencai 单源（标注⚠️单源数据）

## QQ 机器人推送（可选）

当用户要求推送至 QQ 群/好友时：

1. 使用 `requests` 库向 QQ 机器人 HTTP API 发送 POST 请求
2. 请求体包含：股票列表、综合评分、操作建议
3. 消息格式为 QQ 可渲染的文本（支持 AT 消息）

**注意**：QQ 机器人的 API 地址和 Token 由用户在请求时提供，技能不自带默认值。

## 免责声明（每份报告必须包含）

> ⚠️ 本报告由量化模型自动生成，仅供参考，不构成任何投资建议。股市有风险，投资需谨慎。模型的筛选逻辑基于历史数据统计规律，不保证未来收益。使用者应根据自身风险承受能力独立判断，自主决策，自行承担投资风险。
