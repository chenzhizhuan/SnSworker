## （版本2026.7.16-V7）

**类型：修复 — iterate_v4.py 连续空仓日导致无效迭代**

连续多天空仓（大盘暴跌不出票）时，迭代脚本仍按天累计计数器，3天空仓就触发迭代，但数据全空导致四层胜率显示0%、偏差模式识别全部走不通，报告无实际分析价值。

### 修复内容

1. **空仓日不计入迭代计数器**：判断今日是否空仓日（无有效标的参与统计），空仓日计数器保持不变，仅输出"空仓趋势简报"
2. **空仓趋势简报**：空仓日仍生成报告，但内容聚焦趋势分析而非无效的0%胜率
   - 统计近10日空仓占比，≥80%触发警告，≥50%提示偏弱
   - 逐日明细展示标的数/参与统计数/大盘环境（从predict JSON补全）
   - 不建议放宽筛选条件，避免选到弱势股
3. **混合场景处理**：3个有效交易日中含空仓日时
   - 空仓日在四层胜率表中标注"空仓/暴跌"，不显示0%"
   - 有效日均值只统计有标的的日子
   - 有效样本不足（<5只）时跳过分组分析，用参考数据分析暴跌日空仓决策是否正确
   - 暴跌日被skip的标的仍计算参考收盘胜率，验证空仓决策正确性
4. **大盘环境补全**：review JSON中无market_env字段，新增`load_predict_map()`从predict JSON补全大盘环境（红/黄/绿灯+描述）

### 空仓日处理逻辑

```
空仓日 → 计数器不+1 → 生成空仓趋势简报 → 分析近10日空仓趋势 → 提示风险等级 → 退出
有效日 → 计数器+1   → 满3天触发迭代分析 → 混合场景按有效日统计 → 偏差模式识别
```

## （版本2026.7.16-V4）

**类型：新增功能 — 四阶段闭环系统 + 四层胜率体系**

基于22只标的次日5分钟K线分析结论（11:00胜率最高63.6%，11:30平均盈利最高+1.13%，10:00验证偏早）驱动，将选股系统从"次日10:00固定验证"单一模式升级为四阶段闭环。

### 四阶段架构

| 阶段 | 时间 | 脚本 | 功能 |
|------|------|------|------|
| 早盘预判 | 09:30 | predict_v4.py（新建） | 读取前日选股+当日开盘行情，输出操作指南（卖出窗口/目标价/止损价/仓位建议），生成JSON快照 |
| 盘中辅助 | 10:00 | verify_v4.py（改造） | 精简版盘中辅助，保留快照胜率追踪+预判交叉对比，详细复盘移至15:05 |
| 收盘复盘 | 15:05 | review_v4.py（新建） | 四层胜率计算+预测准确度评分（0-100），5分钟K线逐时点盈亏，JSON+CSV双追踪 |
| 三天迭代 | 15:30 | iterate_v4.py（新建） | 计数器控制每3交易日触发，偏差模式识别，改进建议输出（不自动改参数） |

### 四层胜率体系

| 层级 | 计算方式 | 用途 |
|------|---------|------|
| 快照胜率 | 10:00现价 vs 选股价 | 盘中快速参考（保留verify_history.csv原有格式） |
| 收盘持有胜率 | 15:00收盘价 vs 选股价 | 拿到收盘的结果 |
| 窗口可用胜率（核心） | 建议卖出窗口内5分钟K线最高价 vs 选股价 | 按系统建议操作实际能实现盈利的概率 |
| 策略上限胜率 | 日内最高价 vs 选股价 | 评估选股策略本身上限 |

### 预测准确度评分（0-100分）

大盘方向20分 + 个股开盘方向15分 + 卖出窗口命中30分 + 目标价偏差15分 + 止损判断10分 + 风险等级10分
