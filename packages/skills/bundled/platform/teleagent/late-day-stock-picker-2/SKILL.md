## 交互流程（核心改进）

**调用此技能时，必须先询问用户选择执行模式，不可直接运行脚本。**

使用 question 工具向用户提供以下三个选项：

1. **完整四阶段闭环（推荐）** — 一次性设置7个定时任务，覆盖从早盘预判到收盘迭代的完整选股闭环，全程自动运行无需人工干预
2. **三轮定时对比** — 仅设置14:00/14:30/14:50三个定时任务，分三次运行选股脚本，收盘后汇总三轮结果对比验证，选出信号持续强化的最优标的
3. **即时运行一次** — 根据当前时刻数据直接运行选股脚本，输出本次结果

根据用户选择执行对应流程。

## 筛选流程

1. **判断交易日** — 周末及法定假日跳过
2. **mootdx全量扫描** — 获取约5200只A股实时行情
3. **本地硬性过滤** — ST/北交所/停牌/一字板/价格3-105/振幅≤15%/跌幅>-7%
4. **大盘环境检查** — 上证涨跌幅+涨跌家数比+近3日连续下跌检测；**情绪维度(2026.9.9)：涨停/跌停/炸板家数与炸板率**
5. **腾讯API补字段** — 量比/换手率/振幅/均价/名称/开盘价/成交额
6. **稳健版参数筛选** — 涨幅1.8%-5.2%/量比1.9-4.2/换手4.2%-10.5%/振幅≤13%/现价≥均价
7. **强制避雷** — 量比>6.8或换手>17.5%剔除
7.5 **流动性下限(2026.9.9新增)** — 成交额≥2亿（缺数据不误伤）
8. **K线形态过滤** — 上影线≤实体0.8倍 + 收盘≥最高价95% + 实体占比≥40%（3项满足2项通过）
9. **65日K线深度验证（前复权）** — 【2026.9.9起优先腾讯前复权数据】MA5/MA10/MA20 + 连涨天数 + 5日累计涨幅 + 前日涨幅 + 距20日低点/60日高点 + MA20斜率 + MA5/MA10偏离度 + 收益率 + 影体比 + **ATR14(波动率)**
10. **深度趋势排除** — 距60日高点<-30%直接排除
11. **脉冲双因子排除（2026.7.16新增）** — gain_ratio<0.60且shadow_body>0.50直接排除（验证：5亏0盈100%亏损率）
12. **综合评分（满分110+5额外）** — 8维加权 + 5项扣分 + 均线不达标降档锁定
13. **ETF筛选** — 约80只主流ETF（涨幅>0.5%/量比>1.0）
14. **板块联动提示(2026.9.9新增v1)** — 候选股行业聚类，输出板块聚集度
15. **参数敏感性审计（可选）** — `python scripts/audit_overfit.py --runs_dir <运行数据目录>`

> 所有可调阈值已集中至 `scripts/config_parameters.py`；每次调参前先备份、跑审计，禁止频繁微调（避免过拟合）。

## 三轮对比选股机制

尾盘选股信号随交易时间推移会变化，单次运行可能捕捉到不稳定的信号。通过三轮对比，可有效过滤忽高忽低的脉冲股，锁定信号持续加强的优质标的。

### 执行时间表

| 轮次 | 时间 | 目的 |
|------|------|------|
| 第一轮 | 14:00 | 初筛：盘面初步分化，捕捉量价异动标的 |
| 第二轮 | 14:30 | 复筛：验证信号持续性，对比第一轮筛选结果 |
| 第三轮 | 14:50 | 尾盘验证：临近收盘确认，对比三轮结果稳定性 |

### 对比逻辑

1. **盘中两轮对比（14:00 vs 14:30）**：
   - 两轮同时出现的标的 → 信号持续性强，优先考虑
   - 仅14:00出现后消失的 → 脉冲信号，放弃
   - 仅14:30新出现的 → 尾盘确认信号，可关注

2. **尾盘验证（14:50 vs 盘中两轮）**：
   - 三轮均出现 → **最强信号**，次日表现最佳概率高
   - 盘中出现但收盘评分下降 → 信号减弱，降低仓位或放弃
   - 盘中出现但收盘被排除 → 信号失效，坚决不介入

3. **大盘弱时脉冲风险控制（2026.7.16新增）**：
   - sh_ok=false时脉冲信号标注「高风险」，不建议操作
   - 验证数据：大盘弱时脉冲胜率仅30%(3/10)，大盘正常时100%(6/6)

### 操作建议

- 仅三轮对比后仍持续出现的标的才值得建仓
- 评分持续上升的标的优于评分波动的标的
- 一档标的如在三轮中降为二档或消失，说明趋势不稳放弃

### 三轮定时任务配置流程

用户选择"三轮定时对比"后：

1. 创建14:00定时任务 — 运行选股脚本，记录第一轮结果
2. 创建14:30定时任务 — 运行选股脚本，记录第二轮结果
3. 创建14:50定时任务 — 运行选股脚本，记录第三轮结果（尾盘验证）
4. 三轮完成后汇总对比报告，给出最终操作建议
5. 次日10:00运行验证脚本，对比前日选股结果与次日实际涨跌

> 非交易时段（周末/假日）时，告知用户今日非交易日，无法执行选股。

## 评分体系

详见 [references/scoring_rules.md](references/scoring_rules.md)

### 加分项（满分110+5额外）

| 维度 | 分值 | 规则 |
|------|------|------|
| 均线多头(MA5>MA10且价>MA5) | 20 | 多头+20，非多头+0 |
| 5日均量倍数 | 20 | ≥1.28+20，≥1.0+10 |
| 连涨天数 | 15 | ≤1天+15，≤2+10，≤3+5 |
| 5日累计涨幅 | 15 | ≤8%+15，≤12%+10，≤15%+5 |
| 位置(距低点) | 10 | ≤15%+10，≤25%+5 |
| 位置(距高点) | 5 | ≤-5%+5 |
| K线形态 | 10 | 3/3满分+10，2/3+5 |
| 大盘环境 | 5 | 上证跌幅超1.5%且涨跌比超0.8+5 |
| MA20上翘(额外) | 5 | MA20斜率向上+5 |

### 扣分项

| 条件 | 扣分 |
|------|------|
| 前日涨幅>7% | -10 |
| 前日涨幅>5% | -5 |
| MA5/MA10偏离度2-5%（仅非多头时） | -5 |
| MA5/MA10偏离度>5%（仅非多头时） | -10 |
| 量比≥2且收盘涨幅<盘中最大涨幅60%（放量滞涨） | -5 |
| 量比≥2且上影线/实体>0.5（放量长上影） | -5 |
| 5日均量倍数<1.0（量能萎缩） | -5 |

### 降档规则

| 条件 | 效果 |
|------|------|
| 均线未多头排列（ma_pass=False） | 锁定二档上限（最高69分，不得进入一档） |

### 排除规则

| 条件 | 效果 |
|------|------|
| 距60日高点<-30% | 直接排除（深度下降趋势不抢反弹） |
| gain_ratio<0.60且shadow_body>0.50 | 直接排除（脉冲冲高回落，2026.7.16新增） |
| 近3日上证连续2日下跌 | 判定大盘偏弱，不出票 |

### 输出分档

- **一档(≥70分)**：多维达标，尾盘可考虑建仓
- **二档(50-69分)**：部分维度弱，观望为主
- **三档(<50分)**：不推荐

## 2026.9.9 改进说明（四项结构性改进）

1. **过拟合审计**：历史样本仅约36个交易日/43只一档（7月数据），远不足统计显著性。audit_overfit.py 提供样本量统计、成本口径对照、分档门槛敏感性分析（70分附近入选数：65→71只/70→43只/76→25只，存在"贴线"风险）。**结论：当前参数冻结，勿再凭几天行情调参；待积累≥50样本后复跑审计再决定。**
2. **交易成本**：往返成本约0.30%（佣金万2.5+印花税0.05%+滑点0.1%），平均盈利+1%量级时净值显著低于名义，verify 报告已提供"净收益"列。
3. **复权/情绪/流动性/板块**：K线改用前复权；情绪维度输出涨停/炸板率；流动性下限2亿；板块聚类提示。
4. **ATR止盈止损**：predict 报告按ATR动态给出止盈(2%-5%)/止损(1.5%-3%)，波动大的票区间放宽，避免噪声扫损。
