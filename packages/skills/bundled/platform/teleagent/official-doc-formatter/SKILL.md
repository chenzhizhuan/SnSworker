# 官方公文格式化

## 概述

将任意 docx 文档按国标 GB/T 9704《党政机关公文格式》规范进行格式化，覆盖页面设置、标题层级字体、正文排版、中英文分离、引号修正、表格样式等全套格式要素。

## 支持文种

- 请示、报告、通知、函、纪要
- 方案、总结、规定、办法、意见
- 附件类文档

## 格式规范速查

| 要素 | 规格 |
|------|------|
| 页边距 | 上3.7cm 下3.5cm 左2.8cm 右2.6cm |
| 大标题 | 方正小标宋简体 二号(22pt) 居中 |
| 一级标题 | 黑体 三号(16pt) 首行缩进1.27cm 不加粗 |
| 二级标题 | 楷体_GB2312 三号 首行缩进1.27cm |
| 三级/四级/五级标题 | 仿宋_GB2312 三号 首行缩进1.27cm |
| 正文 | 仿宋_GB2312 三号 首行缩进1.27cm |
| 数字/英文 | Times New Roman 三号 |
| 行间距 | 固定28磅 |
| 段前/段后 | 0磅 |

## 使用流程

1. 确认用户待格式化的 docx 文件路径
2. 识别文档类型（请示/通知/函/报告/一般文件）
3. 执行脚本：
   ```
   python -B scripts/format_docx.py 输入文件.docx 输出文件.docx 文档类型
   ```
   文档类型参数：`请示`、`通知`、`函`、`报告`、`附件`、`general`
4. 输出格式化后的 docx 文件

## 标题识别规则（自动判定）

| 模式 | 字体 | 示例 |
|------|------|------|
| 含"请示/报告/通知"等关键词且<50字 | 方正小标宋简体 居中 | 关于XXX的请示 |
| 一、XXX | 黑体 | 一、总体要求 |
| （一）XXX | 楷体_GB2312 | （一）组织领导 |
| 1.XXX | 仿宋_GB2312 | 1.工作目标 |
| （1）XXX | 仿宋_GB2312 | （1）具体措施 |
| ① XXX | 仿宋_GB2312 | ①第一项 |

## 中英文混排处理

- 中文部分：按层级设置对应中文字体
- 数字/英文部分：统一使用 Times New Roman
- 自动拆分中英文片段，分别设置字体属性

## 引号修正

自动将英文直引号（"）替换为中文弯引号（" "），单引号同理。

## 常见陷阱

详见 [references/lesson_learned.md](references/lesson_learned.md)，包含行间距设置、空行规范、引号类型等易错点及正确做法。

## 表格格式化

- 表格居中、自动调整列宽
- 单元格垂直居中
- 全边框：黑色单线 0.5pt
- 单元格内文字：仿宋_GB2312 三号 居中 行距28磅
