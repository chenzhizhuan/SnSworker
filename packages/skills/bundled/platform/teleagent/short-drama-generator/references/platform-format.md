# 短剧平台发布规范（抖音 / 红果短剧）

## 一、画幅与视频参数

| 项目 | 抖音 | 红果短剧 |
|---|---|---|
| 画幅 | 竖屏 9:16（1080x1920） | 竖屏 9:16（1080x1920） |
| 时长 | 单集 1-3 分钟；连续剧每集 1-2 分钟 | 单集 1-3 分钟 |
| 格式 | MP4（H.264 + AAC） | MP4（H.264 + AAC） |
| 帧率 | ≥30fps | ≥30fps |
| 码率 | ≥4Mbps | ≥4Mbps |

本技能默认输出：1080x1920 / 30fps / H.264 / AAC，符合两平台基础要求。

## 二、内容与文案规范

### 标题
- 抖音：≤30 字，建议 15-25 字，带钩子（悬念/冲突/反转）
- 红果：≤20 字，前 8 字必须吸引点击
- 通用格式：`[冲突钩子] + [主角身份] + [转折]`，例如「被全网骂退圈三年后，影后带着真相杀回来了」

### 简介
- 抖音：≤55 字（超出折叠），写清"谁 + 遭遇什么 + 结果如何"
- 红果：≤120 字，可写剧情梗概 + 钩子
- 建议格式：`主角 + 困境 + 转折 + 悬念提问`

### 话题标签
- 抖音：3-5 个，格式 `#短剧 #都市情感 #追妻火葬场 #反转 #爽剧`
- 红果：2-4 个，`#短剧 #逆袭 #甜宠`
- 规则：1 个热门口（如 #短剧）+ 2-3 个垂类词 + 1 个情绪词

### 封面
- 抖音：竖屏 9:16，主体人脸/冲突场景，标题文字 ≤4 个关键词，高对比
- 红果：竖屏 9:16，主角情绪特写 + 剧名

## 三、短剧黄金开头（前 3 秒）

1. **钩子前置**：第一句台词必须是悬念/冲突/反转，不能是寒暄
2. **节奏**：前 3 秒抛冲突 → 10 秒内给第一个反转 → 每 15-20 秒一个小钩子
3. **字幕**：首帧即上钩子字幕（大字号）

## 四、发布流程

1. 抖音：创作者中心 → 发布视频 → 上传成片 + 封面 → 填标题/简介/话题 → 发布
2. 红果短剧：红果创作者后台 → 短剧投稿 → 选择剧集 → 上传 → 填写剧名/简介 → 提交审核

## 五、本技能输出物

- `成片.mp4`：1080x1920 竖屏正片（含配音、字幕、运镜）
- `发布包/`：封面 jpg + publish_info.json（标题/简介/话题，可直接复制粘贴到平台）+ 成片副本
- 打包 zip 可选
