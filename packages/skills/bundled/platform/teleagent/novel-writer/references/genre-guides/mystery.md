# 悬疑/推理类创作指南

> 核心是"谜题设计+逻辑严密+反转冲击"。

## 核心读者期待

- **核心谜题**：一个让读者想要知道答案的悬念
- **公平推理**：线索在文中给出，读者理论上可推理出答案
- **反转冲击**：意料之外但情理之中的真相
- **紧张氛围**：持续的悬疑感和压迫感
- **逻辑严密**：无 plot hole，解答经得起推敲

## 谜题类型

| 类型 | 特点 | 难点 |
|------|------|------|
| 本格推理 | 注重诡计和逻辑 | 诡计要新颖合理 |
| 社会派 | 关注人性和社会 | 深度要够，不能说教 |
| 悬疑惊悚 | 紧张感和追逐 | 节奏控制是关键 |
| 暴风雪山庄 | 封闭空间+有限嫌疑人 | 人物设计要精巧 |
| 叙述性诡计 | 利用叙事本身误导 | 需要高超的叙事技巧 |

## 线索管理

**线索三原则**：
1. 所有关键线索必须在揭秘前出现（不能临时编）
2. 线索出现时要自然融入场景（不能像标红一样突兀）
3. 至少有一条误导性线索（红鲱鱼）

**线索追踪表**（建议与剧情线追踪表配合使用）：

```
线索编号：CL-001
内容：___
埋设位置：第X章
呈现方式：角色对话/环境描写/物品/行为
读者可能注意到：是/否
与真相的关系：直接证据/间接证据/误导
回收/使用位置：第X章
```

## 反转设计

**好反转的标准**：
- 意料之外：读者没想到
- 情理之中：回看前文有伏笔
- 改变认知：反转后重新理解前文有新含义
- 角色驱动：反转由角色动机和逻辑支撑，不是为反转而反转

**多层反转**：
- 每层反转独立成立（不能是"其实其实其实"）
- 层层递进深化（每层比上一层更意外）
- 最终反转最有力（放在高潮点）

## 避坑指南

- 避免天降解答：答案必须由前文线索推导
- 避免凶手随机：凶手要有合理动机和机会
- 避免信息不对称过大：侦探知道的读者也应该有机会知道
- 避免氛围断裂：悬疑感要持续，不能忽紧忽松
- 避免逻辑漏洞：解答要经得起"为什么不直接XX"的追问
- 避免动机薄弱：杀人的理由要足够支撑行为
