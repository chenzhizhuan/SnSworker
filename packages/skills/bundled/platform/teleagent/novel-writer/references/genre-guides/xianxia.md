# 仙侠/玄幻/修仙类创作指南

> 网文最大品类。核心是"升级体系+地图探索+热血爽感"。

## 核心读者期待

- **明确的成长路线**：读者要能看到主角变强的路径和预期
- **爽感密集**：打脸/突破/获宝/越级挑战，高频爽点
- **世界足够大**：地图换卷，新鲜感不断
- **热血与友情**：兄弟情/师徒情/知己情是情感支柱
- **公平的体系**：升级有代价有逻辑，不是纯开挂

## 力量体系设计

**境界划分原则**：
- 5-9个大境界，每个大境界3-5个小境界（如练气1-9层）
- 每个境界有明确的实力描述（能做什么/不能做什么）
- 境界差距要有意义——高一个大境界通常碾压低境界，但有例外空间
- 后期境界留有"传说级"留白，便于扩展

**升级机制**：
- 明确升级条件（修炼时间/资源/领悟/战斗突破）
- 升级有代价（时间/资源/风险/副作用）
- 主角升级速度略快于常人（金手指），但要有合理解释
- 避免"无脑升级"——每次升级应有事件驱动，不是纯时间堆积

**战斗力标尺**：
- 读者需要能判断"这一战能不能赢"
- 建立"参照物"：某个境界能做什么标志性的事（如练气期只能催动低级法术）
- 越级挑战要有限制条件，不能无限越级

## 节奏模型

**黄金三章**：
- 第1章：主角处境+核心矛盾+金手指觉醒/暗示，章末留钩子
- 第2章：金手指初步运用+第一次小爽点（打脸/获宝/逆转）
- 第3章：更大的危机/机遇，确立追读理由

**卷结构**：
- 每卷1个地图（宗门/学院/秘境/大陆）
- 卷初：进入新地图→建立新矛盾
- 卷中：升级+冲突升级+小高潮
- 卷末：大高潮（BOSS战/大揭秘/突破）→过渡到下一卷

**爽点频率**：
- 每2000字一个微爽点
- 每章一个大爽点
- 每卷1-2个卷高潮
- 打脸间隔不超过5章

## 常见套路与反套路

| 套路 | 使用建议 | 反套路方向 |
|------|---------|-----------|
| 退婚流 | 可用但需创新角度 | 主动退婚/对方有苦衷 |
| 废柴逆袭 | 经典但需新意 | 不废柴但有其他限制 |
| 扮猪吃虎 | 核心爽点来源 | 偶尔暴露实力制造新局面 |
| 拍卖会 | 展示世界+制造冲突 | 主角做卖家不做买家 |
| 秘境探索 | 换地图+获宝 | 秘境有意志/不是单纯打怪 |
| 宗门大比 | 展示实力+打脸 | 输了但获得更重要东西 |

## 避坑指南

- **避免战力崩坏**：后期不要无脑升级，保持体系一致性
- **避免反派降智**：反派要有合理智商，失败有逻辑原因
- **避免配角工具化**：配角有自己的生活和目标
- **避免地图疲劳**：换地图时要带入旧角色或旧伏笔，保持连贯
- **避免升级流水账**：升级过程要有故事，不是"修炼三年，突破了"
- **避免金手指泛滥**：金手指要有限制，爽感来自克服困难而非无脑碾压
