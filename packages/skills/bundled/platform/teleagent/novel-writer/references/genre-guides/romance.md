# 言情类创作指南

> 核心是"情感发展+角色魅力+甜虐平衡"。

## 核心读者期待

- **CP化学反应**：主角间的情感张力和互动火花
- **角色魅力**：男女主（或主CP）有鲜明的人格魅力
- **情感发展曲线**：从陌生到相爱的过程合理且有吸引力
- **甜虐平衡**：适当的虐增加张力，但最终给读者满足感
- **情感真实性**：感情发展有逻辑，不是"突然就爱了"

## 子类型与特点

| 子类型 | 核心卖点 | 情感基调 |
|--------|---------|---------|
| 甜宠 | 高甜无虐/日常撒糖 | 轻松甜蜜 |
| 虐恋 | 情感纠葛/误会/分离 | 先虐后甜 |
| 重生言情 | 弥补遗憾/改变命运 | 带着记忆重新选择 |
| 豪门 | 阶层差异/权力关系 | 灰姑娘变公主 |
| 古言 | 古代背景+情感 | 含蓄深沉 |
| 校园 | 青春/初恋/成长 | 纯真青涩 |

## 情感发展曲线

```
好感度
  10 |                    ___---  ← 确认心意
   8 |               ___-
   6 |          ___--        ← 暧昧升温
   4 |     ___--
   2 |----              ← 冲突/误会（虐点）
   0 |___
     |→  相遇  磨合  暧昧  冲突  和好  确认
```

**关键节点**：
- 初遇：制造印象深刻的第一面（不是平淡的"你好"）
- 好感萌芽：某个瞬间被打动（需要具体的触发事件）
- 暧昧期：最有看头的阶段，拉长写，用细节堆积
- 冲突/虐点：由角色性格或外部压力驱动，不是无脑误会
- 表白/确认：情感爆发的释放点，要有铺垫

## 避坑指南

- 避免无脑误会：冲突由角色性格驱动，不是"不说清楚"
- 避免角色OOC：为了虐而让角色做出不符合人设的事
- 避免工具人情敌：情敌要有独立人格，不是纯粹的阻碍工具
- 避免感情跳跃：从反感到相爱需要过程，不能突然转变
- 避免甜度通胀：全程高甜会让甜感贬值，需要有节奏起伏
- 避免忽视配角：配角群像丰富才能衬托CP
