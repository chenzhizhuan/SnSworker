## Phase 2 角色审核

- [ ] 主角有完整的核心驱动模型（外在目标/内在需求/致命缺陷/秘密）
- [ ] 主角弧光设计完整（触发→挣扎→转折→新生/毁灭）
- [ ] 主要配角（3-5个）有独立动机和弧光
- [ ] 反派动机自洽可信（不是为坏而坏）
- [ ] 角色关系图谱完整（主要角色间关系明确）
- [ ] 每个重要角色有独特对话指纹
- [ ] 角色服务于剧情，无冗余角色

## Phase 3 大纲审核

- [ ] 每卷有明确的核心冲突和高潮
- [ ] 张力曲线无连续3章低谷
- [ ] 伏笔全部登记，有回收计划
- [ ] 剧情线不超过5条同时活跃
- [ ] 每个转折有因果前导（无巧合推进）
- [ ] 章节细纲包含：场景目标/冲突/转折/爽点/章末钩子
- [ ] 角色弧光在章节细纲中有展现空间

## Phase 4 逐章审核

### 4a. 初稿审核（润色师检查）

- [ ] 场景按目标→冲突→结果构建
- [ ] 对话完成至少一项功能（推进剧情/揭示角色/制造冲突/伏笔）
- [ ] 对话指纹一致（遮名可辨）
- [ ] 感官描写充分（每场景至少3种感官）
- [ ] 节奏得当（句式变化，紧张短句/舒缓长句）
- [ ] 章末有钩子
- [ ] 无设定PPT/百科全书式说明
- [ ] 去AI化检查通过（8项清单）
- [ ] 无OOC（角色行为符合核心驱动模型）

### 4b. 一致性审核（连续性审核员检查）

- [ ] 设定与圣经一致（无矛盾）
- [ ] 角色状态表已更新（位置/已知信息/能力/心理/关系）
- [ ] 角色未使用不该知道的信息
- [ ] 时间线无矛盾
- [ ] 伏笔按计划埋设/回收，追踪表已更新
- [ ] 出场角色与细纲一致
- [ ] 无未解释的新设定出现

### 4c. 阶段审查（每5章，总编+连续性审核员）

- [ ] 5章张力曲线合理（有高低起伏）
- [ ] 剧情线有推进（无停滞）
- [ ] 角色弧光有进展
- [ ] 伏笔状态正常（短线已回收，长线有触碰）
- [ ] 爽点频率达标（网文标准）
- [ ] 节奏无拖沓（无连续2章纯铺垫）

## Phase 5 终审

- [ ] 角色弧光全部完成

### 节奏与结构
- [ ] 全书张力曲线图绘制，无明显塌陷区
- [ ] 每卷高潮质量递进（不倒退）

- [ ] 无连续5章低谷

- [ ] 全书语言风格统一
