## 设定圣经

设定圣经是世界的"宪法"，所有创作必须与之保持一致。

**存储格式**：使用 `assets/templates/setting-bible-template.md` 模板。

**维护规则**：
- 只增不删：已写入正文的设定不可推翻，只能补充
- 变更标记：设定有重大补充时，标注影响范围（哪些已写章节可能受影响）
- 分区管理：按类别分区（力量体系/地理/势力/历史/名词表），便于检索

**检索规则**：写作前，根据章节细纲涉及的设定，检索圣经中对应分区，仅传相关部分进入上下文。

## 角色状态表

追踪每个角色在故事中每一时刻的精确状态。这是防止OOC和时间线矛盾的核心工具。

**每角色追踪字段**：

```
角色名：___
当前卷/章：第X卷第Y章
├─ 位置：当前所在地点
├─ 已知信息：该角色目前知道什么（信息不对称的关键）
├─ 未知信息：该角色不知道但读者知道的（用于戏剧讽刺）
├─ 能力/装备：当前战力水平、持有物品
├─ 心理状态：当前情绪/动机/内心冲突
├─ 关系快照：与其他主要角色的当前关系状态
├─ 未完成目标：该角色正在追求什么
└─ 上次出场：第X卷第Y章
```

**更新时机**：每章定稿后，连续性审核员更新涉及出场的角色状态。

**使用方式**：写作下一章前，提取出场角色的状态快照传入上下文。

## 剧情线追踪表

管理所有剧情线的状态，确保没有线索被遗忘。

**每条剧情线追踪字段**：

```
剧情线编号：PL-001
剧情线名称：___
类型：主线/支线/伏笔/暗线
状态：🌱待启动 / 🔄进行中 / ⏸暂停 / ✅已回收 / ❌已废弃
├─ 埋设位置：第X卷第Y章
├─ 当前进展：一句话描述最新状态
├─ 预计回收位置：第X卷第Y章（或"待定"）
├─ 涉及角色：___
├─ 读者认知度：未知/暗示/明示/已揭示
└─ 备注：___
```

**伏笔特殊管理**：
- 伏笔分3级：短线（10章内回收）/中线（一卷内回收）/长线（跨卷回收）
- 每卷结束时做伏笔审计：检查是否有超期未回收的伏笔
- 长线伏笔每卷至少"触碰"一次（通过暗示提醒读者它还存在）

**多线交织管理**：
- 同时活跃的剧情线建议不超过5条（含主线）
- 支线不可连续超过3章不触碰主线
- 暗线每卷至少露一次线索

## 时间线记录

记录故事内事件的时间顺序，防止时间矛盾。

**记录格式**：

```
时间标记：故事内时间（如"灵气复苏第3年春"/"星际历2847年"/"第一天上午"）
事件：___
涉及角色：___
位置：第X卷第Y章
备注：平行事件/因果前导
```

**关键检查点**：
- 角色A和角色B是否可能在同一时间出现在不同地点（除非有分身/传送设定）
- 旅行时间是否合理（从A城到B城需要多久）
- 季节/天气是否连贯
- 角色年龄是否随时间正确变化

**平行时间线**：如果故事有多视角并行，用分栏记录同时发生的事件。

## 前文摘要机制

80万字+无法全量传上下文，使用分层摘要压缩历史信息。

**摘要层级**：

| 层级 | 范围 | 字数 | 更新频率 |
|------|------|------|----------|
| 卷摘要 | 每卷 | 500-800字 | 每卷结束时 |
| 阶段摘要 | 每10章 | 300-500字 | 每10章 |
| 近章详摘 | 最近3章 | 每章200-300字 | 每章 |

**写作时的上下文组装**：
1. 所有已完成卷的卷摘要（如已写5卷，约2500-4000字）
2. 当前卷的阶段摘要（如当前在第3个10章段，约600-1000字）
3. 最近3章的详细摘要（约600-900字）
4. 当前章节细纲
5. 出场角色的状态快照
6. 相关设定圣经分区

总上下文约5000-8000字，可控制token消耗在合理范围。

**摘要写作要求**：
- 只记录影响后续的关键信息：角色关系变化、新设定引入、伏笔埋设/回收、能力变化、重要道具
- 不记录临时性细节（如某次无关紧要的对话）
- 标注未解决的悬念和待回收伏笔

## 审查频率

| 审查类型 | 频率 | 执行者 | 内容 |
|----------|------|--------|------|
| 逐章审查 | 每章定稿后 | 连续性审核员 | 设定一致性、角色状态、伏笔、时间线 |
| 阶段审查 | 每5章 | 连续性审核员 + 总编 | 节奏检查、剧情线进展、角色弧光推进 |
| 卷末审查 | 每卷结束 | 全团队 | 伏笔审计、剧情线盘点、设定圣经更新、角色弧光检验 |
| 全书终审 | 完稿后 | 全团队 | 全书连贯性扫描、节奏曲线、伏笔100%回收确认 |

**卷末审查清单**：
- [ ] 所有短线伏笔已回收
- [ ] 所有中线伏笔已回收或有明确下卷回收计划
- [ ] 长线伏笔至少触碰过一次
- [ ] 角色状态表与正文一致
- [ ] 时间线无矛盾
- [ ] 活跃剧情线不超过5条
- [ ] 设定圣经已更新所有新引入的设定
- [ ] 卷摘要已撰写
