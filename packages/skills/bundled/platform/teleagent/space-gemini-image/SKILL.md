# AI图像生成

当用户表达画图意图时（如"画一个..."、"生成图片..."、"帮我创作..."、"AI作画"），使用此技能。

## 两种生成模式

| 模式 | 适用场景 | 调用工具 |
|------|---------|---------|
| **文生图** | 从文字描述生成图片 | `ImageGen` |
| **图生图** | 基于参考图生成新图（风格迁移/局部编辑/背景替换） | `ImageGenWithRef` |

---

## 工作流程

### Step 1：确认生成模式

根据用户输入判断模式：

| 用户说 | 推断模式 |
|--------|----------|
| "画一个..." / "生成图片..." / "帮我画..." | 文生图 |
| "参考这张图..." / "基于这个风格..." / "改一下这张图..." | 图生图 |
| 用户提供了参考图片 | 图生图 |
| 模糊 | 询问用户选择 |

### Step 2：构造提示词

提示词构造规则：

| 模式 | 提示词格式 | 示例 |
|------|-----------|------|
| 文生图 | 直接描述文字 | `一只可爱的橘猫坐在窗台上，阳光洒落，水彩风格` |
| 图生图 | 参考图 + 编辑指令 | 参考图路径 + `将背景替换为星空夜景` |

**提示词优化建议**：
- 描述具体，避免抽象模糊
- 包含风格描述（如"水彩风格"、"极简设计"、"赛博朋克"）
- 中文内容可直接使用，提示词支持中英文
- 如需图中出现中文文字，在提示词中明确写出

### Step 3：选择尺寸（可选）

| 需求 | 推荐尺寸 | 像素值 |
|------|---------|--------|
| 通用（默认） | 2K | 2048x2048 |
| 高清 | 3K | 3072x3072 |
| 超清 | 4K | 4096x4096 |
| 横版 16:9 | 自定义 | 2048x1152 |
| 竖版 3:4 | 自定义 | 1536x2048 |
| 方形 | 自定义 | 2048x2048 |

> 尺寸规则：总像素范围 [3686400, 16777216]，宽高比范围 [1/16, 16]。不符合规则的尺寸会被拦截。

### Step 4：调用工具生成图片

#### 文生图 — ImageGen

调用参数：

| 参数 | 必填 | 说明 |
|------|------|------|
| `prompt` | 是 | 图片描述文本，支持中英文 |
| `size` | 否 | 支持 2K/3K/4K 或 宽x高 像素值，默认 2048x2048 |
| `guidance_scale` | 否 | 提示词遵循程度，1-10，值越大越贴合描述 |
| `seed` | 否 | 随机种子，-1 为随机，固定值可复现 |
| `n` | 否 | 生成数量，1-4 张，默认 1 |

示例调用流程：
```
1. 用户："画一只橘猫"
2. 构造 prompt："一只可爱的橘猫坐在窗台上，阳光温暖，水彩插画风格"
3. 调用 ImageGen(prompt="...", size="2K")
4. 获取生成结果，展示给用户
```

#### 图生图 — ImageGenWithRef

调用参数：

| 参数 | 必填 | 说明 |
|------|------|------|
| `image` | 是 | 参考图（本地路径 / URL / base64） |
| `prompt` | 是 | 编辑指令，描述如何修改参考图 |
| `size` | 否 | 输出尺寸，默认由服务端处理 |
| `guidance_scale` | 否 | 提示词遵循程度，1-10 |
| `seed` | 否 | 随机种子，-1 为随机 |

示例调用流程：
```
1. 用户："参考这张图，换成夜景风格"
2. 获取用户参考图路径
3. 构造 prompt："将背景替换为星空夜景，保持主体不变"
4. 调用 ImageGenWithRef(image="参考图路径", prompt="...")
5. 获取生成结果，展示给用户
```

### Step 5：保存与展示

**保存路径规范**：

```
{工作目录}/space-gemini-image/{YYYY-MM-DD}/{HHMMSS}-{描述简称}.png
```

示例：`C:\Users\Administrator\.local\share\TeleAgent\TeleAgent的工作空间\space-gemini-image\2026-07-28\143052-橘猫窗台.png`

**生成结果展示**：
- 展示图片给用户
- 告知保存路径
- 如需调整，可修改 prompt 后重新生成

## 常见用法

| 用户说 | 操作 |
|--------|------|
| "画一只猫" | 文生图，自动构造提示词并生成 |
| "生成一张赛博朋克城市" | 文生图，指定风格 |
| "参考这张图改背景" | 图生图，使用 ImageGenWithRef |
| "生成4张不同风格的猫" | 文生图，n=4 |
| "再画一张类似的" | 图生图，以上一张作为参考图 |
| "换成暖色调" | 图生图，编辑指令调整色调 |

---

## 注意事项

- 图片生成通常需要 10-30 秒
- 提示词越具体，生成效果越好
- 图生图需要提供参考图路径，支持本地文件和 URL
- 一次最多生成 4 张图（n 参数）
- 固定 seed 值可复现相同结果
- 涉及敏感人物时，使用风格化替代而非真人描述
