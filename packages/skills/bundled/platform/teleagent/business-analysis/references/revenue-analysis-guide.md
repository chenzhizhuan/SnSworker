# 收入分析指南 (Revenue Analysis Guide)

## 收入拆解的三个维度

### 维度一：量价结构分解

```
收入变化 = 销量变化贡献 + 价格变化贡献 + 产品结构变化贡献

销量贡献 = (本期销量 - 上期销量) × 上期均价
价格贡献 = (本期均价 - 上期均价) × 本期销量
结构贡献 = 总收入变化 - 销量贡献 - 价格贡献（残差）
```

**解读规则：**
- 量涨价稳 → 市场需求驱动，可持续性强
- 价涨量跌 → 涨价策略，需关注市场份额
- 量价双涨 → 最优状态，需判断可持续性
- 量涨价跌 → 促销驱动，注意利润侵蚀

### 维度二：产品/SKU 分解

按贡献度排序：
```
收入增量 = Σ(各产品销量变化 × 价格 + 各产品价格变化 × 销量)
```

关键问题：
- 哪个产品贡献了最大增量？为什么？
- 哪个产品下滑了？原因是什么？
- 高毛利产品占比在提升还是下降？

### 维度三：客户/渠道 分解

| 分析维度 | 关键指标 | 预警阈值 |
|---------|---------|---------|
| 新客收入 | 新客数量、首购金额 | 新客占比<10% → 增长乏力 |
| 老客收入 | 复购率、客单价变化 | 复购率下降>5% → 客户流失风险 |
| 渠道结构 | 各渠道占比变化 | 单渠道占比>60% → 依赖风险 |
| 大客户依赖 | TOP5客户收入占比 | >50% → 集中度风险 |

## 收入分析的追问链

```
收入变化了XX%
  ↓ 追问：量变还是价变？
    ↓ 如果是量变：哪个产品/渠道？为什么？
      ↓ 是市场扩大还是竞争对手失守？
        ↓ 是趋势性的还是一次性的？
    ↓ 如果是价变：主动调价还是促销？
      ↓ 对毛利率的影响？
        ↓ 客户接受度如何？
```

## 常见收入异常及归因

| 现象 | 可能原因（由高到低概率） | 验证方式 |
|------|----------------------|---------|
| 收入突增 | ①大单/批量采购 ②促销 ③新客户开发 ④季节性 | 查订单明细 |
| 收入突降 | ①大客户流失 ②竞争加剧 ③产品问题 ④季节性 | 查客户明细 |
| 收入平稳但毛利下降 | ①产品结构变化 ②成本上涨转嫁不足 ③促销增加 | 查产品构成 |
| 收入增长但现金减少 | ①应收账款增加 ②回款周期延长 ③垫资增加 | 查应收账款 |

## 收入预测方法

### 方法一：趋势外推法（适用稳定业务）
```
下月预测收入 = 过去3月平均 × 季节指数 × 趋势系数
季节指数 = 往年同期 / 往年全年平均
```

### 方法二：驱动因素法（适用波动业务）
```
预测收入 = 预测客户数 × 预测转化率 × 预测客单价
```

### 方法三：Pipeline法（适用项目制业务）
```
预测收入 = Σ(在谈项目金额 × 赢单概率)
```
