# 决策支持报告模板 (Decision Support Template)

## 决策支持的核心原则

> **老板要的是选择题，不是问答题。**
> 给选项 + 给利弊 + 给推荐 + 给支撑数据

## 决策建议的结构（SCQA框架）

```
S（Situation）：背景情况 — 现在发生了什么？
C（Complication）：冲突/问题 — 由此带来了什么挑战？
Q（Question）：核心问题 — 我们需要决策什么？
A（Answer）：答案/建议 — 我的建议是什么？
```

**示例：**
- S：5月收入低于预期10%，但往年6-7月季节性旺季收入会高出20%
- C：备货需要资金和仓储，但万一旺季不来，将面临库存积压损失
- Q：是否应该提前备货？备多少？
- A：建议按往年的70%备货，分两批采购以降低风险，具体方案如下

## 决策选项分析框架

### 三选项法（给老板真正的选择）

| 维度 | 方案A（保守） | 方案B（推荐） | 方案C（激进） |
|------|------------|------------|------------|
| 核心动作 | [描述] | [描述] | [描述] |
| 预期收益 | [金额/概率] | [金额/概率] | [金额/概率] |
| 潜在风险 | [金额/概率] | [金额/概率] | [金额/概率] |
| 所需资源 | [资金/人力/时间] | [资金/人力/时间] | [资金/人力/时间] |
| 执行难度 | 低 | 中 | 高 |
| 推荐理由 | — | [核心理由] | — |

## 常见决策场景模板

### 场景一：备货决策

```markdown
**决策背景：**
基于季节性规律，预测[月份]需求将比当前高XX%，
历史数据显示这一预测的准确率为XX%。

**关键约束：**
- 可用资金：XX万元
- 现有仓储容量：XX吨/件，当前使用率XX%
- 供应商最长备货周期：X周

**方案比较：**

| | 不备货 | 按50%预期备货（推荐） | 按100%预期备货 |
|---|---|---|---|
| 若旺季来临 | 断货损失≈XX万 | 正常销售 | 最大化收益 |
| 若旺季不来 | 无风险 | 库存增加≈XX万，可降价处理 | 库存积压≈XX万，损失较大 |
| 资金占用 | 0 | XX万 | XX万 |

**建议：** 按50%预期量备货，分两批采购（第一批XX万，旺季开始前2周视实际情况补第二批）

**所需行动：**
1. [部门]在[时间]前完成采购订单
2. [部门]在[时间]前确认仓储安排
3. [部门]在[时间]前落实资金来源
```

### 场景二：成本上涨应对决策

```markdown
**问题：** [原材料/人工/运费]成本上涨XX%，预计影响毛利率下降XX个百分点。

**可选方案：**

| 方案 | 涨价转嫁 | 内部消化 | 产品结构调整 |
|------|---------|---------|------------|
| 毛利保护 | 完全保护 | 全部承担 | 部分保护 |
| 客户风险 | 可能流失XX% | 无 | 低 |
| 竞争影响 | 看竞争对手跟进 | 竞争优势短期增加 | 结构优化长期有利 |
| 执行周期 | 1-2个月 | 立即 | 3-6个月 |

**财务测算：**
- 方案A（涨价XX%）：毛利率恢复至XX%，但预计销量下降XX%，净影响：±XX万
- 方案B（内部消化）：毛利率降至XX%，年化影响：-XX万
- 方案C（调结构）：半年过渡期内损失XX万，之后毛利率提升至XX%

**建议：** [方案]，理由：[说明]
```

### 场景三：信用风险管理决策

```markdown
**风险描述：**
客户[名称]，当前应收账款XX万元，回款周期已从XX天延长至XX天，
延长原因：[销售反馈]。

**风险评估：**
- 历史合作情况：XX年，累计交易额XX万，无坏账记录
- 当前风险等级：YELLOW / RED
- 坏账概率估算：XX%
- 潜在损失金额：XX万元

**可选方案：**

| 方案 | 继续正常发货 | 暂停发货/控量 | 全面暂停+法律手段 |
|------|------------|------------|----------------|
| 收入影响 | 本月+XX万 | 本月-XX万 | 本月-XX万 |
| 风险控制 | 风险继续累积 | 损失可控 | 止损但关系破裂 |
| 客户关系 | 维持 | 可能受损 | 终止 |

**建议：** [方案]，并要求销售在[时间]前完成对客户资金状况的核实。
若[条件]，则升级为RED并启动法律程序。
```

## 决策报告质量检查清单

在提交决策建议前，自检以下项目：

- [ ] 结论是否放在最前面？
- [ ] 是否给出了至少2个可选方案（而不是只有一个）？
- [ ] 每个方案是否有量化的收益和风险？
- [ ] 是否说清楚了建议方案的核心理由？
- [ ] 所需的行动是否具体到人、部门、时间？
- [ ] 是否考虑了"如果方案失败"的应急预案？
- [ ] 数据来源是否可信，是否需要标注？

## 建议措辞规范

**避免：**
- "需要加强销售力度" → 太模糊
- "存在一定风险" → 没有量化
- "建议相关部门关注" → 没有指定责任人

**应该：**
- "建议销售团队在本月内新增拜访X家目标客户，重点跟进[客户名]，目标签约XX万"
- "预计库存积压风险敞口约XX万元，若6月底前未清库，需计提跌价准备约XX万"
- "建议由[姓名/岗位]牵头，在[日期]前完成[具体任务]，并在[日期]向管理层汇报进展"
