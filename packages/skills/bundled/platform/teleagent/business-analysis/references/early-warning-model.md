# 预测预警模型 (Early Warning Model)

## 预警体系架构

### 三类预警信号

```
┌─────────────────────────────────────────────────────┐
│  RED（立即行动）：已发生或高概率发生的重大风险        │
│  YELLOW（密切跟踪）：趋势异常，需要监控              │
│  GREEN（定期回顾）：正常范围，但需持续观察            │
└─────────────────────────────────────────────────────┘
```

## 核心预警指标体系

### 收入侧预警

| 指标 | 预警条件 | 级别 | 含义 | 建议动作 |
|------|---------|------|------|---------|
| 收入完成率 | <80% | RED | 严重偏离目标 | 立即启动销售专题 |
| 收入完成率 | 80%-90% | YELLOW | 偏低，需追赶 | 要求销售说明并制定方案 |
| 订单增速 | 连续2月下滑 | YELLOW | 未来收入风险 | 提前预警，找原因 |
| 新客占比 | <10% | YELLOW | 增长动力不足 | 关注获客策略 |
| TOP客户集中度 | >60% | YELLOW | 客户依赖风险 | 客户分散化建议 |
| 大客户回款异常 | 延期>30天 | RED | 信用/关系风险 | 通知销售和法务 |

### 利润侧预警

| 指标 | 预警条件 | 级别 | 含义 | 建议动作 |
|------|---------|------|------|---------|
| 毛利率 | 同比降>3个百分点 | RED | 盈利能力恶化 | 立即拆解原因 |
| 净利润 | 同比降>20% | RED | 整体经营恶化 | 专题分析会议 |
| 费用率 | 同比升>3个百分点 | YELLOW | 费用管控失效 | 追查科目 |
| 某费用科目 | 同比增>30% | YELLOW | 异常支出 | 核实真实性 |

### 现金流侧预警

| 指标 | 预警条件 | 级别 | 含义 | 建议动作 |
|------|---------|------|------|---------|
| 应收账款周转天数 | 连续2月增加 | YELLOW | 回款风险上升 | 催款+控制发货 |
| 应收账款周转天数 | 超过行业均值50% | RED | 坏账风险高 | 启动信用评审 |
| 库存周转天数 | 连续2月增加 | YELLOW | 产品滞销 | 排查滞销品 |
| 库存周转天数 | 超过行业均值70% | RED | 大量积压 | 库存处理方案 |
| 经营性现金流 | 持续净流出>3月 | RED | 现金危机前兆 | 融资/压缩开支 |

### 运营侧预警

| 指标 | 预警条件 | 级别 | 含义 | 建议动作 |
|------|---------|------|------|---------|
| 客户投诉率 | 环比增>50% | YELLOW | 产品/服务问题 | 通知相关部门 |
| 订单取消率 | >5% | YELLOW | 客户满意度下降 | 原因调查 |
| 发货及时率 | <95% | YELLOW | 供应链问题 | 排查瓶颈 |
| 供应商交货周期 | 延长>1周 | YELLOW | 供应风险 | 备货/找替代 |

## 趋势预测方法

### 方法一：季节调整趋势法

```python
# 概念公式（非代码）
季节指数 = 往年同期值 / 往年全年月均值
趋势系数 = 近3月环比平均增速
下月预测 = 上月实际 × (1 + 趋势系数) × 季节调整
```

**应用场景：** 消费品、零售、旅游等季节性明显行业

### 方法二：关键驱动因素领先指标法

找到领先于收入/利润变化的先行指标：

| 行业 | 领先指标（提前1-3月） | 与收入相关性 |
|------|---------------------|------------|
| 制造业 | 新订单量、PMI | 高 |
| 消费品 | 门店客流、APP活跃用户 | 高 |
| 服务业 | 预约量、Pipeline金额 | 高 |
| 地产 | 土地成交量、按揭申请 | 高 |

**操作：** 建立领先指标与收入的回归模型，用领先指标预测收入

### 方法三：客户生命周期预测法

```
未来12月预期收入 = 
  现有客户留存 × 平均客单价 × 留存率
  + 预期新客数 × 新客平均首购金额
  + 流失预警客户 × (1 - 流失概率) × 客单价
```

```markdown
   - 已发生/预计发生时间：XX
   - 影响金额估算：±XX万元
   - 建议动作：[具体行动][责任人][截止时间]

1. **[指标名称]** 当前趋势：[描述]

```

## 预警跟踪机制

1. **每日监控**：现金余额、回款、大额异常
2. **每周检视**：订单量、发货量、回款率
3. **每月报告**：完整五层级分析
4. **季度复盘**：预测准确率回顾，修正模型

## 连锁效应预警矩阵

当发现某个信号时，需同步检查：

```
收入下滑 → 检查：现金流、库存积压、销售团队士气
毛利下降 → 检查：成本结构、产品结构、定价策略
应收延长 → 检查：客户信用、合同条款、法律风险
库存增加 → 检查：生产节奏、销售预测、滞销处理
```
