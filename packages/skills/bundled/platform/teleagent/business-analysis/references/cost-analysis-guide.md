# 成本与费用分析指南 (Cost & Expense Analysis Guide)

## 成本分析框架

### 成本变化拆解公式

```
成本变化 = 价格效应 + 用量效应 + 结构效应

价格效应 = (本期单价 - 上期单价) × 本期用量
用量效应 = (本期用量 - 上期用量) × 上期单价
结构效应 = 残差（产品结构变化带来的成本差异）
```

### 成本分析四象限

| | 成本↑ | 成本↓ |
|---|---|---|
| **收入↑** | 需看毛利率，警惕成本增速>收入增速 | 最优：规模效应显现 |
| **收入↓** | 最差：需立即诊断 | 收入↓成本跟不上，固定成本占比高 |

## 成本科目拆解

### 原材料成本
```
原材料成本变化 = 采购价格变化 × 用量 + 用量变化 × 价格 + 损耗率变化
```

追问清单：
- 大宗原材料价格走势如何？（查期货/市场价）
- 供应商是否调价？原因是什么？
- 单耗是否有异常？（本期单耗 vs 历史）
- 有没有更换原材料配方/工艺？

### 人工成本
```
人工成本 = 人员数量 × 人均工资 + 加班费 + 福利
```

追问清单：
- 是否有新增人员？什么岗位？为什么？
- 加班费异常？是赶工还是排班问题？
- 人均产出是否提升？（收入或产量/人数）

### 制造费用
- 折旧：是否新增设备？是否有一次性处置？
- 水电：是否产能利用率变化？
- 维修：是否大修周期？是否设备老化？

## 费用分析框架

### 费用性质区分

| 费用类型 | 特征 | 分析重点 |
|---------|------|---------|
| 固定费用 | 与收入无关（折旧、固定工资、租金） | 关注总额变化，是否有新增 |
| 变动费用 | 随收入/业务量变化（提成、运费） | 关注费用率（费用/收入） |
| 半变动费用 | 阶梯式变化（人员、营销） | 关注边际效益 |
| 一次性费用 | 非经常性（重组、搬迁） | 需单独披露，排除干扰 |

### 关键费用率指标

```
销售费用率 = 销售费用 / 收入 × 100%  → 行业均值比较
管理费用率 = 管理费用 / 收入 × 100%  → 规模效应体现
研发费用率 = 研发费用 / 收入 × 100%  → 创新投入强度
```

**预警阈值（参考）：**
- 销售费用率同比上升>3个百分点 → 营销效率下降，需追问ROI
- 管理费用率持续上升 → 组织效率问题，需追问
- 某科目同比>20% → 必须有合理解释

### 费用分析追问链

```
费用涨了XX%
  ↓ 是哪个科目涨的最多？
    ↓ 该科目涨是因为业务量增长（合理）还是效率下降（需关注）？
      ↓ 是一次性还是持续性？
        ↓ 是否有对应的收入/利润增长？（ROI分析）
          ↓ 下期是否还会持续？
```

## 毛利率变动分析（量价成本综合）

```
毛利率变化 = 价格影响 + 成本影响 + 结构影响

价格影响 = (本期售价 - 上期售价) / 上期收入
成本影响 = -(本期单位成本 - 上期单位成本) × 本期销量 / 本期收入
结构影响 = 高毛利产品占比变化的影响
```

## 成本预警信号

| 预警信号 | 可能含义 | 建议动作 |
|---------|---------|---------|
| 成本增速 > 收入增速 | 规模效应失效，或成本失控 | 立即排查各科目 |
| 单位成本连续上升3个月 | 成本结构性恶化 | 工艺/供应商审查 |
| 废品率/损耗率上升 | 质量/工艺问题 | 通知生产/质量部门 |
| 库存跌价准备增加 | 产品滞销风险 | 排查滞销品，制定处理方案 |
