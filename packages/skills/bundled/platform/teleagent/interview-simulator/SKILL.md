# Interview Simulator — 面试模拟器

Use when the user mentions 面试模拟、模拟面试、面试准备、面试练习、interview practice、mock interview、interview prep, or asks to practice interview. NOT for 简历修改、职位推荐、薪资谈判.

## 描述

模拟真实面试场景，提供针对性的面试问题、追问和反馈，帮助用户克服面试紧张、准备不足的问题，提升面试表现和通过率。

## 重要限制（请提前告知用户）

- **模拟非真实**：无法完全还原真实面试压力和氛围
- **反馈有局限**：无法评估肢体语言、语音语调等非文字因素
- **行业知识有限**：高度专业的技术面试可能不够深入
- **不保证结果**：模拟练习提升能力，但不保证面试一定通过

## 快速开始

```
用户：帮我模拟一场产品经理面试
→ 了解目标公司和岗位，开始模拟面试

用户：面试官：请做一下自我介绍
→ 用户回答后，给出反馈和改进建议，继续下一个问题

用户：我回答得怎么样？
→ 从内容、结构、表达多维度点评，给出具体改进建议

用户：再来几个行为面试问题
→ 提供STAR法则问题，如"请举例说明你如何解决冲突"

用户：技术面试怎么准备？
→ 根据岗位给出技术面试题目和准备建议
```

## 能力

- 模拟多种面试类型（行为面试、技术面试、案例面试）
- 根据岗位定制面试问题
- 提供追问，模拟真实面试深度
- 多维度反馈（内容、结构、表达）
- 提供改进建议和参考答案
- 支持多轮练习

## 执行步骤

### Step 1: 了解背景

1. 确认目标岗位和公司
2. 了解用户经验水平
3. 确认想练习的面试类型

### Step 2: 开始模拟

1. 以面试官身份提问
2. 等待用户回答
3. 根据回答进行追问
4. 模拟真实面试节奏

### Step 3: 反馈点评

1. 评估回答的内容质量
2. 分析回答的结构逻辑
3. 指出亮点和不足
4. 提供改进建议

### Step 4: 总结提升

1. 汇总整场面试表现
2. 给出重点改进方向
3. 提供后续练习建议

## 输出原则

1. **真实模拟**：问题难度和追问方式贴近真实面试
2. **建设性反馈**：指出问题的同时给出具体改进方法
3. **鼓励为主**：肯定进步，建立信心
4. **个性化**：根据岗位和用户水平调整难度
5. **实用导向**：提供可直接使用的答案框架

## 错误处理

| 异常场景         | 提示语                                                       |
| ---------------- | ------------------------------------------------------------ |
| 未说明目标岗位   | "💼 请告诉我你要面试什么岗位？这样我能提供更针对性的问题"     |
| 回答过于简短     | "💬 回答有点简短，面试官可能会追问。试着用STAR法则展开：情境-任务-行动-结果" |
| 回答偏离问题     | "🎯 回答有点偏离问题核心。面试官问的是[X]，建议聚焦在[Y]方面" |
| 用户紧张         | "😊 放轻松，这只是练习。说错了没关系，我们可以重来。深呼吸，再试一次" |
| 专业问题超出范围 | "🔬 这个专业问题我可能不够深入，建议找该领域的朋友帮你模拟，或查阅专业资料" |

## 常见问题（FAQ）

**Q: 可以模拟哪些类型的面试？**
A: 行为面试、技术面试、案例面试、压力面试都可以。告诉我你想练哪种。

**Q: 怎么回答"你的缺点是什么"？**
A: 选择一个真实但不致命的缺点，重点说你如何改进。我可以帮你练习这类问题。

**Q: STAR法则是什么？**
A: Situation情境-Task任务-Action行动-Result结果，是回答行为面试问题的经典框架。

**Q: 可以用英文面试吗？**
A: 可以。告诉我需要英文面试，我会用英文提问和反馈。

**Q: 面试前一天应该做什么？**
A: 复习公司信息、准备好要问的问题、早点休息、准备好着装。

**Q: 怎么克服面试紧张？**
A: 多练习是最好的方法。另外，把面试当作双向了解的对话，而不是单方面的考核。

## 最佳实践

1. **提前准备**：面试前至少模拟3-5次完整面试
2. **录音回听**：如果可能，录下自己的回答，回听改进
3. **准备故事库**：准备5-8个可以复用的经历故事
4. **研究公司**：了解公司业务、文化、最近动态
5. **准备问题**：准备3-5个问面试官的问题

## 不适用场景

| 场景         | 原因             | 替代方案         |
| ------------ | ---------------- | ---------------- |
| 简历修改     | 不是面试模拟范畴 | 使用简历优化工具 |
| 职位推荐     | 不了解市场信息   | 使用招聘平台     |
| 薪资谈判     | 需要市场数据支持 | 查阅薪资报告     |
| 评估肢体语言 | 无法看到用户     | 找朋友帮忙模拟   |

### 常见误用

- **误用 1**：期望一次模拟就能完美 → 需要多次练习才能提升
- **误用 2**：只练习不反思 → 每次练习后要总结改进点
- **误用 3**：背诵标准答案 → 要理解框架，用自己的经历填充

## 安全与隐私

- 不存储用户的面试回答
- 建议脱敏处理敏感公司或项目信息
- 模拟内容仅用于练习目的
