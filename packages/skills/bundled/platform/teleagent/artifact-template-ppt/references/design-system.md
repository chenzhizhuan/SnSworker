# 电信红白高密度视觉系统

## 1. Overall character

Create a formal China Telecom internal-report feel:

- red and white as the primary presentation language;
- authentic China Telecom blue as the brand anchor;
- restrained gold as a secondary emphasis color;
- white canvas, flat information blocks, compact typography;
- visible information hierarchy and evidence density;
- no decorative spectacle competing with the content.

The style should feel calm, credible, practical, and suitable for leadership review.

## 2. Canvas and grid

- Canvas: 16:9, preferably 1280 × 720.
- Main content margins: 28–34 px left and right.
- Header band: approximately 12–76 px.
- Lead/tag band: approximately 87–125 px.
- Main body: approximately 145–653 px.
- Footer page number: lower right, aligned consistently.
- Use two or three major content zones per page. Avoid fragmented micro-cards.
- Keep related items aligned to common edges and consistent gaps.

When possible, clone a reference slide instead of recreating these coordinates.

## 3. Brand palette

Use the retained reference theme first. The following values are the working fallback:

| Role | Color |
|---|---|
| Primary red | `#C00000` |
| Dark red | `#A80000` |
| China Telecom blue | `#0B5A9C` |
| Accent gold | `#F2B705` |
| Main text | `#171717` |
| Muted text | `#5D6470` |
| Warm panel | `#F7F4F0` |
| Light red panel | `#FFF5F5` |
| Light blue panel | `#F2F7FB` |
| Divider | `#D7D7D7` |

Do not introduce extra accent colors unless a source chart requires them.

## 4. Header system

Content slides use a consistent header:

- authentic China Telecom logo at upper left;
- page number followed by a direct red title;
- thin red horizontal rule beneath the title;
- short gold segment overlaying the rule;
- optional four-character tag in a red right-arrow shape;
- one concise lead sentence aligned to the tag;
- page number repeated subtly at lower right.

Reference geometry:

- logo: left 28, top 12, width 158, height 58;
- title: left 205, top 12, width about 1010, height 50;
- red rule: left 28, top 72, width 1224, height 4;
- gold rule: left 520, top 72, width 330, height 4;
- tag: left 34, top 88, width 136, height 32;
- lead: left 186, top 87, width about 1030, height 36.

Keep the title on one line.

## 5. Typography

Use Microsoft YaHei / 微软雅黑 when available. Preserve the reference font when editing the retained deck.

| Text role | Typical size |
|---|---|
| Cover title | 42–46 |
| Cover subtitle | 24–28 |
| Content title | 25–28 |
| Page lead | 17–18 |
| Section arrow label | 16–17 |
| Body | 16–18 |
| Metric value | 26–30 |
| Image caption | 14–15 |
| Footer/page number | 12 |

Use bold for titles, section labels, and key numbers. Avoid bolding full paragraphs.

## 6. Information blocks

- Use warm-gray or pale-red flat blocks.
- Use red arrow labels for the main structural sections.
- Use gold arrow labels for conclusions, changes, experience, or secondary emphasis.
- Use pale-blue framed statements for safety principles or standards.
- Keep borders thin and shadows absent.
- Use rounded rectangles only for short process steps or clearly bounded metrics.
- Do not turn every sentence into a card.

## 7. Image system

Treat images as evidence.

- Personal/profile page: one strong horizontal real photo.
- Project page: one main screenshot plus zero to two supporting screenshots or site photos.
- Safety page: two or three evidence images, such as exercise, duty, report, or test result.
- Team page: one large real team photo.
- Training page: three or four equal modules for training, co-creation, coding, and safety practice.

For user-replaceable frames:

- use a pale gray fill;
- use a thin neutral border;
- add a narrow red accent on the left;
- label the intended evidence, such as “异常定位截图” or “项目调试现场”;
- keep the frame editable and easy to cover or replace.

Do not use generated images as evidence.

## 8. Cover and closing

Cover:

- keep the logo at upper left;
- center one strong title, a short subtitle, and presenter/company;
- use the retained red-gold wave only at the bottom;
- do not add people, city skylines, stars, wheat, or busy backgrounds.

Closing:

- resolve the opening message in two or three lines;
- connect personal or project work to team capability and high-quality development;
- use one natural closing line, not a generic full-page “谢谢”.

## 9. Density control

Aim for high-value density, not maximum word count.

- Use 2–4 metrics when results are important.
- Use 3–5 bullets per block.
- Use captions to identify evidence, not to repeat the title.
- Remove duplicated claims across the title, lead, body, and conclusion.
- Enlarge useful text or add verified evidence when a page feels empty.
- Split the page only when its primary claim becomes ambiguous.
