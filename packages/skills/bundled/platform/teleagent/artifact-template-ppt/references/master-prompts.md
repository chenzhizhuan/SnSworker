# 可复用提示词

## Full production prompt

Copy the following prompt to another agent and replace the bracketed fields.

```text
请基于我提供的材料制作一份电信红白高密度汇报PPT。

【任务信息】
- 汇报主题：{{主题}}
- 汇报对象：{{领导/评审/客户/内部同事}}
- 汇报目的：{{让听众理解、认可、审批或采取什么行动}}
- 汇报时长：{{分钟}}
- 建议页数：{{页数；不确定时由你根据时长判断}}
- 汇报人及单位：{{姓名、部门、公司}}
- 输出语言：中文

【输入材料】
{{列出PPTX、DOCX、PDF、XLSX、图片、截图和其他路径}}

【必须覆盖】
{{客户明确要求回答的问题、章节或内容；没有固定必选项}}

【必须避免】
{{不应出现的词、图形、主题、敏感信息、夸张表达等}}

【图片情况】
- 已有真实图片：{{路径或说明}}
- 需要保留图片位：{{页面和建议图片类型}}
- 不允许生成或伪造的证据：系统截图、证书、官方Logo、项目现场、测试报告。

请严格执行以下要求：

1. 先完整读取所有材料，建立事实清单。项目名称、日期、数量、时长、比例、荣誉、岗位和结果必须有来源；材料冲突时标记并采用最可靠版本，不得补造数据。
2. 用一句话定义本次汇报的传播任务，再建立逐页内容表：页码、直接标题、页面任务、事实证据、版式来源、图片计划、讲稿作用。
3. 内容结构完全服从客户需求。不要机械套"背景—方案—成效"或参考PPT原有章节顺序；可根据任务选择问答、时间线、现状复盘、方案比较、决策建议、产品模块、流程机制、案例集合、人物事迹、培训教学等结构。客户没有要求的章节不要自动添加。
4. 使用 assets/reference.pptx 作为视觉参考。分析其布局坐标和配色，用 pptxgenjs 按照 references/design-system.md 的规格复现风格。按照当前内容选择最合适的参考页，不要所有页面套同一种布局，也不要照抄参考内容。
5. 风格保持红白简约、文字紧凑、证据优先：
   - 中国电信Logo统一放左上；
   - 内容页通常保留红色标题、红金分隔线和短标签结构；标签文字按客户内容填写，可为4—6字，不强行使用固定关键词；
   - 白底、暖灰信息块、少量蓝色和金色强调；
   - 不使用星星、麦穗、城市剪影、军人剪影、动漫人物、花哨科技背景或无意义装饰。
6. 每个内容页标题必须"可识别的项目、产品、主题、决策或模块名称在前，本页要点、结果、问题或比较在后"，让人不读正文也知道本页讲什么。标题必须保持单行。
7. 每页只承担一个主要传播任务，但内部逻辑按客户问题选择，不强制固定顺序。
8. 图片数量按内容决定：个人页通常1张主图，项目或专题页可放1—3张证据图，多主题展示页可放3—4个模块。没有图片时按技能规范留可编辑图片位，不要为凑数量重复图片。
9. 不要为了填满页面堆低价值文字，也不要出现大片留白配小字号。优先增加与客户问题有关、且已验证的事实、指标、截图、比较、过程或感受。
10. 只有工匠或先进典型材料需要时，才使用"务实求效、精研求新、迎难攻坚、示范带动、薪火相传"等近义四字词对应事实；其他汇报不要强行套这些词。
11. 讲稿备注贴近原始材料和客户场景。人物汇报可用自然第一人称；产品、方案、决策或培训材料按适合的口吻写。避免"今天我想交流的不是……而是……"等AI腔。
12. 使用 pptxgenjs（Node.js）生成PPT。参照 references/design-system.md 中的坐标和色值精确还原视觉系统。
13. 完成后逐页全尺寸渲染检查，修复标题折行、文字越界、图片裁切、元素重叠、Logo不一致、空结构占位符和页码问题。
14. 输出一个新的可编辑PPTX，不覆盖原文件。最终只交付确认通过检查的版本。

不要先停下来询问普通版式细节；材料足够时直接按上述规范完成。只有会实质改变内容结论、涉及无法判断的敏感信息或需要新增外部授权时再提问。
```

## Compact prompt

```text
把以下材料整理成一份电信红白高密度汇报PPT：{{材料路径}}。

要求：内容结构根据客户目标和材料重新组织，不机械套"背景—方案—成效"，也不照抄参考PPT的章节；完整核对事实；可识别主题放在标题最前，标题后接本页要点；一页一个主要传播任务；红白简约、文字紧凑、真实数据和截图优先；按内容选用不同参考页；Logo统一左上；没有图片时保留可编辑图片位；不使用星星、麦穗、城市剪影、动漫人物和花哨背景；讲稿自然、贴近原文；逐页渲染检查后交付新的可编辑PPTX。使用 pptxgenjs 生成，参照技能的 design-system.md 还原视觉系统。
```

## Title-only refinement prompt

```text
检查这份PPT的所有内容页标题。将标题改成"可识别的项目、产品、主题、决策或模块名称在前，本页要点、结果、问题或比较在后"的单行标题；只使用材料中已验证的名称和数据；保留下方短标签与页面结构；不要改变正文、图片和讲稿，除非标题调整导致版式冲突。完成后逐页渲染检查并另存新版本。
```
