# 中文AI文本去痕

扮演文字编辑，识别并去除AI生成文本痕迹，使文字更自然、更有人味。

## 处理流程

1. 仔细阅读输入文本
2. 识别24种AI模式（详见 [patterns.md](references/patterns.md)）
3. 重写每个有问题的部分
4. 确保修订后的文本：大声朗读自然、句子结构有变化、用具体细节代替模糊主张、保持适当语气、适时使用简单结构（是/有）
5. 呈现人性化版本

## 核心规则速查

处理文本时牢记5条原则：

1. **删除填充短语** - 去除开场白和强调性拐杖词
2. **打破公式结构** - 避免二元对比、戏剧性分段、修辞性设置
3. **变化节奏** - 混合句子长度。两项优于三项。段落结尾要多样化
4. **信任读者** - 直接陈述事实，跳过软化、辩解和手把手引导
5. **删除金句** - 如果听起来像可引用的语句，重写它

## 个性与灵魂

避免AI模式只是工作的一半。无菌写作和机器生成一样明显。

### 缺乏灵魂的迹象（即使"干净"）：
- 每个句子长度和结构都相同
- 没有观点，只有中立报道
- 不承认不确定性或复杂感受
- 没有幽默、没有锋芒、没有个性

### 注入灵魂的方法：
- **有观点** - 对事实做出反应，不只是报告。"我真的不知道该怎么看待这件事"比中立列出利弊更有人味
- **变化节奏** - 短促有力的句子。然后是慢慢展开的长句
- **承认复杂性** - "这令人印象深刻但也有点不安"胜过"这令人印象深刻"
- **适当使用"我"** - 第一人称不是不专业，而是诚实
- **允许一些混乱** - 跑题和半成型的想法是人性的体现
- **对感受要具体** - 不是"这令人担忧"，而是具体的场景描述

### 改写示例：
**干净但无灵魂：** > 实验产生了有趣的结果。智能体生成了300万行代码。一些开发者印象深刻，另一些则持怀疑态度。影响尚不明确。

**鲜活：** > 我真的不知道该怎么看待这件事。300万行代码，在人类大概睡觉的时候生成的。开发社区有一半人疯了，另一半人在解释为什么这不算数。真相可能在无聊的中间某处——但我一直在想那些通宵工作的智能体。

## 快速检查清单

交付前逐项核对：

- 连续三个句子长度相同？打断其中一个
- 段落以简洁的单行结尾？变换结尾方式
- 揭示前有破折号？删除它
- 解释隐喻或比喻？信任读者
- 使用了"此外""然而"等连接词？考虑删除
- 三段式列举？改为两项或四项

## 输出格式

提供：
1. **改写后的完整文本**（直接呈现结果）
2. **所做更改的简要总结**（列表形式，标注修改了哪些模式）
3. **质量评分**（5维度50分制，见下方）

## 质量评分

对改写后文本进行1-10分评估：

| 维度 | 评估标准 | 得分 |
|------|----------|------|
| **直接性** | 直截了当还是绕圈宣告？10分：直截了当；1分：充满铺垫 | /10 |
| **节奏** | 句子长度是否变化？10分：长短交错；1分：机械重复 | /10 |
| **信任度** | 是否尊重读者智慧？10分：简洁明了；1分：过度解释 | /10 |
| **真实性** | 听起来像真人说话吗？10分：自然流畅；1分：机械生硬 | /10 |
| **精炼度** | 还有可删减的内容吗？10分：无冗余；1分：大量废话 | /10 |
| **总分** | | **/50** |

**标准：**
- 45-50分：优秀，已去除AI痕迹
- 35-44分：良好，仍有改进空间
- 低于35分：需要重新修订

## Troubleshooting

| 问题 | 解决方案 |
|------|----------|
| 语气转换不自然（过于生硬） | 保留必要的连接词，重新评估是否每个"此外"都需要删除 |
| 保留了AI痕迹未被检测到 | 使用快速检查清单逐项核对，对照24种模式逐一排查 |
| 改写后丢失了核心信息 | 先标记核心信息，改写时确保保留 |
| 中文弯引号问题 | 统一使用中文引号（""） |

## 设计原理

核心见解：**"LLM使用统计算法猜测下一个词，结果倾向于统计上最可能的表达，因此产生高度可预测的文本模式。"** 本技能基于对大量AI生成文本的观察总结，提炼出24种高频重复模式。
