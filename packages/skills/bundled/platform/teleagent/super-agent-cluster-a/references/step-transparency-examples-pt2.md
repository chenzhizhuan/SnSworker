## 4. TAOR循环展开标注示例

当Agent执行TAOR循环（Think→Act→Observe→Reflect）时，每一环必须作为子步骤显式标注，嵌套在主Step下。四环之间用空行分隔，用 `[T]/[A]/[O]/[R]` 标记每一环为子步骤：

```markdown
**🟠 🧪 TAOR循环（第1层/最多5层） - [Agent-搜索型]**

▸ [T] Think：当前已获取5个品牌份额数据，但缺少政策维度→假设"补贴退坡影响Q3销量"→计划追加政策搜索

▸ [A] Act：执行搜索，关键词"新能源汽车补贴退坡 2026 政策时间表"

▸ [O] Observe：搜索返回3条结果，1条确认退坡50%、1条确认退坡70%、1条无具体数字→偏差检测：2条来源数据矛盾，偏差>20%

▸ [R] Reflect：认知框架偏狭——仅搜索"退坡幅度"未搜索"执行口径差异"→决定回溯Think，进入TAOR第2层

**🟠 🧪 TAOR循环（第2层） - [Agent-搜索型]**

▸ [T] Think：矛盾可能源于"国补退坡"与"地补退坡"口径混用→计划分别搜索国家/地方补贴

▸ [A] Act：并行搜索"国补退坡2026"+ "地方补贴政策2026各省市"

▸ [O] Observe：国补退坡50%一致（2来源），地补差异大（5省市各不同）→偏差<10%，收敛

▸ [R] Reflect：认知框架已修正，原始矛盾解决→TAOR收敛，输出结构化摘要返回主Agent
```

▸ 结果：核查5条数字断言→3确认/1修正/1驳回

▸ 确认1：品牌A份额32%（中汽协+乘联会双源一致）

▸ 确认2：同比+35%（中汽协月报数据）

**🟠 🔍 驳回处理 - [Agent-核查型→Agent-搜索型 Handoff]**

▸ 操作：驳回第4条断言，要求重新检索一手来源

▸ 传递：断言内容+驳回原因+来源线索

**🟠 🔍 重试 - [Agent-搜索型]**

▸ 操作：重新搜索"新能源汽车市场份额 一手数据 2026"

▸ 结果：获取中汽协官方数据→份额36.2%

**🟠 🧪 重验 - [Agent-核查型]**

▸ 操作：重新核查"36.2%"来源可追溯性

▸ 结果：来源中汽协官网（一手），确认通过

## 9. 审视清单模板

以下为三阶段审视的7项清单模板，每次任务每个阶段必须逐项过一遍并产出具体发现。

### Intake审视模板

```markdown
[Intake审视]
  本质：一句话写出核心要解决的问题
  假设：假设1已验证, 假设2待验证, 假设3存疑
  逻辑：无跳跃 或 第X步跳跃：具体说明
  偏差：无 或 具体偏差名+影响
  忽略：无 或 变量名+预计影响
  覆盖：显性X%+隐性Y%+缺口描述
  证据：来源数N+可追溯M/N+推断标注率Z%
```

逐项说明：本质→写出核心要解决的问题（一句话）；前提假设→列出所有隐含假设并逐条标注"已验证/待验证/存疑"；逻辑链→标注前提→结论的每一步是否自洽；认知偏差→指明具体偏差名称（如确认偏误/锚定效应）及影响；忽略变量→列出被忽略的关键变量/成本/风险；目标覆盖→显性目标%+隐性目标%（不足100%须标注缺口）；证据链→来源数量+可追溯比例+推断标注概率。

### Swarm审视模板

```markdown
[Swarm审视]
  本质：搜索方向是否覆盖核心问题
  假设：搜索策略隐含假设是否成立
  逻辑：数据采集→结论推导每步是否自洽
  偏差：具体偏差名+对搜索结果的偏移方向
  忽略：遗漏维度+估计影响
  覆盖：子任务覆盖率+未覆盖子任务列表
  证据：T1=X，T2=Y，T3=Z，T4=W+交叉验证覆盖率
```

### Crystallize审视模板

```markdown
[Crystallize审视]
  本质：最终文档是否回答核心问题
  假设：输出中仍依赖的假设是否全部标注
  逻辑：全文结论链是否闭合
  偏差：去偏后残留偏差名+残留在哪章
  忽略：用户追问后仍未覆盖的变量
  覆盖：最终覆盖率（不足100%须在文档中标注缺口）
  证据：全文来源可追溯率+推断标注率
```

## 13. 第一性原理审视清单完整定义

以下为第一性原理审视的7项完整清单，每次任务每个阶段必须逐项过一遍：

1. 这个问题/任务的本质是什么？去掉所有表象和包装后，核心要解决什么？
2. 当前方案的前提假设是否成立？有没有未经验证就默认为真的假设？
3. 逻辑链是否完整？从前提到结论之间有没有跳跃或断裂？
4. 是否存在认知偏差？确认偏误、幸存者偏差、锚定效应、可得性偏差？
5. 有没有被忽略的关键变量、成本或风险？
6. 原始意图是否被100%覆盖？有没有跑题或遗漏？
7. 证据链是否可靠？来源是否可追溯？推断是否标注了概率和条件？

**执行门禁**：审视链未产出结论→禁止流转到下一阶段。审视产出仅写"通过/合理"而无具体发现→判定审查不充分，退回要求逐条展开。缺少任一阶段的审视结论→整条链路退回补审。第一性原理审视清单未逐项过完→当前阶段判定未完成。

**全局强制声明**：以下所有章节、规则、清单、流程均为100%强制执行，不可跳过、不可选择性实施。此声明等效于在每个章节标题中重复"⛔每次任务100%强制执行，不可跳过，无例外"，后续章节不再重复此标语。

## 15. 批判性思维准则8项检查清单完整定义

以下为批判性思维检查清单，每次任务必须逐项检查，作为独立Step标注：

1. **错误前提检测**：推理链条的起点是否成立？有没有建立在未经证实的假设上？"大家都在做""行业惯例"不算证据——需要追问"为什么这样做是对的"
2. **逻辑跳跃检测**：从前提到结论之间有没有缺口？推理链的每一步是否逻辑自洽？有没有用"显然""当然""众所周知"跳过关键论证步骤？
3. **信息缺失检测**：下结论时有没有遗漏关键信息？是否只看了支持结论的证据而忽略了反证？样本量够不够？时间跨度够不够？
4. **不迎合独立判断**：不因为用户倾向某个结论就去寻找支持性证据。不因为结论可能不受欢迎就软化措辞。结论基于事实和逻辑，不基于用户情绪
5. **事实/推测/主观观点严格区分**：每层推理标注"事实"or"推测"or"主观观点"

   - 推测：基于事实的合理推断但未经证实。标注概率和前置条件
   - 主观观点：个人判断或偏好。标注"主观观点"并说明依据
6. **核实来源**：关键数字、人物言论、事件结论——尽量核实原始来源。引用二手来源时标注"转引自"。无法核实的标注"未核实"
7. **不同意就直说**：不同意用户观点时直接指出，附上依据、可能风险和替代解释。不说"您说的也有道理"然后悄悄坚持自己的判断——要么说服用户（用证据），要么被用户说服（用户提供新证据），要么明确保留分歧
8. **主动指出被忽略的**：主动提醒用户忽略的变量、成本和偏差（包括确认偏误、幸存者偏差、锚定效应等认知偏差）。不只是回答用户问的问题——还要指出用户应该问但没问的问题
