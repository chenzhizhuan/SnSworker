# 步骤透明化示例集

本文件包含步骤透明化格式的完整示例，供Agent执行时参考。SKILL.md中仅保留核心规则定义，详细示例统一存放在此。

**⛔示例独立性声明（v2.0名称化版）**：本文件及 pt2/pt3 中所有步骤名称仅为格式示范，各示例相互独立、不构成连续体系，⛔禁止复制名称入真实任务。真实任务须按名称唯一性铁律重新命名（全局唯一+禁止同名重复+禁跳号/复用/重置/乱序）。

**强制执行原则**：以下所有示例中的步骤均不可跳过。Intake的全部操作（目标解析→提问追问→记忆注入→复杂度分级路由LDD→任务分解→第一性原理审视→领域术语表→计划拷问→审议门（执行前）→威胁评估）为全任务100%强制、Swarm的TAOR+交叉验证、Verify的四范式+DQG门禁、Crystallize的审视+校验——每一步必须在Step标注中显式出现，省略即违规。

**Step标注格式规则**：十项规则（整行加粗+阶段图标+步骤间空行+子步骤▸+主行≤40字短标题+一字段一行+→仅限值内部+TAOR四环分行+▸无缩进+空行分隔）见 SKILL.md 顶部「⛔ Step标注格式」章节。以下所有示例中的Step行均已符合此格式——实际执行时同样必须保持。**关键：Markdown渲染器会折叠单换行为空格，主行与每个▸子行之间、▸子行相互之间必须加空行，仅换行不够。** **⛔规则17子行完整显示硬规则**：每条▸子行≤100字、每Step≤11行、主行≤40字，全部内容完整不被截断；超100字即格式错误，必要字段可占满但不得超限。

**⛔历史上下文压缩规则（规则16）**：当任务为同一问题指纹重复（相似度≥85%）的历史重提，或▸子行需引用历史基线时，⛔禁止复述完整历史基线/需求细节/上次结论全文，仅输出概括压缩摘要。格式①：`▸ 摘要：历史任务重提，沿用已锁定基线（一句话概括）`；格式②：存在差异时追加`▸ 差异：本轮变更点`，无差异标`▸ 差异：无（沿用基线）`。**⛔指纹命中不豁免提问（v2026.09.04新增）**：即使问题指纹命中历史任务（相似度≥85%）触发本规则，每轮用户消息后仍须通过question工具执行一次提问追问（硬门禁2），历史压缩仅约束▸子行摘要长度，⛔禁止以"指纹命中/历史已理解"为由跳过提问环节。✅正例：指纹命中→输出提问Step→调用question工具→用户回答后再进入记忆注入；❌反例：指纹命中→直接输出目标解析结论→跳过question直接搜索（违规，Intake判未完成退回重执行）。**作用**：防历史重提时正文过长、上下文膨胀且不丢失追问环节。

**三组认知准则+步骤透明化一体化强制规则**：
- 准则①（第一性原理+提问追问）：必须在Intake/Swarm/Crystallize各产出1个审视Step（至少3个），缺失→退回补审。Intake阶段检查点=准则①独立Step，Crystallize阶段终检=准则①交叉复验
- 准则②（世界级专家5项核心行为）：必须在Verify产出1个5项行为检查Step（反驳/来源/推测/独立验证/奉承扫描），缺失→Verify拒绝通过。Verify阶段检查点=准则②独立Step，Crystallize阶段终检=准则②交叉复验
- 准则③（批判性思维3项产出）：必须在Verify产出1个3项产出Step（推理链审查/事实推测观点区分/忽略变量清单），缺失→Verify拒绝通过。Verify阶段检查点=准则③独立Step，Crystallize阶段终检=准则③交叉复验
- Crystallize阶段准则①②③终检：确认三组准则全部已产出可见Step，任一缺失→退回对应阶段补全
- 步骤透明化：无Step标注=未执行，准则不可脱离Step标注"脑子里过一遍"

完整规则定义见 SKILL.md §步骤透明化格式、§第一性原理+提问追问准则、§世界级专家准则、§批判性思维准则 四个章节。
