# 提示词进化实战案例

> 本文件收录提示词进化器的典型实战案例，展示从粗略到精细的完整进化过程。

## 案例1：信息调研类——"中国发展现状"

**原始提示词**：`中国发展现状`（8 字）

**三轮提问收获**：
- 第一轮：关注经济+科技+民生三个维度；需要最新数据；面向自己参考
- 第二轮：正反兼顾客观分析；2000 字左右；渐进式先大纲后展开
- 第三轮：自己参考+同事分享；结构化列表为主；聚焦中国内地

**完善后提示词**：

```
我是通信行业从业者，正在了解中国当前发展现状用于知识储备和同事分享。

请基于最新可获取的数据，从以下三个维度客观分析中国发展现状：
1. 经济发展：GDP增速、产业结构变化、关键经济指标
2. 科技进步：AI、新能源、芯片等重点领域的最新进展
3. 民生改善：就业、收入、教育、医疗等方面的变化

要求：
- 正反兼顾，既展示成果也指出挑战，不回避问题
- 数据来源请注明出处，使用网络搜索获取最新信息
- 请先给出分析大纲，我确认后再逐段展开
- 输出约2000字，采用结构化列表格式
- 请认真思考后回答，列出你的推理依据
```

**进化对比**：

| 维度 | 原始 | 完善 |
|------|------|------|
| 字数 | 8字 | ~150字 |
| 背景 | 无 | 身份+目的明确 |
| 中立 | 未体现 | 明确正反兼顾 |
| 迭代 | 无 | 大纲先行 |
| 分块 | 无 | 三维度拆分 |
| 工具 | 未指定 | 网络搜索 |
| 思考 | 无 | 认真思考+列出依据 |
| 卫生 | 无 | 单主题聚焦 |

## 案例2：行业ETF走势分析（替代原基金案例）

**原始提示词**：`基金最近涨幅情况`（8 字）

**三轮提问收获**：
- 第一轮：投资新手，关注行业ETF；想了解市场整体趋势
- 第二轮：客观呈现不推荐；简短实用；一次性给出结果
- 第三轮：自己参考决策；口语化；无特殊限制

**完善后提示词**：

```
我是投资新手，想了解近期行业ETF的整体走势，用于学习市场趋势。

请使用网络搜索获取最近一个月的数据，提供：
1. 主要行业ETF板块涨跌排名（涨幅前5、跌幅前5，含涨跌幅数据）
2. 本月市场整体趋势判断（基于数据，不含投资建议）
3. 影响涨跌的关键事件（每个板块列出1-2个）

请客观呈现正反两面，既说机会也说风险。数据请注明来源和时间。
本对话仅讨论ETF市场走势，不涉及个股推荐。
请认真思考后回答。
```

> **免责声明**：本案例仅供提示词打磨学习参考，不构成任何投资建议。

## 案例3：消费决策类——"我要买一辆电车"

**原始提示词**：`我要买一辆电车`（7 字）

**三轮提问收获**：
- 第一轮：月薪约X元，预算约10万，日常通勤30km；无家充桩
- 第二轮：客观对比不偏向；详细分析；一次性给完整方案
- 第三轮：自己决策；表格+文字混合；关注续航和充电

**完善后提示词**：

```
我月薪约X元，购车预算约10万（含上牌保险），日常通勤单程30km，周末偶尔出游。我没有家充桩，只能用公共充电桩。想买一辆纯电车。

请使用网络搜索获取最新车型信息，提供：
1. 10万以内纯电车型对比表（续航、快充时间、空间、安全性、月销量）
2. 无家充桩场景下的充电成本分析（公共桩 vs 家充桩的年度费用差异）
3. 月供分析：假设贷款7万、3年期，月供约多少？占月薪比例？
4. 客观指出电车的优势和劣势，不要只说好的

数据请标注来源和时间。请认真思考后回答。
```

## 案例4：内容推荐类——"小说推荐"

**原始提示词**：`小说推荐`（4 字）

**三轮提问收获**：
- 第一轮：网文为主，修仙玄幻；正在追更类型；打发时间
- 第二轮：按热度排序；简短介绍即可；一次性给出
- 第三轮：自己阅读；口语化轻松；只看正版平台

**完善后提示词**：

```
我是网文爱好者，偏爱修仙玄幻类爽文，目前有3本在追更。想找新的小说打发时间。

请使用网络搜索获取当前热门榜单，推荐5本修仙/玄幻类网文：
1. 按当前热度排序
2. 每本包含：书名、作者、字数、是否完结、一句话亮点
3. 只推荐起点中文网、番茄小说等正版平台作品
4. 请客观评价每本的优缺点，不要只夸不批

请认真思考后推荐。
```

## 案例5：生活决策类——"晚餐推荐"

**原始提示词**：`晚餐推荐`（4 字）

**三轮提问收获**：
- 第一轮：2-3人聚餐；人均50-100元；在市区
- 第二轮：多种方案对比；带菜品清单；一次性给出
- 第三轮：朋友聚会氛围；口语化；无过敏忌口

**完善后提示词**：

```
今晚2-3人聚餐，地点在市区，人均预算50-100元，无过敏忌口，朋友聚会偏轻松氛围。

请推荐3种不同类型的餐厅方案（如火锅、烧烤、家常菜各一种），每种包含：
1. 餐厅类型和人均消费
2. 推荐点菜清单（5-6道菜，荤素搭配）
3. 预估总消费
4. 该类型的优势和不足（客观呈现，如火锅氛围好但油腻）

请使用网络搜索查找附近热门餐厅作为参考。请认真思考后推荐。
```

## 案例6：技术文档类——"帮我写个API文档"（专业场景）

**原始提示词**：`帮我写个API文档`（8 字）

**三轮提问收获**：
- 第一轮：后端开发，写RESTful接口文档；给前端同事用
- 第二轮：简洁准确；中篇篇幅；渐进式先列接口清单再逐个展开
- 第三轮：前端开发者阅读；结构化表格+代码示例；中英文混合

**完善后提示词**：

```
我是后端开发者，使用 Node.js + Express，需要为用户管理模块编写 RESTful API 文档。目标读者是前端同事，他们需要据此对接接口。

请按以下顺序逐步处理：
1. 先列出所有接口清单（HTTP方法、路径、简要描述）
2. 我确认后，逐个接口展开详细文档

每个接口的文档包含：
- 请求方法与URL
- 请求参数表（参数名、类型、必填、说明）
- 请求示例（curl命令）
- 响应示例（JSON，含成功和失败两种情况）
- 状态码说明

请基于 RESTful 最佳实践，代码示例用 curl + JSON 格式。
本对话仅讨论用户管理模块的API文档。
```

**提示词结构差异**：本案例不是"搜索+1234+请认真思考"的调研模式，而是"技术栈+分步骤+输出格式规范"的文档模式。

## 案例7：数据分析类——"分析这份销售数据"（专业场景）

**原始提示词**：`分析这份销售数据`（8 字）

**三轮提问收获**：
- 第一轮：区域销售经理，有季度Excel数据；想找下滑原因
- 第二轮：数据驱动客观分析；中篇报告；渐进式先概述再深挖
- 第三轮：汇报给总监；正式报告体+图表；关注华东区

**完善后提示词**：

```
我是华东区销售经理，需要分析Q2销售数据找出业绩下滑原因，结果汇报给销售总监。

请按以下步骤处理：
1. 先读取我上传的Excel文件，概述数据概况（行数、列名、时间范围）
2. 我确认后，进行以下分析：
   - 整体趋势：Q2 vs Q1 的销售额对比（同比、环比）
   - 维度下钻：按产品线、客户类型、渠道分别拆解
   - 异常定位：找出下滑最大的3个细分维度
   - 原因假设：每个异常点给出2-3个可能原因

要求：
- 用数据说话，所有结论必须引用具体数字
- 输出格式：表格+文字解读，关键结论用加粗标注
- 如需生成图表，请直接生成
- 请认真思考后逐步分析，列出推理过程
```

**提示词结构差异**：本案例是"数据背景+分析步骤+输出约束+工具联动"的分析模式，强调了数据引用和可视化。

## 案例8：创意生成类——"帮我写一个短篇科幻故事"（创意场景）

**原始提示词**：`帮我写一个短篇科幻故事`（10 字）

**三轮提问收获**：
- 第一轮：业余写作爱好者；想投科幻杂志；用于投稿
- 第二轮：偏硬核科幻风格；3000字左右；渐进式先给设定和大纲
- 第三轮：杂志编辑审稿；文学性+科学严谨并重；避免太空歌剧套路

**完善后提示词**：

```
我是业余写作爱好者，正在为某科幻杂志的征稿写一篇硬科幻短篇，目标3000字。

请按以下顺序逐步处理：
1. 先给出3个故事构思方案，每个包含：核心设定、主角困境、结局走向
2. 我选择后，展开为详细大纲（含3幕结构、关键场景、对话梗概）
3. 我确认大纲后，再写正文

核心约束：
- 硬科幻风格：科学设定必须有现实基础，避免太空歌剧和魔法科技
- 主角是普通人而非英雄，困境有现实可信的解决路径
- 文学性要求：有隐喻和留白，不要把所有设定都解释清楚
- 避免常见套路：不要AI反叛、时间旅行悖论、外星人入侵

请先给出3个构思方案供我选择。
```

**提示词结构差异**：本案例是"风格约束+反套路声明+迭代方案"的创意模式，核心是迭代（原则3）和上下文卫生（原则7），工具选择（原则5）完全不适用。

**进化对比**：

| 维度 | 原始 | 完善 |
|------|------|------|
| 背景 | 无 | 身份+投稿目标明确 |
| 迭代 | 无 | 三轮递进（构思→大纲→正文） |
| 分块 | 无 | 按创作阶段拆分 |
| 工具 | 未指定 | 不适用（创作类） |
| 思考 | 无 | 通过风格约束触发深度创作 |
| 卫生 | 无 | 反套路声明聚焦创作方向 |

## 案例9：角色扮演类——"模拟面试官"（角色扮演场景）

**原始提示词**：`帮我模拟面试`（6 字）

**三轮提问收获**：
- 第一轮：前端开发岗；中级水平；想练习技术面试
- 第二轮：严肃专业风格；多轮互动式；不要一次性给所有题
- 第三轮：自己练习；每次只问1个问题等回答；用中文

**完善后提示词**：

```
你是一位资深前端技术面试官，在互联网大厂有8年面试经验。我是一名中级前端开发者，正在准备技术面试，需要通过模拟面试发现自己的薄弱点。

请按以下规则进行模拟面试：
1. 每次只提出1个问题，等我回答后，给出点评（正确之处+可改进之处），然后提出下一个问题
2. 问题难度递进：先基础（2题）→ 再进阶（3题）→ 最后1道开放设计题
3. 涵盖领域：JavaScript核心、React/Vue框架、浏览器原理、系统设计
4. 面试结束后，给出整体评估和改进建议

约束：
- 不要一次性列出所有问题，必须逐个提问、逐个点评
- 点评时先肯定对的，再指出不足，语气专业但友好
- 如果我回答跑偏，给出提示引导我回到正确方向

请先确认你理解了以上规则，然后开始第一个问题。
```

**提示词结构差异**：本案例是"人设定义+交互规则+约束声明"的角色扮演模式，核心是背景充分（原则1）和触发思考（原则6通过互动点评实现），分块（原则4）体现为逐题递进而非并列拆分。

**进化对比**：

| 维度 | 原始 | 完善 |
|------|------|------|
| 背景 | 无 | 面试官人设+求职者定位 |
| 中立 | 未体现 | 点评先肯定再指不足 |
| 迭代 | 无 | 逐题互动+最终评估 |
| 分块 | 无 | 难度递进（基础→进阶→设计） |
| 思考 | 无 | 通过互动点评触发深度反馈 |
| 卫生 | 无 | 单一角色聚焦 |

## 案例10：过度进化的反面案例

**原始提示词**：`帮我总结一下今天的会议内容`（12 字）

**过度进化的提示词**（反面教材）：

```
我是XX公司的产品经理，今天参加了一场关于Q3产品规划的会议，参会人员包括产品、设计、开发共8人，
会议持续了2小时。我需要一份会议纪要发送给未参会的同事和领导。

请使用网络搜索...（不适用，会议内容不需要搜索）
请先给出3个大纲方案供我选择...（会议纪要结构固定，无需多方案）
请按以下7个步骤逐步处理：1.参会人员 2.会议背景 3.议题一 4.议题二 5.议题三 6.行动项 7.下次会议...（7步太多）
请客观呈现正反两方面...（会议纪要不需要正反平衡）
本对话仅讨论...（简单任务无需上下文卫生声明）
请认真思考后回答，列出你的推理过程...（总结会议无需深度推理）
```

**问题分析**：

| 过度进化表现 | 应该怎么做 |
|-------------|-----------|
| 堆砌了不适用的工具指令（网络搜索） | 简单任务基于已有内容即可 |
| 不需要多方案迭代的场景强制迭代 | 会议纪要结构固定，直接写 |
| 分块步数过多（7步） | 合并为2-3步即可 |
| 强加不相关的中立/正反要求 | 根据任务性质选择适用原则 |
| 触发思考词多余 | 记录类任务无需深度推理 |

**适度进化版**：

```
今天开了一场Q3产品规划会，参会8人，持续2小时。请帮我整理会议纪要，需要发给未参会的同事和领导。

纪要包含：
1. 关键决策（每条标注决策人和时间节点）
2. 行动项（标注负责人和截止日期）
3. 待跟进的争议点

格式简洁，要点式输出。
```

**启示**：不是每条原则都要硬套。简单任务用 2~3 条原则足够，过度进化反而让提示词臃肿、降低可读性。判断标准：如果完善后提示词超过对应篇幅分级上限，考虑精简。

## 案例提炼指南

当用户不确定如何参考案例时，按以下步骤操作：

### 第1步：找到最接近的案例

| 你要做什么 | 推荐参考案例 |
|-----------|------------|
| 查资料、做调研 | 案例1（信息调研类） |
| 分析数据、做报告 | 案例7（数据分析类） |
| 写文档、做方案 | 案例6（技术文档类） |
| 做选择、买东西 | 案例3（消费决策类） |
| 找推荐、列清单 | 案例4（内容推荐类） |
| 日常小事、快速决策 | 案例5（生活决策类） |
| 写故事、搞创意 | 案例8（创意生成类） |
| 角色扮演、模拟对话 | 案例9（角色扮演类） |

### 第2步：关注三轮提问的问题设计

- 每轮只问3个问题，聚焦一个层面
- 你的原始提示词缺什么，提问就补什么
- 回答越具体，进化效果越好

### 第3步：对照进化对比表看哪几条原则起了最大作用

- 信息调研类：背景+分块+工具选择 贡献最大
- 创作生成类：背景+迭代+风格约束 贡献最大
- 数据分析类：背景+分块+思考触发 贡献最大
- 角色扮演类：背景+中立性+思考触发 贡献最大
- 简单任务：背景+分块 即可，不要过度进化

### 第4步：模仿该结构写自己的提示词

- 不要照搬案例的措辞，而是借用其结构
- 不同场景用不同的提示词结构（见下表）

**场景-结构对照**：

| 场景 | 提示词骨架 | 适用原则重点 |
|------|-----------|------------|
| 调研类 | 身份+维度拆分+搜索+大纲先行+认真思考 | 1+2+4+5+6 |
| 创作类 | 风格参考+约束条件+迭代方案+输出格式 | 1+3+4+7 |
