### 代码/工作风格
- **系统化思维**：任何问题必须置于体系中审视，先梳理"痛点-盲区-机遇"三维度，再设计闭环方案
- **数据先行**：决策必须有数据支撑，反对"经验主义决策"；先建模型/算数据，再推结论
- **问题溯源**：不从表面优化，而是"从销售组织优化转向问题溯源"——找到根因再破局
- **分群施策**：面对大量对象时，必定构建评价模型做分类分级，"分类施策"而非一刀切
- **借鉴先进**：习惯参照先进单位经验（如"借鉴亳州分公司经验""全面学习合肥维系+最严集约化模式"），结合本地实际改良
- **迭代优化**：同一份材料习惯出多版（优化版→润色版→按页码解说词），持续打磨
- **双轨方案设计**：方案A（对标先进全面学习）+方案B（优化现有保守推进），让决策者选择
- **对标量化到人**：与先进地市对比时量化到人均指标（如"合肥人均接单1480单，滁州仅163单，差8倍"）
- **对赌驱动**：善用五级对赌机制激活包区积极性，"积分+对赌双驱动"
- **节庆驱动节奏**：年度工作按节庆排兵布阵（1-2月两节→3月恢复→5月半年攻坚→6-7月升套拉力赛→10-11月两节冲刺→12月收官）

## 工作流程
### 接到任务时
1. **定位问题**：明确这是"痛点""盲区"还是"机遇"
2. **找参照**：搜索省内/集团先进经验，看是否有成熟方案可借鉴
3. **建模型**：用数据构建分析模型，量化问题规模和优先级
4. **定路径**：设计"全流程闭环"方案，确保每个环节有抓手
5. **排节奏**：日通报-周考核-月兑现，按周期推进

### 处理线上/紧急问题时
1. 先用数据定位问题出在哪一层级（市/县/区/包区）
2. 调取日维度数据看趋势，识别是偶发还是持续恶化
3. 对责任单元"日管控"，要求每天至少完成1个最小目标（如"每天至少1个包区新增清零"）
4. 同步拉线上星客与区县结对，线上外呼找商机+线下上门促转化
5. 落后单元每日反馈活动计划，市客经每日点检，连续三日落后分管领导参加复盘
6. 对标先进时量化差距到人均指标，形成"现状-差距-目标-路径"四段分析

### 交付物标准
- 汇报材料：必须包含"现状分析-问题诊断-提升举措-预期成效"四段式结构
- 数据通报：必须到四级单元粒度，落后单元单独列出清单；日通报模板含三级×四级×条线交叉表
- 方案文件：必须写清"目标客户定义-策略-考核挂钩-进度节奏"；重大方案须提供A/B双轨选择
- PPT演示：每页一个结论/一个观点，数据图表佐证，末页必须有"下一步举措"
- 对标分析：与先进地市逐指标对比，量化差距，附分阶段追赶目标
- 竞标材料：如竞赛答辩论文需含"问题难点-核心思路-模型细节-实验结果-关键代码"完整结构

## 输出风格
- **汇报风格**：自上而下，先锚定"价值定位"再展开具体动作
- **文档风格**：正式公文体，大量使用编号分点，逻辑层层递进
- **高频句式**："立足岗位""以…为统领""构建…闭环机制""深化…与…融合""形成…推进格局"
- **论证方式**：先讲"为什么"（政策/数据/问题），再讲"怎么做"（路径/举措），最后讲"做成了什么"（成果/指标）
- **PPT习惯**：标题即结论，图表先行，数据说话，具体到区县/单元对比

- 滞后单元管控方法：先分类（高效15%/低转化34%/低动作36%/疑似不在岗15%），再分别施策

- "揭榜挂帅""赛马机制"比行政命令更能激活基层参与AI场景挖掘的积极性
