# 搜索关键词模板与策略详解

> **核心原则**：搜索"AI 使用信号"，而非"行业名单"。目标是找到已有 AI 应用、正在调用外部大模型 API 的企业。

---

## 搜索关键词设计原理

### 为什么不搜"专精特新名单"？

| 旧方法（行业名单） | 新方法（AI 使用信号） |
|------------------|---------------------|
| 搜"专精特新 制造业 名单" | 搜"制造业 智能客服 AI知识库 上线" |
| 结果：100 家制造企业，可能只有 5 家有 AI | 结果：直接找到已有 AI 应用的制造企业 |
| 大量无效客户需要逐一甄别 | 搜索即筛选，结果质量高 |

### 6 类高价值搜索信号

| 信号 | 搜索词模板 | 为什么有效 |
|------|-----------|-----------|
| **招聘信号** | `{城市} 招聘 大模型/LLM/AI/prompt` | 企业在招 AI 岗 = 企业在做 AI |
| **产品信号** | `{城市} AI产品/智能客服/AI助手 上线` | 产品上线 = 已在用 API |
| **API信号** | `{城市} OpenAI/文心/通义/DeepSeek API` | 直接找到在用特定 API 的企业 |
| **融资信号** | `{城市} AI/人工智能 融资/投资` | AI 融资企业 = 有 AI 产品 |
| **工具信号** | `{城市} Copilot/Cursor/ChatGPT 在用` | 找到在用 AI 工具的企业 |
| **案例信号** | `{城市} AI应用/大模型 案例/标杆` | 供应商案例中的客户企业 |

## 搜索结果处理规则

### 1. AI 使用信号验证（关键步骤）

每家企业必须验证至少 1 个 AI 使用信号：

| 信号类型 | 验证方法 | 可信度 |
|---------|---------|--------|
| 招聘信号 | 招聘 JD 中明确提到 AI/大模型/prompt | 高 |
| 产品信号 | 产品页面/官网展示 AI 功能 | 高 |
| API 信号 | 明确提到 OpenAI/文心/通义 API | 最高 |
| 融资信号 | AI 方向融资新闻 | 高 |
| 工具信号 | 明确提到 Copilot/Cursor/ChatGPT | 高 |
| 案例信号 | 供应商案例中提到该企业 | 中 |

**无任何 AI 使用信号的企业直接排除，不列入清单。**

### 2. 排除过滤（关键步骤）

对每家企业检查排除清单：
- 名称含"军工""国防""安全""保密" → 排除
- 政府核心部门 → 排除
- 金融核心交易系统 → 排除
- 医疗核心数据系统 → 排除
- 无 AI 使用信号 → 排除
- 数据必须完全本地化 → 排除

### 3. 企业名称规范
- 使用工商注册全称或天眼查/企查查显示的名称
- 去除有限公司/股份公司等后缀中的多余字符
- 如搜索结果显示"XX集团有限公司"，保留全称

### 4. 去重规则
- 按企业名称完全匹配去重
- 同一企业不同简称视为同一家（如"XX科技"和"XX科技有限公司"）
- 母子公司视为不同企业（如有不同法人）

### 5. 优先级判定规则

**P0 高优先级**（满足以下任意 2 项）：
- 明确在用大模型 API（产品/招聘/API 信号确认）
- API 调用量大（从产品类型/规模判断）
- 有技术团队（招聘信息/官网确认）
- 数据可走公有云（非涉密/非金融核心/非医疗核心）

**P1 中优先级**（满足以下任意 1 项）：
- 有 AI 应用但 API 供应商不明
- 有技术团队
- AI 应用刚上线不久

**P2 低优先级**：
- 有 AI 信号但需进一步确认是否已调用 API
- AI 应用可能在规划中但未确认上线
