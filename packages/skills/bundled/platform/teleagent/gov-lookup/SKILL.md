# 政府部门与关键人查询

从互联网公开信息查询政府部门的组织架构和关键人/领导信息。

## 工作流程

### 1. 明确查询目标

从用户请求中提取：
- **目标部门**：全称（如"河南省工业和信息化厅"）
- **查询类型**：组织架构 / 关键人 / 两者
- **层级深度**：仅领导班子 / 含内设机构 / 含下属单位

若用户表述模糊，主动追问部门全称。

### 2. 构建搜索策略

读取 [search-strategies.md](references/search-strategies.md) 获取关键词策略与权威来源指引。

**搜索优先级**：
1. 政府官网"机构概况"/"领导信息"栏目（最权威）
2. "三定方案"原文（职能+机构+编制）
3. 权威媒体报道（新华社、人民日报等）
4. 人事任免公告

**搜索技巧**：
- 加年份限定确保时效性（如 `2026`）
- 多关键词交叉验证同一信息
- 不同来源互相对照确认准确性

### 3. 执行搜索并交叉验证

使用 `online_search` 工具，按以下顺序搜索：

**组织架构搜索**：
```
"{部门全称}" "内设机构" OR "机构设置" OR "三定方案"
```

**关键人搜索**：
```
"{部门全称}" "领导班子" OR "领导分工" OR "主要领导"
```

**人员确认搜索**：
```
"{人名}" "{部门全称}" "职务"
```

对搜索结果：
- 至少从2个不同来源交叉验证关键人信息
- 标注信息来源和时效
- 发现矛盾时以政府官网为准

### 4. 整理输出结果

#### 4a. 结构化文本/表格

**组织架构表格**：

| 层级 | 机构名称 | 主要职责 | 负责人 |
|------|---------|---------|-------|
| 厅领导 | XX厅 | 全面工作 | 厅长：XXX |
| 内设机构 | XX处 | 具体职责 | 处长：XXX |

**关键人信息表格**：

| 姓名 | 职务 | 分管领域 | 备注 |
|------|------|---------|------|

**关键人详细信息**：
- 姓名、职务、分管领域
- 简历要点（如公开可查）
- 信息来源与时效标注

#### 4b. 可视化组织架构图

当用户需要可视化呈现时，使用 `scripts/generate_org_chart.py` 生成 HTML 组织架构图。

**输入JSON格式**：
```json
[
  {
    "name": "XX厅",
    "person": "厅长：张三",
    "title": "正厅级",
    "children": [
      {
        "name": "办公室",
        "person": "主任：李四",
        "title": "正处级",
        "children": []
      }
    ]
  }
]
```

**生成命令**：
```powershell
$env:PYTHONIOENCODING='utf-8'; python "{skill_dir}/scripts/generate_org_chart.py" data.json --output org_chart.html --title "XX厅组织架构图"
```

**注意**：先将查询结果整理为上述JSON格式，写入 `.temp/` 目录，再运行脚本生成HTML。

### 5. 信息标注规范

所有输出必须包含：
- **数据来源**：标注信息来自哪个网站/文件
- **时效说明**：标注信息更新时间（如"截至2026年8月"）
- **免责声明**：信息来自互联网公开资料，仅供参考，以官方最新发布为准

## 常见场景示例

**场景1**：用户问"河南省工信厅的内设机构有哪些"
→ 搜索"河南省工业和信息化厅 内设机构"+"三定方案"，整理为表格，可选生成架构图

**场景2**：用户问"工信部现任领导班子"
→ 搜索"工业和信息化部 领导班子 2026"，交叉验证，整理为关键人表格

**场景3**：用户问"帮我查一下XX厅的分管副厅长是谁"
→ 搜索"XX厅 领导分工 2026"，定位分管副厅长信息

**场景4**：用户问"画出XX局的组织架构图"
→ 先搜索组织架构信息，整理为JSON，调用脚本生成HTML可视化图

## 注意事项

- 仅查询互联网公开信息，不涉及任何非公开渠道
- 领导人事变动频繁，务必加时间限定搜索
- 对信息来源做交叉验证，矛盾时以政府官网为准
- 不对公开信息做推测或补充未查证的内容
