# 搜索策略与政府信息来源指引

## 一、政府官网域名规则

### 省级政府
- 格式：`www.{省名拼音缩写}.gov.cn`
- 示例：`www.henan.gov.cn`（河南省）、`www.gd.gov.cn`（广东省）
- 省名缩写对照常见易错项：
  - 陕西 → shaanxi（双a区分山西）
  - 内蒙古 → nmg（内蒙）

### 省级厅局
- 格式：`{厅局关键词}.{省域名}` 或 `{省域名}/部门简称`
- 常见厅局关键词：`jht`（工信厅）、`szt`（住建厅）、`kjt`（科技厅）、`jyt`（教育厅）

### 国务院及部委
- 国务院官网：`www.gov.cn`
- 各部委：`www.{部委简称}.gov.cn`
- 常见部委简称：`miit`（工信部）、`mof`（财政部）、`ndrc`（发改委）

### 市县级
- 格式：`www.{城市名}.gov.cn`
- 部分地市使用：`{城市名}.{省域名}`

## 三、权威信息来源优先级

1. **政府官网**（最权威）
   - 各级政府门户网站
   - 部门子站"机构概况"/"领导信息"栏目

2. **官方公报/公告**
   - 国务院公报：`www.gov.cn/gongbao`
   - 省政府公报

3. **权威新闻媒体**
   - 新华社、人民日报等官方报道
   - 地方党报（如《河南日报》）

4. **人事任免公告**
   - 人大公告（任命/免职）
   - 组织部公示

## 四、信息时效性注意事项

- 领导班子信息变动频繁，搜索时加上年份限定
- 优先搜索最近6个月内的信息
- 三定方案相对稳定，但注意最新修订版本
- 机构改革期间（如2023年机构改革），组织架构可能大幅调整，需关注最新改革方案
