# 创意设计层 (Layer 4 · Creative Design)

> v6.0 新增 | 优先级：Phase 4

## 1. 解决什么问题

分析类、布置会、述职等材料不适合"模板化流水线"，需要灵活的创意设计思路。本层提供**设计思路推荐机制**，先给2-3个方向让用户选择，再基于选定方向生成，确保创意不偏离用户预期。

## 2. 核心机制

```
用户需求 → 场景识别 → 推荐2-3个设计方向 → 用户选择 → 生成定制化PPT
```

## 3. 场景化设计库

### 3.1 经营分析会

**特征**：数据密集、需要看趋势和结构、领导关注核心指标

| 设计方向 | 适用场景 | 视觉特点 | 推荐模板组合 |
|----------|---------|---------|------------|
| A. 仪表盘式 | 指标多需一目了然 | 顶部KPI大数字→中部趋势图表→底部关键发现 | T13+T9+T7 |
| B. 对比发现式 | 有同期/环比对比 | 左右对比（上期vs本期）+ 差异高亮 | T6+T9+T13 |
| C. 叙事线式 | 有完整经营故事 | 按发现问题→分析原因→给出策略的逻辑链展开 | T4+T11+T7 |

**选择提示**：
- "数据多，领导速看" → A
- "要讲变化和差距" → B
- "要讲完整经营逻辑" → C

### 3.2 工作布置会

**特征**：行动导向、有明确任务分解、强调时间节点

| 设计方向 | 适用场景 | 视觉特点 | 推荐模板组合 |
|----------|---------|---------|------------|
| A. 时间线式 | 有明确阶段和节点 | 横向时间轴→每节点挂任务+责任人 | T11(timeline)+T7 |
| B. 矩阵分解式 | 多维度任务布置 | 行=维度/条线，列=阶段/责任人 | T10(结构表)+T8 |
| C. 军令状式 | 强调目标和承诺 | 大数字目标→责任分解→奖惩机制 | T13+T10+T5 |

**选择提示**：
- "按时间阶段推进" → A
- "多部门多线并行" → B
- "重在目标承诺" → C

### 3.3 专项汇报

**特征**：聚焦单一主题、深度分析、有对策建议

| 设计方向 | 适用场景 | 视觉特点 | 推荐模板组合 |
|----------|---------|---------|------------|
| A. 漏斗式 | 问题层层深入 | 现状→问题→原因→对策，逐层收窄 | T5+T11+T4 |
| B. 金字塔式 | 结论先行 | 顶部结论→中部论据→底部数据 | T4+T9+T10 |
| C. 对话式 | 回应质疑/提问 | Q→A 结构，每个问题配一张证据 | T6+T9+T13 |

**选择提示**：
- "要讲深讲透一个问题" → A
- "领导先看结论" → B
- "要回应质疑" → C

### 3.4 述职报告

**特征**：个人视角、业绩+反思+规划、讲求真诚

| 设计方向 | 适用场景 | 视觉特点 | 推荐模板组合 |
|----------|---------|---------|------------|
| A. 故事线式 | 有完整工作故事 | 开头→发展→高潮→反思→未来 | T4+T11+T15 |
| B. 数据说话式 | 业绩量化明显 | KPI开道→数据支撑→反思|差距|计划 | T13+T9+T7 |
| C. 双面式 | 突出成绩也直面问题 | 成绩页(暖色) → 问题页(冷色) 交替 | T7+T6+T15 |

**选择提示**：
- "要讲工作心路历程" → A
- "业绩数据很硬" → B
- "要坦诚也要体面" → C

### 3.5 对标分析

**特征**：外部/内部对标、找差距、学先进

| 设计方向 | 适用场景 | 视觉特点 | 推荐模板组合 |
|----------|---------|---------|------------|
| A. 雷达图式 | 多维度综合对标 | 雷达图展示差距→逐维度展开 | T9+T6+T7 |
| B. 榜单式 | 有排名逻辑 | 排名表→Top3亮点→自身差距→追赶路径 | T10+T13+T11 |
| C. 画像式 | 深入分析标杆 | 标杆画像(我) → 标杆画像(他) → 差异矩阵 | T8+T6+T10 |

**选择提示**：
- "多维度打分对比" → A
- "要排名和追差距" → B
- "要深度解构标杆" → C

## 4. 设计方向推荐流程

### Step 2B: 创意方向推荐（插入在 Step 2 之后）

```
识别场景 → 查设计库 → 推荐2-3个方向 → 用户选择 → 进入 Step 3
```

**推荐展示模板**：

```
🎨 PPT设计方案推荐

场景识别：经营分析会

方案A · 仪表盘式
  顶部KPI大数字 → 中部趋势图表 → 底部关键发现
  适合：数据多，领导速看
  预计8-10页

方案B · 对比发现式
  左右对比（上期vs本期）+ 差异高亮
  适合：要讲变化和差距
  预计10-12页

方案C · 叙事线式
  发现问题 → 分析原因 → 给出策略
  适合：要讲完整经营逻辑
  预计12-14页

请选择方案（A/B/C），或说明你的偏好我来调整。
```

### 4.1 无匹配场景时的处理

如果场景不在5种预设中：

1. 基于最接近的场景推荐，标注差异
2. 使用通用设计框架：
   - 信息密度高 → 仪表盘式
   - 流程/步骤多 → 时间线式
   - 对比为主 → 对比发现式
   - 讲故事为主 → 叙事线式
3. 用户可自定义方向

### 4.2 创意约束

推荐设计方向时必须遵守：

- 不违反 `CORPORATE_SPEC.md` 中的企业视觉规范
- 不破坏 `LAYOUT_HABITS.md` 中的版面习惯
- 电信主题下不得大面积使用非主题色
- 推荐方向仍需通过 Slide Contract 和 QA 流程

## 5. 与各层的交互

| 交互层 | 关系 |
|--------|------|
| Layer 1 · 数据智能 | 数据分析页面使用 ED# 驱动模式，创意层关注整体叙事逻辑 |
| Layer 2 · 模板锚定 | 创意设计尊重模板锚定约束，不推荐破坏模板结构的方案 |
| Layer 3 · 风格记忆 | 创意方案在记忆规范范围内推荐，不冲突 |
| Layer 5 · 精控执行 | 设计方案的微调也走 Layer 5 沉淀闭环 |

## 6. 设计灵感来源（进阶）

### 6.1 从用户历史PPT中学习

如果检测到用户工作空间中有历史PPT：
- 提取其页面结构和视觉特征
- 作为设计方向的参考依据
- 在推荐时说明"参考了您X月份的汇报PPT风格"

### 6.2 从行业模板中借鉴

可参考但不直接复制的风格：
- 华为：蓝灰商务+数据驱动
- 阿里：橙色活力+故事线
- 腾讯：科技蓝+简洁清朗
- 麦肯锡：叙事结构+金字塔原理

借鉴方式：只取设计思路，不取配色/字体。
