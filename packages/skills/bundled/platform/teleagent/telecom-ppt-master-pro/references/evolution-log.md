 — python-pptx 原生底版继承（5G模板页眉100%还原）

**日期**: 2026-07-26
**来源**: 用户验证 FTTR 培训 12 页 PPT 成功后指示"把底版更新到skill里"
**核心变更**: 新增 python-pptx 原生底版继承方案，替代 pptxgenjs 代码复刻页眉，5G logo 升级为真实图片

### 学会的能力

1. **python-pptx 原生 layout 继承**
   - 加载官方 `电信5G原生模板1.0.pptx`（1 master + 12 layouts）
   - 用 layout `2019-004`（index=11，0占位符+4原生形状）新建 slide
   - 页眉元素（红色方块叠块、5G logo 图片 image1.png、红色横线）由 layout 原生继承，零代码绘制
   - 移除原 slide1：`prs.slides._sldIdLst.remove(list(xml_slides)[0])`

2. **Length 类型双重包装陷阱修复**
   - `Pt()` 返回的 Length 继承自 int，`isinstance(Pt(1), int)` 为 True
   - `Pt(Pt(1))` 会越界报错
   - 修复：add_rect 的 line_w 参数判断顺序必须是 `Length → int/float → 其他`
   - 必须 `from pptx.util import Inches, Pt, Emu, Length`

3. **Duplicate name 警告可忽略**
   - python-pptx 移除原 slide 时 rels 未完全清理，save 时报 `Duplicate name: 'ppt/slides/slide1.xml'`
   - 不影响 PowerPoint 正常打开和渲染（已验证 12 页均可正常 Export PNG）

4. **python-pptx QA 路径**
   - 用宿主受控渲染能力生成 PNG 缩略图
   - 配合 `image_understanding` 工具逐页视觉检查
   - 不依赖实时预览（python-pptx 非 JS 引擎，不走 pages 模块）

5. **helper 函数库沉淀**
   - `add_textbox(s, x, y, w, h, runs, align, valign, line_spacing)` — 多 run 文本框
   - `add_rect(s, x, y, w, h, fill, line, line_w, shape)` — 矩形/圆角矩形/椭圆，line_w 四类型安全
   - `add_oval(...)` — 椭圆
   - `draw_card(s, x, y, w, h, line, line_w, fill)` — 电信卡片
   - `add_header_title(s, prefix, suffix)` — 页眉标题文字（前缀红:后缀蓝）

## v8.0 — open-design 设计 token 体系融合（重大视觉升级）

**日期**: 2026-07-25
**来源**: nexu-io/open-design (81.4K stars) 设计系统方法论 + 用户反馈"PPT风格太朴素，颜色素材字体不搭配"
**核心变更**: 引入 DESIGN.md 品牌契约式设计 token 体系，全面升级配色/字体/间距/材质

### 学会的能力

1. **10 级色阶 token 体系**
   - 每个主题色从 3 级（深/中/浅）升级为 10 级（50-900 Tailwind 风格色阶）
   - telecom-red 品牌色阶: #FFF5F5 → #C00000 → #4D0004
   - executive-blue 品牌蓝色阶: #F0F7FD → #0070C0 → #002050
   - 新增绿色正向色阶 (positive[50-900]) 专门用于 executive-blue 达标标注
   - 统一灰度色阶 neutral[50-900] — 全部主题共用

2. **字体配对系统**
   - 告别"全篇微软雅黑"：FONT_SANS + FONT_DISPLAY + FONT_NUMBER + FONT_SERIF 四层配对
   - 数据数字专用于 FONT_NUMBER (Arial/Helvetica) 确保等宽对齐
   - 引用/公文场景使用 FONT_SERIF (SimSun) 增强专业感

3. **表面材质层级系统 (Elevation L0-L5)**
   - L0(页面底) → L1(内容区) → L2(卡片) → L3(标题栏) → L4(浮层) → L5(品牌底)
   - 三级阴影高程: card(blur:4) / overlay(blur:8) / prominent(blur:12)
   - 引入品牌色阴影 (elevation-brand) 强化电信红视觉冲击

4. **4px 基准间距格系统**
   - 所有间距基于 space-1(0.04") 到 space-16(0.65") 的语义 token
   - 三栏布局公式: (safeW - 2*THREE_COL_GAP) / 3
   - 卡片内部标准内边距: CARD_PADDING_X=0.14", CARD_PADDING_Y=0.12"

5. **12 语义色彩角色**
   - 传统 6 角色 (primary/accent/contrast/neutral/text/highlight) 升级为 12 角色
   - 新增: brand-vivid / brand-muted / positive / surface-raised / surface-header / border / text-secondary

6. **颜色协调性自动校验**
   - 文字-背景对比度 ≥ 4.5:1 (正文) / ≥ 3:1 (大标题)
   - 同屏颜色不超过 4 种语义色
   - 相邻元素色阶差 ≥ 300

### 新增文件
- `references/design-system.md` — 设计 token 体系权威来源（DESIGN.md 等价物）

### 修改文件
- `references/themes.md` — telecom-red / executive-blue 升级为 10 级色阶 + 字体配对 + 高程 token
- `references/style-guide.md` — 添加 design-system.md 引用，正文色改为 neutral[800] 替代纯黑

### 学会的能力

1. **10种原生图形布局（T25-T34）**
   - T25 时间轴 (`drawTimeline`)：水平轴线+编号圆点+交替上下标签+起止装饰
   - T26 流程箭头 (`drawProcessFlow`)：编号步骤盒+CHEVRON箭头连接+未步高亮
   - T27 金字塔 (`drawPyramid`)：TRAPEZOID梯形层叠+颜色渐变+可选侧标注
   - T28 循环图 (`drawCycle`)：圆形排列节点+中心圆+↻箭头连接+外围标签
   - T29 总分结构 (`drawTree`)：根节点+连线+分支卡片+子项列表
   - T30 漏斗图 (`drawFunnel`)：递减宽度TRAPEZOID+标签+右侧百分比
   - T31 殿堂框架 (`drawTemple`)：梯形屋顶+多柱子+矩形基座
   - T32 垂直步骤 (`drawVerticalSteps`)：竖轴线+编号圆+内容卡片+左侧色条
   - T33 阶梯进化 (`drawStaircase`)：递增高度矩形+编号圆+上升箭头
   - T34 价值链 (`drawValueChain`)：全高卡片+彩色顶条+编号+箭头连接

2. **智能匹配系统 (`recommendLayout`)**
   - 关键词检测：10类逻辑关键词（时间/流程/层级/循环/总分/漏斗/基础/下行/进阶/链式）
   - 结构特征加分：条目数2→流程+2，条目数3→循环+2/金字塔+1，条目数4→循环+1，条目数≥5→时间轴+1
   - 默认回退：≤4条目→总分结构，≥5条目→时间轴
   - 返回：{ layout, score, allScores, reason }

3. **双主题支持**
   - 所有10种布局支持 `telecom-red` 和 `executive-blue` 两种主题
   - 通过 `{ theme: 'telecom-red' | 'executive-blue' }` 参数切换
   - 主题配色对象含16个色值（primary/accent/iceLight/iceMid/border/text/muted/highlight/positive/negative等）

4. **与diagram-drawing技能协作**
   - 原则：能用原生形状的优先用原生（保证可编辑性）
   - 复杂决策流程/泳道图/思维导图/鱼骨图 → 调用diagram-drawing生成PNG嵌入PPT
   - diagram-drawing输出PNG/SVG，支持23种图表类型（Draw.io引擎20种+Excalidraw引擎3种）

5. **技术特性**
   - 全部使用pptxgenjs原生形状（RECTANGLE/OVAL/TRAPEZOID/CHEVRON/RIGHT_ARROW等）
   - 所有形状在PowerPoint中完全可编辑（非图片嵌入）
   - `create(pres)` 工厂模式，传入pptxgenjs实例后返回全部函数
   - 支持shadow()轻阴影效果、rectRadius圆角、安全边界约束
