### 1.2 配色使用原则

**红色系绝对主导**：红色出现3554次 vs 蓝色713次，比例为5:1。

**三色黄金法则**：
- **黑+红+白** = 电信PPT基础三色（覆盖90%+场景）
- **黄** = 数据/重点高亮色（第4高频色，必须加入设计体系）
- **蓝** = 辅助信息色（仅限次要标注、链接、说明性内容）

**禁止使用的颜色**：
- 紫色 / 橙色 / 绿色大面积 → 与电信风格冲突
- 蓝色大面积做主色 → 电信主色是红色系，蓝色只是辅助

## 2. 字体规范

| 用途 | 字体 | 大小 | 字重 | 实测频率 |
|---|---|---|---|---|

| 辅助文字 | 微软雅黑 | 10pt | Regular | 2102次 |
| 小标题 | 微软雅黑 | **14pt** | Bold | 1799次 |
| 模块标题 | 微软雅黑 | **16pt** | Bold | 1587次 |
| 注释/备注 | 微软雅黑 | 9pt | Regular | 916次 |
| 小字说明 | 微软雅黑 | 8pt | Regular | 602次 |
| 标签文字 | 微软雅黑 | 11pt | Regular | 461次 |
| 页面主标题 | 微软雅黑 | 20-24pt | Bold | 277/244次 |
| 大标题 | 微软雅黑 | 28-32pt | Bold | 低频 |

**字体栈**: `"Microsoft YaHei", Arial, sans-serif`

**辅助字体**（零星使用）：仿宋（公文引用）、华文细黑（特殊标题）、黑体（大标题）、楷体（引用）

### 2.2 字号档位速查

```
标题层: 28-32pt (大标题) → 20-24pt (页面标题) → 16pt (模块标题)
内容层: 14pt (小标题) → 12pt (正文) → 10-11pt (辅助)
注释层: 8-9pt (备注/说明)
数字目标: 12-14pt Bold + 红/黄高亮
```

### 2.3 与v1.0的修正

> v1.0中规定正文8-10pt偏小，实测电信PPT正文以**12pt**为主流，14pt为小标题档。
> 本次修正向上调整字号档位，贴合实际使用习惯。

## 4. 布局规范

### 4.1 通用原则
- **画布**: 16:9 (33.87×19.05cm / 10"×5.625")
- **左右边距**: 0.25"（约0.64cm）
- **内容区域**: 9.5" 宽（约24.13cm）
- **3栏布局为首选**: 每栏约 2.85-3.0" 宽，栏间距 0.25-0.37"
- **标题位置**: 顶部 y=0~1cm, x=1~2cm, 宽17~30cm
- **内容起始**: 左起1~3cm，纵向10cm起分布

### 4.2 背景模式（1764份实测发现）

- **全背景图模式**: 非常普遍（218页使用背景图片/纹理），电信PPT普遍采用模板底图
- **母版模板**: "省公司年会发言001"使用72次（最常用母版），另有"空白"版式（56次）
- **纯色背景**: 较少见，多数页面有图片/渐变底图

> 注意：生成PPT时优先使用纯色背景+装饰元素模式，除非用户提供背景图片。

### 4.3 Shape构成统计（实测）

| 类型 | 次数 | 说明 |
|---|---|---|
| AUTO_SHAPE | 864 | 自选图形，最常见 |
| TEXT_BOX | 769 | 文本框 |
| GROUP | 165 | 组合图形 |
| PICTURE | 146 | 图片 |
| TABLE | 73 | 表格 |
| CHART | 38 | 图表 |
| FREEFORM | 49 | 自由曲线 |

L1 标题栏 (深红通栏, y≈0, h≈0.5")

## 4.5 安全边界强制约束（v5.0 pptxgenjs 适配）

> **所有生成的材料必须严格遵守此约束，确保内容不跨出画布、不重叠。**
> **v5.0 起统一使用 pptxgenjs（JavaScript）作为生成引擎。**

### 4.5.1 画布定义

| 参数 | 值 | pptxgenjs 写法 |
|---|---|---|
| 画布尺寸 | 13.33"×7.50"（16:9） | `pres.layout = 'LAYOUT_WIDE'` |
| 安全左边距 | ≥ 0.45" | `x ≥ 0.45` |
| 安全右边距 | ≥ 0.45" | `x + w ≤ 12.88` |
| 可用宽度 | ≤ 12.43" | — |

### 4.5.2 页头页尾保留区

**通用主题**（academic-red / business-navy / tech-cyan / warm-amber / minimal-mono）：

| 区域 | Y范围 | 说明 |
|---|---|---|
| 导航栏保留区 | 0 ∼ 1.85" | 导航条+页面标题区 |
| 页脚保留区 | 7.10" ∼ 7.50" | 页脚区 |
| **有效内容区** | **1.85" ∼ 7.10"** | 所有正文、卡片、表格、图形必须在此范围内 |

**电信主题**（telecom-red）：

| 区域 | Y范围 | 说明 |
|---|---|---|
| 顶部横条保留区 | 0 ∼ 0.52" | 深红标题通栏 + 金线，禁止放置内容元素 |
| 底部横幅保留区 | 7.05" ∼ 7.50" | 底部红色总结横幅，禁止放置内容元素 |
| **有效内容区** | **0.55" ∼ 7.05"** | 所有正文、卡片、表格、图形必须在此范围内 |

> **关键差异**：电信主题有效内容区起始于 y=0.55"（无导航栏空间浪费），通用主题起始于 y=1.85"。电信主题可用内容高度更大（6.50" vs 5.25"），但底部横幅也更大。

### 4.5.3 越界预防规则

1. **禁止硬编码绝对定位**：所有元素位置必须基于可用空间动态计算，不得使用固定 y 值叠加
2. **内容均分机制**：多条目列表/卡片必须用 `(可用高度) / (条目数)` 计算每条高度，而非固定间距
3. **底部元素上移优先**：当内容总量超出有效区时，优先压缩底部间距、减小字号（最小 7pt），而非跨越底部保留区
4. **重叠检测意识**：同一页面的形状/文本框禁止出现坐标区间重叠，两个元素的 `[x, x+w]` 和 `[y, y+h]` 区间不得交叉
5. **字数换行预估**：中文每字符约 0.14"（10pt），英文每字符约 0.08"。单行文本宽度 = 字数 × 字符宽度，超出容器宽度时强制换行并预留额外行高
6. **坐标单位**：pptxgenjs 中所有坐标单位为英寸（"），无需 `Inches()` 转换

### 4.5.4 多栏/网格安全公式

```
三栏布局:
  栏宽 = (可用宽度 - 栏间距×2) / 3
  栏间距 = 0.25"∼0.30"
  栏高 = 有效内容区高度

  // pptxgenjs 写法
  const CW = (W - 0.8 - 0.6) / 3;  // W = 10 (LAYOUT_WIDE)

2×2网格:
  模块宽 = (可用宽度 - 水平间距) / 2
  模块高 = (有效内容区高度 - 垂直间距) / 2
  水平间距 = 0.28"∼0.32"
  垂直间距 = 0.30"∼0.35"

  // pptxgenjs 写法
  const CW = (W - 0.8 - 0.3) / 2;
  const CH = (safeH - 0.3) / 2;  // safeH 依主题不同

VS对比布局:
  左侧对比区宽 ≤ 4.0"，右侧表格区 = 剩余宽度
```

### 4.5.5 生成引擎（v5.0 统一 pptxgenjs）

| 场景 | 引擎 | 说明 |
|---|---|---|
| **所有场景** | **pptxgenjs (JavaScript)** | v5.0 起统一使用，不再使用 python-pptx |
| 常规材料（宣贯/汇报/培训/通报多页） | pptxgenjs | 使用 `assets/telecom-boilerplate.js` 或 `assets/boilerplate.js` |
| 单页总视图/架构图 | pptxgenjs | 同上 |

> **v5.0 变更**：原 v4.x 使用 python-pptx + 底版2.pptx 生成常规材料，v5.0 起统一切换为 pptxgenjs。底版2.pptx 保留作为 `assets/` 参考资产，不再作为生成引擎的母版输入。

### 4.5.6 生成后自检清单

每页生成完成后必须执行：

```
□ 通用主题：所有元素 y ≥ 1.85 且 y+h ≤ 7.10
□ 电信主题：所有元素 y ≥ 0.55 且 y+h ≤ 7.05
□ 所有元素 x ≥ 0.45 且 x+w ≤ 12.88
□ 同页内无形状重叠（review 每个元素的 x/y/w/h）
□ 多条目均分后各行高度一致（差值 < 0.05"）
□ 文字未贴边（与卡片边框间距 ≥ 0.08"）
□ 生成文字 ≥ 7pt（电信正文 12pt）
```

## 5. 内容呈现规范

### 5.1 必须遵守
- **数字目标红色加粗**: 如 `≥35%`、`≥90%`、`≥3场` 等所有量化指标
- **黄色高亮数据**: 重要数据/数值可用 `#FFFF00` 底色标注（第4高频，已验证）
- **简洁优先**: 每条不超过 15 字，拒绝长句
- **三栏对称**: 内容分三栏时保持结构均衡
- **标语一行**: 底部标语控制在 1 行以内
- **三角装饰**: 左侧红色竖条标记条目层级
- **量化指标格式**: 百分比(%)最常见，其次金额(元)，再次万/亿级规模

### 5.2 量化指标呈现标准（基于实测）

| 指标类型 | 出现频率 | 推荐呈现方式 |
|---|---|---|
| 百分比(%) | 75次 | 红色加粗 + 可选黄色底标 |
| 金额(元) | 43次 | 红色加粗 + "万"单位换算 |
| 万级规模 | 26次 | 大字号红色 + 单独卡片 |
| 人数/户数 | 22次 | 指标卡样式 |
| 次数 | 5次 | 辅助标注 |

### 5.3 排版示例
```
深红标题（22pt Bold）
    红金渐变线
副标题 / 模块标签（10-13pt）
    卡片:
    ┌──────────────────────┐
    │  浅粉标题栏（标题）    │
    │──────────────────────│
    │ ▌ 标签A（红色加粗）    │
    │   描述文字（灰）       │
    │ ▌ 标签B              │
    │   关键数字≥35%（红加粗）│
    │   [黄色底标重点值]     │
    └──────────────────────┘
```

## 6. 封面设计模式（20份PPT实测）

### 6.1 内部电信PPT封面（70%居中全幅）

| 封面类型 | 占比 | 特征 |

| **居中全幅** | 70% | 标题居中偏上(y=4-7cm)，字号37-48pt，副标题/日期居中偏下(y=9-13cm) |

```
Shape1: 标题（36-48pt Bold微软雅黑，居中偏上）

Shape3: 日期（14-20pt，居中最下）

[Shape5: Logo/背景图片]
```

**极简封面**（2-3个Shape，无背景图片、无装饰图形）：

## 9. 表格呈现规范

### 9.1 表格尺寸标准

| 表格类型 | 宽度 | 行数 | 列数 | 位置 |
