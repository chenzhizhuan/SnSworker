# 风格记忆层 (Layer 3 · Style Memory)

> v6.0 新增 | 优先级：Phase 3

## 1. 解决什么问题

每次生成PPT时都能"记住"用户的写作风格、企业规范和版面习惯，用得越多越像用户，而不是每次都重新来过。

## 2. 三级记忆体系

```
临时微调 (REFINEMENT_LOG.md)  ← Layer 5 微调沉淀
    │
    ├─ 同类3次 → 升级为固定规范
    │
    ├──→ WRITING_STYLE.md    — 写作风格（句式、措辞、语感）
    ├──→ CORPORATE_SPEC.md   — 企业规范（配色、字体、术语、模板）
    └──→ LAYOUT_HABITS.md    — 版面习惯（间距、对齐、卡片样式、条件格式）
```

### 2.1 WRITING_STYLE.md — 写作风格

记录用户偏好的文字表达方式。

```markdown
# 写作风格

## 句式偏好
- 短句为主，每条≤15字（电信体）
- 行动句优先，使用"确保""力争""推进"
- 数字目标前置，如"全年力争完成2.5万户"
- 禁用词：杜绝、严禁（过于生硬）

## 措辞偏好
- 用"牵引"代替"引导"
- 用"穿透"代替"深入"
- 用"闭环"代替"完成"
- 用"赋能"代替"帮助"

## 语感偏好
- 正式汇报：庄重简洁，少用修饰
- 宣贯材料：口语化，多用短句排比
- 数据汇报：数字先行，结论靠后
```

### 2.2 CORPORATE_SPEC.md — 企业规范

记录企业/部门的固定规范，不可随意变更。

```markdown
# 企业规范

## 视觉规范
- 主色：#C00000（电信深红）
- 辅色：#FFD700（金色装饰线）
- 禁用色：蓝色不得大面积做主色
- 正文字体：Microsoft YaHei 12pt
- 标题字体：Microsoft YaHei Bold 14-16pt

## 术语规范
- "5G-A" 不写 "5GA" 或 "5G-A版"
- "存量" 不写 "老用户"
- "升套" 不写 "升级套餐"
- "政企" 不写 "企事业"
- "地市" 不写 "分公司"（在全省语境中）

## 模板规范
- 封面必须带深红通栏
- 页脚格式：左=作者·单位，右=章节·页码
- 表头必须深红底白字
- 数字目标必须红色加粗+黄底
```

### 2.3 LAYOUT_HABITS.md — 版面习惯

记录用户反复出现的版面偏好，由微调闭环自动沉淀。

```markdown
# 版面习惯

## 间距偏好
- 卡片间距：0.25"（默认0.2"）
- 章节间留白：0.15"（默认0.12"）

## 排版偏好
- §2.1 标题始终加粗（来自3次微调升级）
- §2.2 前三名标红加粗（来自3次微调升级）
- §2.3 表格交替行用浅粉色（来自2次微调）
- §2.4 KPI数字字号≥28pt（来自1次微调）

## 条件格式偏好
- 排名类数据：Top3红色加粗，末3灰色
- 涨跌类数据：涨绿跌红
- 百分比数据：低于X%标红预警

## 图表偏好
- 柱状图：默认纵向，间距80%
- 表格：默认深红表头 + 交替行粉白
```

### 2.4 REFINEMENT_LOG.md — 微调记录

记录每次微调的临时日志，追踪升级进度。同类判定规则见 `refinement-mapping.md` §5.2，记忆文件示例见 `refinement-mapping.md` §5.3。

```markdown
# 微调记录

## 文字格式 | 标题加粗 | count: 3/3 → 已升级 ↑
- 来源：专线经营分析PPT(7/10)、风控季度汇报PPT(7/10)、5G-A规模PPT(7/10)
- 操作：所有页面标题 bold:true
- 已升级到 LAYOUT_HABITS.md §2.1

## 数据强调 | 前三名标红 | count: 2/3
- 来源：专线经营分析PPT(7/10)、5G-A规模PPT(7/10)
- 操作：排名≤3时 color:'C00000' bold:true
- 下次再触发1次将升级为固定规范
```

## 3. 记忆读写流程

### 3.1 启动时读取

每次生成PPT时（Step 1），按优先级读取记忆：

```
1. CORPORATE_SPEC.md    → 强制遵守，不可覆盖
2. WRITING_STYLE.md     → 文字生成时应用
3. LAYOUT_HABITS.md     → 布局生成时应用
4. REFINEMENT_LOG.md    → 检查待升级条目
5. evolution-log.md     → 已学会的能力（v5.0原有）
```

### 3.2 生成后写入

| 事件 | 写入目标 | 内容 |
|------|---------|------|
| 用户微调（单次） | REFINEMENT_LOG.md | 操作类型、目标、count+1 |
| 微调升级（3次） | LAYOUT_HABITS.md / WRITING_STYLE.md | 升级为固定规范 |
| 用户提供模板 | CORPORATE_SPEC.md + layouts/ | 视觉规范 + Layout Map |
| 用户口头偏好 | WRITING_STYLE.md | 措辞/句式偏好 |
| 新能力学会 | evolution-log.md | 模式/修复/新增（v5.0原有） |

### 3.3 冲突处理

```
CORPORATE_SPEC > LAYOUT_HABITS > WRITING_STYLE > REFINEMENT_LOG > 默认值
```

- 企业规范与企业习惯冲突时，以企业规范为准
- 记忆之间冲突时，以更新的记忆为准
- 用户本次显式指令 > 所有记忆

## 4. 增量沉淀策略

### 4.1 自动沉淀

无需用户主动操作，系统自动从以下来源提取记忆：

| 来源 | 提取方式 | 沉淀目标 |
|------|---------|---------|
| 微调指令 | Layer 5 解析 | REFINEMENT_LOG → LAYOUT_HABITS |
| 用户反馈 | "每次都这样" | 直接写入 LAYOUT_HABITS |
| 对比差异 | 本次 vs 上次偏好 | 增量更新 WRITING_STYLE |
| 模板使用 | 频率统计 | CORPORATE_SPEC |

### 4.2 显式沉淀

用户可以主动要求沉淀：

| 用户说法 | 操作 |
|----------|------|
| "记住这个风格" | 当前PPT的风格写入 WRITING_STYLE |
| "这是我们的企业规范" | 提取规范写入 CORPORATE_SPEC |
| "以后表格都这样排" | 写入 LAYOUT_HABITS |
| "更新电信PPT技能" | 按v5.0原有流程更新 evolution-log |

### 4.3 沉淀确认

自动升级（3次微调→固定规范）时需告知用户：

```
📋 风格记忆升级

检测到"标题加粗"已连续3次微调，已自动升级为版面固定规范。
已写入 LAYOUT_HABITS.md §2.1。

如需取消，请说"取消标题加粗习惯"。
```

## 5. 权重衰减

详见 `refinement-mapping.md` §5.4。

| 时间 | 权重 | 行为 |
|------|------|------|
| 1周内 | 1.0 | 自动应用 |
| 1-2周 | 0.8 | 自动应用，但新规范可覆盖 |
| 2-4周 | 0.5 | 提示用户确认 |
| 1-3月 | 0.3 | 不主动应用，用户提及时恢复 |
| 3月以上 | 0.1 | 归档，仅搜索可检索 |

CORPORATE_SPEC 不受衰减影响，始终权重 1.0。

## 6. 记忆文件存储位置

记忆文件存储在技能目录下的 `memory/` 子目录：

```
telecom-ppt-master/
├── memory/                      # v6.0 新增
│   ├── WRITING_STYLE.md         # 写作风格
│   ├── CORPORATE_SPEC.md        # 企业规范
│   ├── LAYOUT_HABITS.md         # 版面习惯
│   └── REFINEMENT_LOG.md        # 微调记录
├── layouts/                     # Layer 2 模板存储
├── references/
├── assets/
└── scripts/
```

## 7. 与各层的交互

| 交互层 | 关系 |
|--------|------|
| Layer 1 · 数据智能 | 自动点评的文字风格从 WRITING_STYLE 获取 |
| Layer 2 · 模板锚定 | 企业模板的视觉规范自动沉淀到 CORPORATE_SPEC |
| Layer 4 · 创意设计 | 创意方案需在记忆规范范围内推荐 |
| Layer 5 · 精控执行 | 微调沉淀是记忆的主要输入源 |
