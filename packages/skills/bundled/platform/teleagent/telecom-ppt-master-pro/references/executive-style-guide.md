# 高管座谈会设计体系

> 基于2026年安徽公司总经理座谈会三份发言材料（市场部77页、王磊副总53页、李新颖总55页）深度拆解提取。
> 本文件是电信PPT大师 v7.0 核心新增能力，专门服务于总经理座谈会/半年会/经营复盘等高管级材料场景。
> 当用户要求生成"座谈会材料"、"半年会发言材料"、"高管汇报材料"、"经营复盘"、"总经理座谈会"时激活本体系。

## 一、核心配色体系（蓝色主导 + 红色强调）

### 1.1 配色总览

与 v6.0 的红色主导体系（telecom-red）根本性不同，座谈会材料使用**蓝色主导 + 红色强调**的双色体系：

| 角色 | 色值 | 名称 | 用途 | 数据来源 |
|---|---|---|---|---|
| `#0070C0` | **电信蓝（主色）** | 蓝色模块标签、标题栏底、正常增长数据、柱状图主填充 | 市场部P2页#1070C0出现55次，王磊P3页出现62次 |
| `#0055B8` | 电信深蓝 | 次级标题、导航栏文字、强调性蓝色 | 市场部多页出现#004090 |
| `#5090D0` | 电信亮蓝 | 辅助说明文字、趋势线、图表辅助色 | 市场部P2三栏使用 |
| `#90C0E0` | 浅蓝 | 背景区块、表格隔行、信息面板底色 | 市场部P2频繁出现 |
| `#C00000` | **电信红（强调色）** | 负增长数据、核心结论关键词、警示标注、负拉动指标 | 三份PDF封面+数据页 |
| `#D6001F` | 品牌红 | 封面标题、特殊强调 | 市场部/王磊封面 |
| `#FFD700` | 金色 | 渐变装饰、指标达标标注 | 封面渐变飘带 |
| `#FFD166` | 暖金 | 数字标注、收入亮点 | 数据卡片 |
| `#70B040` | 绿色 | 正增长指标、达标标注、正向数据 | 市场部P3出现 |
| `#FFFFFF` | 白色 | 全局背景、卡片底色 | 全量通用 |
| `#F0F0F0` | 浅灰 | 页面背景、信息区块 | 全量最高频底色 |
| `#000000` | 纯黑 | 正文文字 | 全量最高频文字色 |
| `#888888` | 辅助灰 | 注释、页脚、数据来源说明 | 通用 |

### 1.2 配色使用原则

**蓝主红辅法则**：
- **蓝色 = 正常/正面**：标题、导航、正常增长数据（+X%）、柱状图主色、模块进度标签
- **红色 = 异常/负面/核心强调**：负增长数据（-X%）、负拉动指标、核心结论关键词、警示框
- **绿色 = 达标/优秀**：完成时序、达标标注、标杆案例
- **金色/暖金 = 装饰与特殊标注**：封面渐变、达标率≥100%的高亮

**正负双色编码规范**：

| 数据类型 | 颜色 | 格式 | 示例 |
|---|---|---|---|
| 正增长 | `#0070C0` 蓝色 | `+{数值}` | `+0.53PP` |
| 负增长 | `#C00000` 红色 | `-{数值}` | `-1.16PP` |
| 持平/中性 | `#000000` 黑色 | `{数值}` | `0.06PP` |
| 达标 | `#70B040` 绿色 | `{数值}%` | `51.0%` |
| 未达标/预警 | `#C00000` 红色 | `{数值}%` | `42.3%` |
| 核心结论关键词 | `#C00000` 红色加粗 | 关键词 | **剪刀差** |

### 1.3 与 v6.0 telecom-red 体系的切换规则

| 场景 | 使用体系 | 触发关键词 |
|---|---|---|
| 总经理座谈会/半年会/经营复盘 | **executive-blue**（本体系） | "座谈会"、"半年会"、"复盘材料"、"高管发言" |
| 日度运营/宣贯/月报/标准化运营 | telecom-red（v6.0 原有） | "运营PPT"、"宣贯"、"月报"、"标准化" |
| 两者均有 | 优先 executive-blue，用户指定切换 | — |

> **重要**：executive-blue 体系不替换 telecom-red，而是作为并行体系。在 `references/themes.md` 中注册为 `executive-blue` 主题，与 `telecom-red` 并列。当检测到座谈会/半年会场景时自动切换。

## 二、封面设计（两种风格）

### 2.1 风格A：正式白底 + 渐变飘带（市场部/王磊式）

```

│                                                   │
│                                                   │

│              {主标题第二行}               ← 28-32pt 红色加粗居中
│                                                   │
│              ═══════════════════════              │  ← 红→橙→金渐变飘带 h=0.15"
│              {副标题/单位}                        │  ← 16pt 灰色居中
│              {日期}                               │  ← 14pt 灰色居中

└─────────────────────────────────────────────────┘
```

**设计要素**：
- 背景纯白 `#FFFFFF` 或极浅灰 `#F8F8F8`
- 标题用红色 `#C00000` 28-32pt 微软雅黑 Bold
- 标题下方加红→橙→金渐变线（width=3", h=0.06"）
- 底部装饰条为红橙黄三段渐变（从左到右：`#C00000` → `#E04040` → `#FFD700`）
- 左上电信Logo占位区（宽1.2" × 高0.5"）
- 右上天翼5G/AI品牌Logo占位区
- 无大面积背景图片，以文字+装饰线为主

**实现要点（pptxgenjs）**：

- 用户未指定 → 默认风格A

## 三、导航系统（模块进度标签）

### 3.1 顶部导航栏结构

座谈会材料的标志性设计：顶部导航栏包含**模块进度标签**，是区别于普通电信PPT的核心特征。

```
┌──────────────────────────────────────────────────────────────┐
│ [蓝色标签]总体收入（1/5）│  {页面标题}  │ [天翼AI品牌Logo]  │ ← h=0.45"
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                        内容区域                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

**导航栏三段式结构**：

| 段位 | 内容 | 位置 | 样式 |
|---|---|---|---|
| 左段 | 模块进度标签 | x=0, w=3.0" | 蓝色底 `#0070C0` + 白字 11pt Bold |
| 中段 | 当前页面标题 | x=3.0", w=8.0" | 白底 + 深色文字 13pt Bold |
| 右段 | 品牌Logo占位 | x=11.0", w=2.33" | 天翼AI/5G品牌Logo |

### 3.2 模块进度标签命名规则

```
格式：{模块名}（{当前页}/{模块总页数}）
实例：
  总体收入（1/5）    → 总体收入模块第1页，共5页
  净计费收入（2/4）  → 净计费收入模块第2页，共4页
  分公司画像（1/4）  → 分公司画像模块第1页，共4页
  上半年复盘（3/4）  → 上半年复盘模块第3页，共4页
  重点业务（1/2）    → 重点业务模块第1页，共2页
  重点市场（3/4）    → 重点市场模块第3页，共4页
```

**实现要点**：

## 四、核心布局模式

### 4.1 结论先行数据支撑布局（最核心模式）

座谈会材料最重要的布局原则：**文字结论在上，图表/表格在下**。每页先给出核心判断，再用数据支撑。

```
┌────────────────────────────────────────────────────┐
│ [导航栏] 总体收入（1/5）│ 截至6月收入份额...       │
├────────────────────────────────────────────────────┤
│ p {核心结论句}                                     │ ← 蓝色▶标记 + 12pt 结论文字
│   Ø {判断1，含数据}                                │ ← 蓝色子项标记
│   Ø {判断2，含数据}                                │
├────────────────────────┬───────────────────────────┤
│                        │                           │
│   {图表A：趋势图}      │  {图表B：排名/对比图}     │
│                        │                           │
│   标题：收入份额趋势(%) │  标题：分公司份额变化(PP) │
│                        │                           │
├────────────────────────┴───────────────────────────┤
│ ▌蚌埠、六安份额提升0.5PP以上  ▌淮北、芜湖份额下降  │ ← 红色竖条+结论
└────────────────────────────────────────────────────┘
```

**设计规范**：
- 结论区高度：约1.5"（占内容区25%）
- 图表区：剩余空间的70%，左右分栏或上下分栏
- 底部结论条：0.4"高，蓝/红竖条标记正/负面结论
- 结论文字每条≤30字，必须含数据

### 4.2 分公司画像 2×2 网格布局

座谈会标志性布局：每页展示4个分公司的画像卡片，每张卡片含趋势图+明细表+一句话结论。

```
┌──────────────────────┬──────────────────────┐
│  {公司A名}           │  {公司B名}           │
│  p 增幅X%，全省第N   │  p 增幅X%，全省第N   │  ← 结论行
│  • 关注重点产品：... │  • 关注重点产品：... │  ← 洞察子项
│  • 关注细分市场：... │  • 关注细分市场：... │
│ ┌──────────────────┐ │ ┌──────────────────┐ │
│ │ 逐月收入趋势图    │ │ │ 逐月收入趋势图    │ │  ← 趋势折线图
│ └──────────────────┘ │ └──────────────────┘ │
│ ┌──────────────────┐ │ ┌──────────────────┐ │
│ │ 套餐/产品 | 贡献PP│ │ │ 套餐/产品 | 贡献PP│ │  ← 迷你明细表
│ │ 融合     | 1.0   │ │ │ 融合     | 1.3   │ │
│ │ 单品     | 0.9   │ │ │ 单品     | 0.5   │ │
│ └──────────────────┘ │ └──────────────────┘ │
├──────────────────────┼──────────────────────┤
│  {公司C名}           │  {公司D名}           │
│  （同上结构）         │  （同上结构）         │
└──────────────────────┴──────────────────────┘
```

**尺寸规范**（13.33"×7.50"画布）：
- 导航栏：y=0, h=0.45"
- 4张卡片区域：y=0.60", h=6.40"
- 每卡宽度：(12.43 - 0.3) / 2 = 6.065"
- 每卡高度：(6.40 - 0.2) / 2 = 3.10"
- 卡片间距：水平0.3", 垂直0.2"
- 卡片圆角矩形，白色底 `#FFFFFF`，淡灰描边 `#E0E0E0` 1pt，轻阴影
- 卡片标题行：公司名12pt Bold + 增幅排名 11pt 蓝/红色
- 趋势图高度：1.0"，迷你表高度：1.2"

### 4.6 四象限分析布局（双维度矩阵）

```

## 六、特殊设计元素

### 6.1 正负分组虚线框

用虚线框将正面/负面分公司分组标注。

```
┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐  ┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐
   份额提升分公司          份额下降分公司
  蚌埠 六安 淮南          淮北 芜湖 阜阳
  合肥 池州 安庆          滁州
   +0.5PP以上             -0.3PP以下
─ ─ ─ ─ ─ ─ ─ ─ ─   ─   ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─
  蓝色虚线框 #0070C0        红色虚线框 #C00000
```

### 6.2 项目符号系统

| 用途 | 符号 | 颜色 | 实现 |
|---|---|---|---|
| 核心结论 | `p`（实心三角箭头→右） | `#0070C0` 蓝色 | `►` 或 pptxgenjs triangle |
| 子判断/关注点 | `Ø`（圆形空心） | `#0070C0` 蓝色 | `○` 或 `•` |
| 举措编号 | `举措1` `举措2` | `#0070C0` 蓝色底白字标签 | 蓝色圆角矩形标签 |
| 正向结论竖条 | `▌` | `#70B040` 绿色 / `#0070C0` 蓝色 | 左侧竖条矩形 |
| 负向结论竖条 | `▌` | `#C00000` 红色 | 左侧竖条矩形 |
| 关注编号 | `Ø 关注一：` `Ø 关注二：` | `#0070C0` 蓝色 | 文字+冒号 |

### 6.3 指标卡片（KPI卡）

```
┌──────────────┐
│ 56.6亿       │ ← 数值 20pt Bold 蓝色
│ 净计费规模   │ ← 标签 10pt 灰色
│ 25年规模     │ ← 对比 9pt 浅灰
└──────────────┘
```
- 卡片底：白色 `#FFFFFF`
- 卡片描边：浅灰 `#E0E0E0` 0.75pt
- 轻阴影：blur=3, offset=1, opacity=0.08
- 数值颜色根据正负：蓝色正/红色负

### 6.4 达标进度标注

```
利润完成进度趋势
4.0% ╱     8.8% ╱  9.9% ╱  5.1% ╱  11.1% ╲  10.4% ╱
 1月       2月      3月     4月      5月       6月
                    ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ 达标线7%
```

- 达标线：绿色虚线 `#70B040`
- 达标月：蓝色标注
- 未达标月：红色标注

## 七、字体与字号系统

### 7.1 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 全局中文 | 微软雅黑 | 与 telecom-red 一致 |
| 全局英文/数字 | Arial | 数字指标用Arial更清晰 |
| 公文引用 | 仿宋（可选） | 政治学习类内容 |

### 7.2 字号档位

```
封面标题: 28-32pt Bold（红色/金色）
页标题:   13pt Bold（导航栏中段）
模块标题: 18pt Bold（章节过渡页）
KPI数值:  20-24pt Bold（蓝色/红色）
结论文字: 11-12pt Regular
子判断:   10-11pt Regular
表格表头: 10pt Bold
表格正文: 9-10pt Regular
图表标签: 8-9pt Regular
注释说明: 8pt Regular（灰色）
```

### 7.3 与 telecom-red 的字号差异

| 元素 | telecom-red | executive-blue | 原因 |
|---|---|---|---|
| 页标题 | 20-24pt | 13pt（导航栏内） | 座谈会导航栏已固定位置 |
| 正文 | 12pt | 11-12pt | 高密度多面板需更紧凑 |
| 结论句 | 无固定 | 11-12pt 带标记 | 座谈会结论先行需要明确层级 |
| 注释 | 9pt | 8pt | 数据来源/统计口径标注 |

## 八、安全边界规范

### 8.1 executive-blue 主题安全区域

| 区域 | Y范围 | 说明 |
|---|---|---|
| 导航栏保留区 | 0 ∼ 0.50" | 蓝色模块标签+页面标题栏 |

| **有效内容区** | **0.55" ∼ 7.10"** | 所有正文、图表、表格、卡片 |

### 8.2 多面板间距规范

| 布局类型 | 水平间距 | 垂直间距 | 最小卡片高 |
|---|---|---|---|
| 2×2 网格 | 0.30" | 0.20" | 2.8" |
| 左右双栏 | 0.35" | — | — |
| 三组纵向分栏 | 0.30" | — | 5.0" |
| 四KPI卡片 | 0.20" | — | 1.0" |
| 仪表盘多面板 | 0.25" | 0.20" | — |

### 8.3 越界预防补充

在 v6.0 `style-guide.md` §4.5 基础上补充：
- 图表标题必须在图表上方0.15"处，字号≤10pt
- 迷你表格列宽按内容最长值+0.3"计算
- 分公司名称横向排列时，16个分公司需分两行或缩小字号至7pt
- 结论区文字超出2行时，需缩减措辞或拆分为多条短句

## 九、页面结构模板速查

### 9.1 座谈会材料标准页面结构

| 页面类型 | 导航栏 | 内容结构 | 适用场景 |
|---|---|---|---|
| 封面 | 无 | 标题+装饰带+单位日期 | P1 |
| 目录 | 无 | 大数字+章节标题 | P2 |
| 章节过渡 | 无 | 大数字01/02+章节名 | 章节切换页 |
| 结论先行数据页 | 有（模块标签） | 结论→图表→底部判断 | 经营收入分析 |
| 分公司画像页 | 有 | 2×2网格（4公司） | 分公司逐个画像 |
| 三组分栏页 | 有 | 三组柱图+各自结论+汇总 | 县公司/区域中心分组 |
| 仪表盘页 | 有 | KPI行+主图表+三关注 | 市场概况 |
| 四象限矩阵页 | 有 | 散点矩阵+象限标注+结论 | 完成进度交叉分析 |
| 工作部署页 | 有 | 举措列表+优秀实践 | 下半年工作安排 |
| 总结表态页 | 无 | 目标+口号+装饰 | 末页 |

### 9.2 典型座谈会deck结构（15-20页）

```
P1  封面（风格A或B）
P2  目录（2-3大章节）
P3  章节过渡1（01 上半年复盘）
P4  总体收入概览（仪表盘布局）
P5  收入份额分析（结论先行+正负柱图）
P6  预算完成分析（左右双栏：进度图+排名表）
P7  分公司收入增幅（正负双色柱图+分组虚线框）
P8  分公司画像1-2（2×2网格×2页）
P9  分公司画像3-4（2×2网格×2页）
P10 县公司分析（三组纵向分栏）
P11 重点业务分析（多面板仪表盘）
P12 重点市场分析（四象限矩阵+关注点）
P13 章节过渡2（02 下半年重点工作）
P14 工作视图（目标+路径）
P15 举措1-2（工作部署页）
P16 举措3-4（工作部署页）
P17 优秀实践案例
P18 总结表态（目标+口号+装饰）

- 提供座谈会相关Excel/数据并要求"生成发言材料"
