## 一、经营分析会通报体（核心风格）

### 1.1 总体特征

- **口语化但专业**：介于正式公文和口头汇报之间，不是"红头文件"口气，而是"数据说话"的务实风格
- **先总后分**：先给总体结论，再逐项展开
- **数字驱动**：每个判断必须跟数据，不空谈
- **点名批评**：直接点分公司名，好坏都点名
- **闭环思维**：问题→原因→举措→下一步

### 1.2 段落结构模板

```
[时间范围]，[全省总体数据]，[同比/环比变化]，[总体趋势判断]
从[维度A]看：[具体数据+判断]
从[维度B]看：[具体数据+判断]
其中[表现好的分公司]完成较好，[表现差的分公司]完成靠后/不足/承压
下一步工作要求：[具体举措1]、[具体举措2]
```

### 1.3 典型句式

#### 数据描述句

| 句式模板 | 实例句 |
|---|---|
| `{时间}，全省{指标}完成{数值}，环比{变化}({趋势判断})` | 10月，全省融合套餐725.1万，月均离网率0.69% |
| `{指标}完成{数值}，同比{变化}，环比{变化}` | 存量收入保有率104.5%，同比提升0.7PP，环比下降0.2PP |
| `看{维度}：{具体分析}` | 看过程：1-10月融合套餐各类经营动作对保有率影响整体可控 |
| `其中{子项}贡献{数值}` | 其中：高迁及业务加装等正向经营动作贡献收入1506万 |
| `{指标}趋势向好/承压/有所减缓` | 10月存量收入下降趋势向好 |

#### 分公司点评句

| 句式模板 | 实例句 |
|---|---|
| `{分公司A}、{分公司B}完成较好/靠前，{分公司C}、{分公司D}完成靠后/不足` | 亳州、铜陵、黄山完成较好，六安、芜湖、合肥完成不足 |
| `{分公司}完成较好且{附加条件}，{分公司}完成不足且{附加条件}` | 六安、宣城完成较好且提值占比高，池州、芜湖完成不足且提值占比低 |
| `{分公司}对{指标}负拉动相对较低，{分公司}负拉动相对较高（高低差{差值}）` | 池州、滁州、阜阳负拉动相对较低，蚌埠、淮南、亳州负拉动相对较高（高低差1.59PP） |
| `{分公司}整体较好，{分公司}多项指标完成靠后` | 淮南、亳州、六安、滁州整体较好，马鞍山、阜阳、宣城多项指标完成靠后 |
| `{分公司}占比高于{阈值}，{分公司}占比低于{阈值}` | 安庆、铜陵、亳州、马鞍山客户经营积分占总积分比高于45%，滁州、蚌埠、阜阳占比低于30% |

#### 问题指出句

| 句式模板 | 实例句 |
|---|---|
| `{指标}仍需进一步提升` | 仍需进一步提升刚性违约金收取 |
| `{分公司}已经低于{阈值}，{分公司}全年完成{目标}有压力` | 阜阳、宿州、亳州已经低于104% |
| `{指标}对存量收入保有贡献相对不足` | 专线对存量收入保有贡献相对不足 |
| `{指标}下降趋势有所减缓，但仍承压` | 融合存量收入保有下降趋势有所减缓 |
| `{问题}，需关注` | 低速率、单专线、低活跃专线是离网高风险群体，需关注 |

#### 整改/下一步要求句

| 句式模板 | 实例句 |
|---|---|
| `下一步工作要求：{举措1}、{举措2}，持续{目标}` | 下一步工作要求：分公司加快推进融产品的同时需坚持提值导向，避免一加一减，持续提升客户价值 |
| `需加速突破/加快推进/强化执行` | 升套提值需加速突破 |
| `重点关注/聚焦{目标}` | 重点关注融产品提值占比 |
| `后续将持续跟踪/关注{指标}` | 后续将持续跟踪活动转化对收入贡献情况 |

#### 对比/对标句

| 句式模板 | 实例句 |
|---|---|
| `{A}与{B}拍照基数相当，但{A}净计费增幅({数值})高于{B}({数值})` | 白莲坡与永固拍照基数相当，白莲坡1-9月净计费增幅11.3%高于永固-1.6% |
| `{A}好于{B}，但差距缩小` | 存量保有率好于去年同期，但差距缩小 |
| `{指标}较{上月}改善{数值}` | 环比下降806万，较9月改善196万 |

## 二、风险管控类文字风格

### 2.1 总体特征

- **客观陈述，不加情绪词**：不写"严重"、"恶劣"，只写事实
- **三段式结构**：案例简述→风险现象→整改方案→复核标准
- **责任到人/部门**：明确谁负责、何时完成
- **事前-事中-事后**是组织逻辑的核心

### 2.2 典型句式

#### 风险描述句

| 句式 | 示例 |
|---|---|
| `{时间/场景}，{主体}存在{风险行为}，涉及金额{数值}` | 2025年1-9月，某营业部在优惠活动中存在未按规范执行的行为 |
| `经核查，{事实描述}` | 经核查，部分工单存在重复派单、优惠叠加等问题 |
| `主要表现为：{风险点1}、{风险点2}` | 主要表现为：未签协议直接加固、优惠超标、未进行客户告知 |

#### 整改方案句

| 句式 | 示例 |
|---|---|
| `已要求{主体}在{时限}内完成{动作}` | 已要求该营业部在11月30日前完成全部问题工单的复核整改 |
| `制定{规范名称}，明确{具体要求}` | 制定优惠到期续约执行规范，明确折扣修复和提值占比的考核标准 |
| `纳入{考核/通报}，与{奖惩}挂钩` | 纳入月度客业条线通报，与包区积分佣金考核挂钩 |

#### 复核标准句

| 句式 | 示例 |
|---|---|
| `复核要点：{要点1}、{要点2}` | 复核要点：优惠金额是否超标、客户是否知情、协议是否签署 |
| `回头看机制：{频率}抽查{比例}` | 回头看机制：每月抽查不少于10%的问题工单整改效果 |

## 三、方案宣贯/制度解读类文字风格

### 3.1 总体特征

- 从"为什么"到"是什么"到"怎么做"
- 变化点突出（新旧对比）
- 表格占比极高（48%），文字为辅
- 分角色、分受众

### 3.2 典型句式

| 类型 | 句式模板 | 示例 |
|---|---|---|
| 背景引出 | `随着{变化}，{需要调整}` | 随着客户经营工作的深入，原有积分规则已不适用 |
| 核心变化 | `变化点{编号}：{原规则}→{新规则}，{原因}` | 变化点一：积分权重由业务量转向客户价值提升 |
| 落地要求 | `{层级/角色}需在{时限}内完成{动作}` | 各营业部需在11月15日前完成积分规则的学习宣贯 |
| 注意事项 | `特别注意：{事项}，否则{后果}` | 特别注意：新旧规则切换期间积分计算有过渡期，否则会影响12月佣金核算 |

## 四、knowcard产品培训类文字风格

### 4.1 总体特征

- **中英双语标题**（如"破局之道：智能体引领变革 / The Solution: Agents Leading..."）
- **痛点→方案→功能**三段式描述
- **专业但不艰深**：技术术语有解释，面向销售/交付人员
- 文字密度高，每页信息量大

### 4.2 典型句式

#### 产品定位

| 句式 | 示例 |
|---|---|
| `{产品名}是{基于什么技术}的{什么类型平台}，{核心价值}` | 风控合规智能体是基于大模型的企业级智能决策与合规运营平台，构建全方位的风险防御体系 |
| `致力于为{目标客户}提供{核心能力}` | 致力于为政府、企业及行业用户提供大模型应用一站式服务 |

#### 痛点描述（三栏/三痛点模式）

| 句式 | 示例 |
|---|---|
| `{痛点标签}：{现象描述}` | 响应滞后，被动应对：依赖人工规则，更新缓慢，难以应对新型、多变的欺诈手段 |
| `覆盖不全，{问题}` | 覆盖不全，经验依赖：人工审核效率低，面对海量业务数据难以做到全面覆盖 |
| `数据孤岛，{问题}` | 数据孤岛，协同困难：各系统独立运行，信息共享不畅 |

#### 功能描述（短句+要点列表）

| 句式 | 示例 |
|---|---|
| `{功能名}：{一句话描述}` | 智能风险识别与预警：毫秒级风险识别与预警，动态调整风控策略 |
| `{功能名}，{核心能力}` | 智能问答与知识管理，将风控合规从"事后补救"推向"事前预防" |
| `覆盖从{环节1}到{环节2}的全流程` | 覆盖从风险识别、合规审查，到监管报送、事件处置的全流程自动化 |

#### 案例成效

| 句式 | 示例 |
|---|---|
| `{指标}提升/缩短{百分比或绝对数}` | 每月1000余份报告的处理时间整体缩短30%-50% |
| `显著{动词}{效果}` | 显著提升专项报告处理效率，助力管理向精准化、智能化转型 |

## 四-B、商机分析诊断体（v4.0 新增）

### 4B.1 总体特征

- **诊断式结构**：先给全景数据，再拆解问题，最后给出行动路径
- **数据卡片命名**：总商机数 / 已转化 / 沉淀未转的有效商机 / 异网商机
- **细分分析格式**：{类型}:{数量}({占比}) + {原因} + {建议动作}
- **三步法句式**：分类分级→精准跟进→闭环复盘，每步含3条可执行动作

### 4B.2 典型句式

#### 数据诊断句

| 句式模板 | 实例 |
|---|---|
| `总商机{数量}户，已转化{数量}户({百分比})，沉淀未转{数量}户({百分比})，异网商机{数量}户({百分比})` | 总商机720户，已转化312户(43.3%)，沉淀未转287户(39.8%)，异网商机223户(30.1%) |
| `核心问题：近{百分比}商机沉淀未转化，异网商机占比约{百分比}` | 核心问题：近40%商机沉淀未转化，异网商机占比约30% |

#### 细分分析句

| 句式模板 | 实例 |
|---|---|
| `异网客户协议未到期：{数量}户({百分比})：{原因}，{建议}` | 异网客户协议未到期：86户(30%)：客户有转网意向但近半年协议未到期，建立到期提醒台账，到期前15天重新触达 |
| `存量加装意向未转化：{数量}户({百分比})：{原因}，{建议}` | 存量加装意向未转化：78户(27%)：客户有FTTR/看家/组网等加装需求但首次接触未成交，需二次配餐+算账 |

#### 三步行动句

| 步骤 | 句式模板 | 动作示例 |
|---|---|---|
| Step1 分类分级 | `{类型}商机 → {时限}优先跟进` | 异网/高价值商机 → 48小时优先跟进 |
| | `{类型}商机 → {时限}触达` | 到期续约商机 → 提前1个月触达 |
| | `{类型}商机 → {管理方式}` | 普通本网商机 → 纳入周计划管理 |
| Step2 精准跟进 | `{动作}、{动作}、{动作}` | 配餐到人、跟进留痕、日清日结 |
| | `{类型}商机必查{信息}` | 异网商机必查异网消费+套餐痛点 |
| | `连续{天数}未转化→{角色}介入` | 连续3天未转化→营业部主任介入复盘 |
| Step3 闭环复盘 | `转化成功→{动作}` | 转化成功→记录CRM订单号，提炼经验 |
| | `沉淀未转→{动作}` | 沉淀未转→标记归因（价格/竞品/需求） |
| | `按{周期}复盘→{动作}` | 按周复盘→分析转化率和异网占比，优化策略 |

#### 管控指标句

| 指标名 | 计算规则 | 目标值 |
|---|---|---|
| 商机转化率 | 转化成功数/有效商机数 | ≥30% |
| 异网商机占比 | 异网录入数/商机总数 | ≥35% |
| 闭环完整率 | 完整闭环数/总商机数 | ≥98% |
| 一线触点日录入量 | 全触点商机日录入指标 | ≥3单/天 |
| 48小时跟进率 | 高价值异网商机优先跟进 | 100% |

#### 核心理念句

| 句式 | 实例 |
|---|---|
| `{主题}不是终点，而是{新定位}` | 商机录入不是终点，而是经营起点 |
| `以「{步骤1}→{步骤2}→{步骤3}」三步法，把{输入}转化为{输出}` | 以「分类分级→精准跟进→闭环复盘」三步法，把每一单商机都转化为实际收入 |

### 4B.3 细分分析5类标准标签

| 序号 | 标签名 | 典型占比 | 原因模板 | 建议模板 |
|---|---|---|---|---|
| 1 | 异网客户协议未到期 | 25-35% | 客户有转网意向但近半年协议未到期 | 建立到期提醒台账，到期前{N}天重新触达 |
| 2 | 存量加装意向未转化 | 25-30% | 客户有{加装产品}等需求但首次接触未成交 | 需二次配餐+{算账方法} |
| 3 | 价格/套餐犹豫观望 | 18-22% | 觉得贵或对套餐不满意 | 需用「{算账方法}」二次说服，突出{差异化卖点} |
| 4 | 等竞品到期对比 | 10-15% | 同时了解其他运营商优惠 | 需强化我方{核心优势}差异化优势，防策反 |
| 5 | 触达未果/需求变化 | 8-12% | 多次联系不上、地址搬迁或需求已不存在 | 纳入月度清理，释放跟进精力 |

## 四-C、工具问题对比体（v4.1 新增）

### 4C.1 总体特征

- **问题导向**：用于PPT"存在问题"章节，只暴露差距、不给解决路径
- **三栏VS对比**：每栏一个工具，绿色正面数据 vs 红色反面数据，中间橙色差距标签
- **正反案例并排**：标杆（用了工具的好结果）vs 落后（没用工具的差结果）
- **底部定调**：一句话带差距倍数，红底白字

### 4C.2 典型句式

#### 数据对比句

| 句式模板 | 实例 |
|---|---|
| `用到位的 {数据}，没用的 {数据}，差距 {倍数}` | 用到位的362次，没用的16次，差距22倍 |
| `同一工具，用了的积分{高}，不用的{低}` | 同一工具，用了的积分4742，不用的30 |

#### 差距标签

| 差距类型 | 标签格式 | 示例 |
|---|---|---|
| 倍数差距 | `差距 N倍` | 差距 22倍 |
| 百分比差距 | `差距 N%` | 差距 42% |
| 定性差距 | `鸿沟` | 鸿沟 |

#### 标杆案例句

| 句式 | 实例 |
|---|---|
| `借助{工具}，{核心行为}，月均积分{数值} ↑{百分比}` | 借助附近有单精准定位商机，月均积分4742 ↑118% |
| `触客前必查{工具}，100%通过{方法}，{成果}` | 触客前必查客户画像，100%通过笔算，积分收益双提升 |

#### 落后案例句

| 句式 | 实例 |
|---|---|
| `几乎不使用{工具}，{标准动作}严重缺位，月均积分仅{数值}` | 几乎不使用附近有单，标准动作严重缺位，月均积分仅30 |
| `{工具}形同虚设，仅靠{落后行为}，触客{问题描述}` | 笔算单形同虚设，仅靠口头报价，触客无准备无方案 |

#### 底部定调句

| 句式 | 实例 |
|---|---|
| `同一个工具，用了的积分{高值}，不用的{低值}` | 同一个工具，用了的积分4742，不用的积分30 |
| `同一工具的好差差距达{N}倍，这是{版本}必须破的题` | 同一工具的好差差距达22倍甚至40倍，这是2.0必须破的题 |

### 4C.3 三色对比标识规范

| 颜色 | 色值 | 用途 | 示例 |
|---|---|---|---|
| 绿色 | `#27AE60` | 用到位的/标杆数据、好案例标题 | 用到位的 362次 |
| 红色 | `#C00000` | 没用的/落后数据、差案例标题 | 没用的 16次 |
| 橙色 | `#E67E22` | 差距标签（白字填充圆角矩形） | 差距 22倍 |

## 五、文字风格速查（按PPT类型）

### 5.1 经营分析会/月报体

| 要素 | 写法 |
|---|---|
| 语气 | 务实、数据驱动、直接点名 |
| 段落长度 | 每页1段核心文字（50-150字），配合表格/图表 |
| 数据呈现 | `{数值}{单位}`格式，红色标注关键变化 |
| 分公司点评 | 好的在前、差的在后，点名+原因一句话 |
| 趋势判断 | 用"向好/承压/减缓/提升/下降"等词 |
| 备注 | 8pt小字，注明统计口径、数据来源、时间范围 |

### 5.2 风险管控报告体

| 要素 | 写法 |
|---|---|
| 语气 | 客观、具体、可追溯 |
| 段落结构 | 案例→现象→方案→标准 |
| 数据呈现 | 金额、时间、数量精确到具体值 |
| 责任归属 | 明确到部门/营业部/岗位 |
| 整改时限 | 给出具体日期或周期 |

### 5.3 方案宣贯/通知体

| 要素 | 写法 |
|---|---|
| 语气 | 明确、可执行、有条理 |
| 核心结构 | 为什么→是什么→怎么做→谁做→何时完成 |
| 变化点 | 必须有新旧对比，标明差异 |
| 表格使用 | 高频，配合少量文字说明 |
| 注意事项 | 用"特别注意"、"注"、"提醒"等标识 |

### 5.4 产品培训/介绍体

| 要素 | 写法 |
|---|---|
| 语气 | 专业但不生硬，面向销售/交付人员 |
| 句式 | 中英双语标题、短句+要点列表 |
| 信息密度 | 高，每页8-15个信息点 |
| 痛点先行 | 先讲客户痛点，再讲产品方案 |
| 案例佐证 | 用具体案例和数据支撑产品价值 |

## 七、常用词组与搭配

### 7.1 趋势判断词

| 正向 | 中性 | 负向 |
|---|---|---|
| 趋势向好 | 相对平稳 | 趋势承压 |
| 环比改善 | 基本持平 | 持续下降 |
| 有所提升 | 略有波动 | 仍需关注 |
| 增长/提升 +数值 | 下降趋势减缓 | 完成不足 |
| 完成靠前/较好 | | 完成靠后 |
| 领跑 | | 低于{阈值} |
| 表现突出 | | 有压力 |

### 7.2 连接过渡词

- `从{维度}看：` — 引入分析角度（最高频）
- `其中` — 引出具体子项
- `进一步看` — 引出更深层分析
- `尤其是` — 突出重点
- `值得关注的是` — 引出风险/异常点
- `下一步` — 引出举措

### 7.3 量化表达规范

| 类型 | 格式 | 示例 |
|---|---|---|
| 百分比 | `{数值}%` 或 `{数值}PP`（百分点） | `104.5%` `+0.7PP` |
| 金额（万） | `{数值}万元` 或 `{数值}亿` | `137.8亿` `907万元` |
| 户数/规模 | `{数值}万户` `{数值}万条` | `725.1万` `17.2万条` |
| 比值变化 | `占比{数值}%，环比{变化}PP` | `占比33.5%，环比下降1.7PP` |
| 日均 | `日均{数值}{单位}` | `日均4000户` |

## 八、严禁的写作方式

1. **禁止空洞形容词**：不用"总体上"、"基本上"、"一定程度的"
2. **禁止模糊判断**：不用"比较好"、"不太理想"——必须有数据支撑
3. **禁止被动语态**：不用"被完成"、"被实现"
4. **禁止长句**：每句不超过50字，复杂内容拆成多个短句
5. **禁止无点名点评**：好的/差的不点名，等于没说
6. **禁止情绪化表达**：不用"令人震惊"、"严重"，只用数据说话
7. **禁止knowcard用内部话术**：knowcard产品培训不用"分公司"、"营业部"等内部词汇

## 九、高管座谈会发言体（v7.0 新增）

> 从安徽公司2026年总经理座谈会三份发言材料（市场部77页/王磊53页/李新颖55页）深度提取。
> 当场景为座谈会/半年会/经营复盘时激活本章节，与 `executive-style-guide.md` 配合使用。

### 9.1 总体特征

- **结论先行，数据支撑**：每页先给核心判断（"p 截至6月…"），再展开图表和数据表格
- **全省视角到分公司穿透**：从全省总量→地市排名→县公司分组→区域中心，层层穿透
- **剪刀差思维**：用"剪刀差"概念描述好差公司之间的差距，并量化PP值
- **双轮驱动框架**：基础业务+产数业务双轮并重，两盘都看
- **存增一体理念**：存量保有+增量发展一体化，反对"一加一减"
- **点名穿透**：好的差的直接点名到分公司甚至县公司/营业部
- **预判思维**：不只说当前，还要预判"预计下半年…""2027年…"
- **政治高度**：融入学习教育、正确政绩观等政治语境（王磊材料典型）

### 9.2 段落结构模板

#### 模板A：全省总量定调 → 分维度展开 → 分公司点评 → 预判

```
p 截至{时间}，{全省总体指标}{数值}，{同比/环比变化}，{总体趋势判断}
Ø {判断1，含数据+运营商对比}
Ø {判断2，含数据+运营商对比}
{图表区：趋势图+排名图}
p {分公司A}、{分公司B}份额提升{数值}以上
p {分公司C}、{分公司D}份额下降
```

**实例**（市场部P3）：
> p 截至6月，收入份额36.84%，本年提升0.53PP
> Ø 安徽LT：坚持融合高套发展，支撑收入份额增长
> Ø 安徽YD：强化项目抢夺，保持收入份额相对稳定
> p 蚌埠、六安、淮南、合肥、池州、安庆、宿州份额较上年底提升0.5PP以上
> p 铜陵、亳州、宣城份额提升幅度较去年同期收窄明显
> p 淮北、芜湖、阜阳、滁州份额下降

#### 模板B：分公司画像句式（2×2画像页专用）

```
p 1-{时间}，{分公司}净计费收入增幅{数值}（全省第{N}），同比{变化}PP
• 关注重点产品：{产品名}贡献相对不足（对增幅拉动{数值}PP，第{排名}）
• 关注细分市场：{市场名}{同比/环比}{变化}（{数值}，第{排名}）
```

**实例**（市场部P9）：
> p 1-6月，芜湖净计费收入增幅5.1%（全省第1），同比提升2.8PP（去年同期2.3%）
> • 关注重点产品：互联网专线贡献相对不足（对增幅拉动0.1PP）
> • 关注细分市场：商客市场同比负增长（-1.8%）

#### 模板C：三组分组结论句式（县公司/区域中心页专用）

```
Ø {分公司A}、{分公司B}增幅超{阈值}，{分公司C}、{分公司D}负增长，剪刀差{数值}PP
全省{N}个县公司正增长，其中{分公司}（{县公司列表}）所辖县公司均实现正增长
{M}个县公司负增长，{分公司}（{数量}/{总数}）尤要关注
```

**实例**（市场部P6）：
> Ø 寿县、凤台、怀远增幅超8%，涡阳、利辛、阜南等17个县公司负增长，剪刀差近35PP

### 9.5 标题命名规范

座谈会材料标题有特定范式：

#### 封面标题

```
两行结构（最常见）：
{七字方针句}、{七字方针句}
坚决完成全年各项经营目标

实例：
坚持双轮驱动、存增一体           ← 第一行：七字×2，顿号分隔
坚决完成全年各项经营目标         ← 第二行：表态句

建强销售组织体系 加快存增一体发展
坚决完成全年经营目标任务
```

#### 章节标题

```
简洁名词结构：
上半年市场复盘     ← 上半部分
下半年重点工作     ← 下半部分

或带编号：
01 上半年工作复盘
02 下半年工作安排
```

#### 页面标题

```
模块名 + 序号：
总体收入（1/5）
净计费收入（2/4）
分公司画像（1/4）
重点业务（1/2）
重点市场（3/4）
重点区域（2/3）

分维度名：
分公司收入增幅
县公司收入增幅
区域中心收入增幅
分公司基础和产数收入完成分布
```

#### 举措标题

```
编号+动宾结构：
举措1  该开的开：全面完成全年规划建设目标
举措2  该关的关：门店分类运营，推进低销门店"关停并转"
举措1  抓实精准施策"四个一"
举措2  省市县区联动标杆引领
举措1  压实终端运营责任
举措2  匹配增存一体政策
```

### 9.6 座谈会页脚标注规范

```
注：数据源自"数说123之安徽"，10万及以上项目
注：收入均为2026年划小预算归集，门店按6月产能有销口径

说明：队伍配置统计城市、农村、商圈、旗舰店人数，团队能力为一线认证通过率
```

- 字号8pt，灰色 `#888888`
- 位置：页面底部，y≥7.15"
- 每个独立图表如有不同口径，需分别标注

### 9.7 与经营分析会通报体（§一）的差异

| 维度 | 经营分析会通报体（§一） | 座谈会发言体（§九） |
|---|---|---|
| 受众 | 省公司条线内部 | 总经理/高管团队 |
| 视角 | 月度运营视角，"做了什么" | 半年/全年复盘视角，"什么趋势+怎么办" |
| 深度 | 全省+分公司两层 | 全省→分公司→县公司→区域中心四层穿透 |
| 预判 | 一般不做预判 | 必须预判"下半年/明年"趋势 |
| 举措 | 简短"下一步工作要求" | 详细分举措+优秀实践+时限目标 |
| 政治 | 无 | 穿插学习教育、正确政绩观 |
| 图表配合 | 以表格为主 | 以柱图/折线图/画像卡片为主 |
| 核心概念 | 保有率、离网率、完成率 | 剪刀差、双轮驱动、存增一体、时序 |
