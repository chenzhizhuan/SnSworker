# Scenario Presets

在填写 Slide Contract 之前，先选一个场景预设。预设是护栏而非路由——选最接近的，应用用户覆盖项，其余保持默认。

## `telecom-report`（默认预设 · 电信风格）

- **用途**：中国电信业务报告、运营分析、宣贯材料、党建学习、标准化运营PPT
- **推荐主题**：`telecom-red`（强制，不可更换）
- **推荐长度**：8-16 页
- **默认序列**：`T1 -> T2 -> T13(核心指标) -> T6(对比分析) -> T9/T10(数据详情) -> T7(措施三卡片) -> T11(工作流程) -> T15(总结部署) -> T16`
- **必须包含**：核心KPI指标页（T13）、对比/诊断页（T6）、工作部署/流程页（T11/T7）、总结部署（T15）
- **标题风格**：默认主张式标题（如"宽带渗透率环比提升3.2个百分点"）
- **章节导航**：10+ 页时默认开启
- **特殊要求**：
  - 使用 `assets/telecom-boilerplate.js` 而非 `assets/boilerplate.js`
  - 顶部深红通栏 + 底部红色横幅
  - 数字目标红色加粗，关键数据黄色高亮
  - 卡片浅粉填充 + 浅红描边
  - 安全区域 y=0.55~7.05"
  - 文字风格遵循 `writing-style.md` 中的电信通报体/风险管控体/方案宣贯体
  - 内容模式遵循 `content-patterns.md` 中的15种模式

## `academic-oral`

- **用途**：学术会议口头报告、研讨会报告
- **推荐主题**：`academic-red`；AI/ML 类会议可用 `tech-cyan`
- **推荐长度**：10-14 页
- **默认序列**：`T1 -> T2 -> T4 -> T6 -> T11 -> T5/T9 -> T9/T13 -> T15 -> T16`
- **必须包含**：方法/方案页（T11 或受控变体）、主要结果证明页（T5/T9/T13）、贡献/总结页（T15）
- **章节导航**：10+ 页时默认开启

## `academic-defense`

- **用途**：毕业论文答辩
- **推荐主题**：`academic-red`
- **推荐长度**：18-28 页
- **默认序列**：`T1 -> T2 -> T3(引言) -> T4/T6 -> T3(相关工作) -> T6/T7 -> T3(方法) -> T11 -> T5/T6 -> T3(实验) -> T10/T9/T13 -> T3(结论) -> T15 -> T16`
- **章节导航**：是

## `business-report`

- **用途**：内部汇报、经营分析、董事会材料、咨询报告
- **推荐主题**：`business-navy`
- **推荐长度**：8-14 页
- **默认序列**：`T1 -> T2 -> T4 -> T6 -> T9/T13 -> T11/T12 -> T7/T8 -> T15 -> T16`
- **必须包含**：问题/背景（T4/T6）、证据/结果页（T9/T13）、建议/下一步（T11/T12/T15）
- **标题风格**：默认使用主张式标题（claim-style）
- **章节导航**：12+ 页或正式定期汇报时开启

## `training-courseware`

- **用途**：培训课件、课程、工作坊材料
- **推荐主题**：`warm-amber`
- **推荐长度**：12-24 页
- **默认序列**：`T1 -> T2 -> T4 -> T7 -> T11 -> T8 -> T14 -> T15`，按模块重复，以 T16 结束
- **章节导航**：多模块时开启

## `quick-routine`

- **用途**：普通快速 PPT、简短汇报
- **推荐主题**：`business-navy`
- **推荐长度**：6-10 页
- **默认序列**：`T1 -> [T2可选] -> T4/T6 -> T7/T9/T13 -> T15 -> T16`
- **章节导航**：默认关闭

## `executive-symposium`（v7.0 新增 · 高管座谈会预设）

- **用途**：总经理座谈会、半年会发言材料、经营复盘会、高管述职发言材料
- **推荐主题**：`executive-blue`（强制，不可更换）
- **推荐长度**：15-25 页
- **默认序列**：`T17(封面) -> T18(目录) -> T19(结论先行数据页) -> T20(分公司画像2×2网格) -> T21(三组纵向分栏) -> T22(多面板仪表盘) -> T23(四象限矩阵) -> T24(工作部署页)`
- **典型deck结构**：
  ```
  P1  封面（T17，风格A白底渐变飘带 / 风格B红底城市剪影）
  P2  目录（T18，大数字+章节标题）
  P3  章节过渡1（01 上半年复盘）
  P4  总体收入概览（T22 仪表盘布局）
  P5  收入份额分析（T19 结论先行+正负双色柱图）
  P6  预算完成分析（T19 左右双栏变体）
  P7  分公司收入增幅（T19 正负双色柱图+分组虚线框）
  P8-09  分公司画像（T20 2×2网格×2页）
  P10 县公司分析（T21 三组纵向分栏）
  P11 重点业务分析（T22 多面板仪表盘）
  P12 重点市场分析（T23 四象限矩阵）
  P13 章节过渡2（02 下半年重点工作）
  P14-16 工作部署（T24 举措列表+优秀实践+问题区）
  P17 优秀实践案例
  P18 总结表态（T17末页变体）
  ```
- **必须包含**：结论先行数据页（T19）、分公司画像页（T20）、工作部署页（T24）
- **标题风格**：结论先行式（每页顶部蓝色加粗结论条，底部蓝/红判断条）
- **章节导航**：模块进度标签三段式（左侧蓝色模块标签+中间页面标题+右侧品牌Logo）
- **特殊要求**：
  - 使用 `executive-blue` 主题和 `executive-style-guide.md` 视觉规范
  - 使用 `addExecutiveNav`/`addExecutiveFooter`/`addExecutiveTitle` 替代电信红色导航/页脚/标题
  - 蓝色主导配色：蓝色=正常/正面，红色=异常/负面/核心强调，绿色=达标
  - 数字目标正增长绿色加粗、负增长红色加粗（非统一红色）
  - 卡片白色填充+浅蓝灰描边（非粉色填充）
  - 四层穿透：全省→地市→县公司→区域中心
  - 剪刀差量化：分公司分析必须量化好差PP差距
  - 文字风格遵循 `writing-style.md` §九 座谈会发言体
  - 内容模式遵循 `content-patterns.md` 模式16-19

## 预设规则

- 用户指定页数则遵守
- 预设与用户主题冲突时，用户主题优先
- 场景不明确时用 `telecom-report`（电信PPT大师默认）或 `quick-routine`（非电信场景）
- 不自行发明新预设

## 场景化设计预设（v6.0 新增 · Layer 4）

v6.0 新增5种场景化设计预设，与 `creative-design.md` 中的设计方向关联。
当用户需求匹配以下场景时，先推荐设计方向让用户选择，再按选定方向调整预设序列。

| 场景预设 | 适用场景 | 设计方向 | 对应 creative-design.md 章节 |
|----------|---------|---------|---------------------------|
| `business-analysis` | 经营分析会 | 仪表盘式/对比发现式/叙事线式 | §3.1 |
| `work-deployment` | 工作布置会 | 时间线式/矩阵分解式/军令状式 | §3.2 |
| `special-report` | 专项汇报 | 漏斗式/金字塔式/对话式 | §3.3 |
| `performance-review` | 述职报告 | 故事线式/数据说话式/双面式 | §3.4 |
| `benchmarking` | 对标分析 | 雷达图式/榜单式/画像式 | §3.5 |

### 使用方式

1. 识别场景后推荐2-3个设计方向（见 creative-design.md 推荐流程）
2. 用户选择方向后，按对应方向调整默认序列和模板组合
3. 如用户已提供模板，则设计方向在模板锚定约束内推荐

### `business-analysis`（经营分析会）

- **推荐主题**：`telecom-red`
- **推荐长度**：8-14页
- **方向A 仪表盘式**：T1→T13(KPIx3)→T9(趋势)→T7(关键发现)→T10(详情)→T15→T16
- **方向B 对比发现式**：T1→T6(同比)→T9(差距)→T13(变化)→T10(明细)→T7(行动)→T15→T16
- **方向C 叙事线式**：T1→T4(发现)→T6(对比)→T11(因果)→T7(策略)→T9(预期)→T15→T16

### `work-deployment`（工作布置会）

- **推荐主题**：`telecom-red`
- **推荐长度**：8-12页
- **方向A 时间线式**：T1→T13(目标)→T11(时间轴)→T7(阶段卡)→T10(分解)→T15→T16
- **方向B 矩阵分解式**：T1→T8(矩阵)→T10(任务表)→T7(责任卡)→T11(流程)→T15→T16
- **方向C 军令状式**：T1→T13(军令)→T5(分解图)→T10(承诺表)→T10(奖惩)→T15→T16

### `special-report`（专项汇报）

- **推荐主题**：`telecom-red` 或 `business-navy`
- **推荐长度**：8-14页
- **方向A 漏斗式**：T1→T4(现状)→T5(问题聚焦)→T11(根因链)→T7(对策)→T15→T16
- **方向B 金字塔式**：T1→T4(结论)→T9(论据)→T10(数据)→T7(支撑)→T15→T16
- **方向C 对话式**：T1→T6(Q&A)→T9(证据)→T13(数据)→T6(追问)→T15→T16

### `performance-review`（述职报告）

- **推荐主题**：`telecom-red` 或 `warm-amber`
- **推荐长度**：10-16页
- **方向A 故事线式**：T1→T4(开头)→T13(业绩)→T11(历程)→T6(反思)→T7(计划)→T15→T16
- **方向B 数据说话式**：T1→T13(KPI)→T9(趋势)→T7(亮点)→T6(差距)→T7(计划)→T15→T16
- **方向C 双面式**：T1→T7(成绩·暖)→T7(问题·冷)→T6(对比)→T11(改进)→T15→T16

### `benchmarking`（对标分析）

- **推荐主题**：`telecom-red` 或 `business-navy`
- **推荐长度**：8-12页
- **方向A 雷达图式**：T1→T9(雷达)→T6(维度)→T7(发现)→T11(路径)→T15→T16
- **方向B 榜单式**：T1→T10(排名)→T13(Top3)→T6(差距)→T11(追赶)→T15→T16
- **方向C 画像式**：T1→T8(画像)→T6(对比)→T10(差异)→T7(启示)→T15→T16
