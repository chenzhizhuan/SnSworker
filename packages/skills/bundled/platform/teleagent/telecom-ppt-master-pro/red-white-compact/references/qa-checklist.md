# 交付前质量检查

Complete every section before delivery.

## 1. Facts and language

- [ ] Every project name matches the source.
- [ ] Every date, count, duration, ratio, honor, role, and result is verified.
- [ ] Units and before/after comparisons are consistent.
- [ ] No reference-deck sample fact leaked into the new deck.
- [ ] No invented quote, user reaction, certificate, screenshot, or outcome.
- [ ] Titles identify the project or module without reading the body.
- [ ] Every title stays on one line.
- [ ] Visible copy is natural Chinese and free of prompt or production language.
- [ ] Speaker notes match the source and visible facts.

## 2. Narrative

- [ ] The deck has a clear audience and purpose.
- [ ] Every slide has one primary claim.
- [ ] The content sequence answers the customer’s actual questions.
- [ ] No fixed “background–solution–result” pattern was imposed without need.
- [ ] Reference slide content and order were not treated as mandatory.
- [ ] Repeated claims and redundant summary pages are removed.
- [ ] No background, safety, team, training, outlook, or other section was added unless required by the task.
- [ ] If a closing slide is used, it resolves the opening and connects to the customer’s requested outcome.

## 3. Visual and brand

- [ ] Authentic China Telecom logo appears consistently at upper left on content slides.
- [ ] Red title rail, gold accent, page number, margins, and typography are consistent.
- [ ] White, red, blue, gold, and warm-gray palette remains restrained.
- [ ] No stars, wheat, city silhouette, military silhouette, cartoon person, or decorative background remains unless explicitly requested.
- [ ] Cover and closing remain minimal when those slide types are used.
- [ ] Body text is readable and no page looks empty because text was shrunk.
- [ ] No low-value decorative chart or UI-like card grid was added.

## 4. Images and evidence

- [ ] Every image supports the slide claim.
- [ ] Real screenshots and photos are preferred.
- [ ] Image identity, crop, caption, and source are correct.
- [ ] Generated imagery is not presented as evidence.
- [ ] Missing media uses an intentional editable image frame only when requested.
- [ ] No fake UI, fake logo, fake certificate, or fake official scene exists.
- [ ] Personal page uses approximately one main image.
- [ ] Project and security pages use multiple images only when they improve the evidence chain.

## 5. Technical QA

- [ ] The final file is a distinct editable PPTX.
- [ ] Every slide is rendered and inspected individually at full size.
- [ ] A montage is used only for deck-level consistency review.
- [ ] No text clipping, title wrapping, broken glyph, overlap, or off-canvas object exists.
- [ ] No unintended empty structural placeholder exists.
- [ ] Page numbers, footers, and speaker notes are present where intended.
- [ ] Media is embedded and not linked to temporary paths.
- [ ] Overflow detection passes.
- [ ] PPTX archive/file-integrity check passes.
- [ ] Only the final confirmed artifact is delivered.
