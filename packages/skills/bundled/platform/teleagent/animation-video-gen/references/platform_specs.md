# 平台视频规格（短剧动画发布参考）

本技能默认输出 **1080P MP4（H.264+AAC, yuv420p）**，通过剧本 JSON 的 `aspect_ratio` 控制
`9:16`（竖屏短剧）/ `4:3` / `16:9`（横屏解说）。下表为各平台推荐规格与运营要点。

## 抖音（Douyin）

| 属性 | 值 |
|------|-----|
| 宽高比 | 9:16（主推），16:9 |
| 分辨率 | 1080×1920（推荐） |
| 最大时长 | 15 分钟 |
| 最大文件 | 4 GB |
| 视频编码 | H.264 / H.265 |
| 音频编码 | AAC |
| 码率 | 8 Mbps（1080p） |
| 帧率 | 24 / 25 / 30 fps |
| 字幕 | 建议烧录（ASS）或平台自动 |

**运营要点：**
- 前 3 秒必须钩住用户（动作/对白/冲突）
- 短剧单集 60–180 秒最佳
- 竖屏 9:16 独占
- 结尾留悬念（下集预告）
- korean_manga 画风参考"一口气看完"长视频：底部粗体字幕 + 顶部"全文X分钟"提示

## 快手（Kuaishou）

| 属性 | 值 |
|------|-----|
| 宽高比 | 9:16（主推），1:1，16:9 |
| 分辨率 | 1080×1920 |
| 最大时长 | 15 分钟 |
| 视频编码 | H.264 |
| 码率 | 6–8 Mbps |

- 字幕提升完播

| 最大文件 | 无硬性限制（建议 <8 GB） |

**运营要点：**

- 弹幕互动：顶部预留视觉空间，字幕别压顶
