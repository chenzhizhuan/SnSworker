# 短剧剧本结构与提示词工程指南

## 输入方式总览

| 输入类型 | 示例 | 解析工具 |
|---------|------|---------|
| 简短提示词 | "霸道总裁爱上灰姑娘" | `script_generator.py --prompt` |
| 关键词组合 | 题材+角色+冲突+结局 | `script_generator.py --prompt` |
| 粗略大纲 | JSON大纲格式 | `script_generator.py --outline` |
| 对话格式脚本 | "林墨：我不甘心！" | `script_parser.py --format dialogue` |
| Markdown脚本 | # 场景 + **角色**: 对白 | `script_parser.py --format markdown` |
| 小说/叙事文本 | 含引号对话的纯文本 | `script_parser.py --format novel` |
| SRT字幕 | 字幕时间轴格式 | `script_parser.py --format srt` |
| 分镜脚本 | 镜号|景别|内容|对白 | `script_parser.py --format storyboard` |
| 自动检测 | 任意格式 | `script_parser.py --format auto` |

## 提示词编写指南

### 基础提示词

告诉技能你想要什么样的短剧：

```
都市爱情短剧：一个普通的咖啡店女孩意外成为集团继承人
```

### 进阶提示词（推荐）

提供更多细节，让生成更精准：

```
类型：逆袭爽文
主角：陈默，28岁，被家族赶出的弃子，隐藏身份是神秘投资人
对手：陈家大少爷陈昊，嚣张跋扈
核心冲突：陈默被退婚后重返城市，陈家发现他的真实身份
开篇钩子：婚礼现场，新娘突然宣布退婚
情感基调：先抑后扬，打脸爽感
集数：5集短剧，每集约2分钟
```

### 大纲模式

提供更精确的场景序列：

```json
{
  "title": "龙归",
  "genre": "逆袭爽文",
  "episode": 1,
  "outline": [
    {"scene": "开场", "desc": "豪华婚礼现场，新娘当众退婚"},
    {"scene": "回忆", "desc": "三年前陈默被赶出陈家的雨夜"},
    {"scene": "转折", "desc": "陈默接到神秘电话，身份即将曝光"},
    {"scene": "高潮", "desc": "陈家晚宴，所有人震惊于陈默的真实身份"},
    {"scene": "悬念", "desc": "更大的危机浮出水面"}
  ]
}
```

## 单集节奏模板

### 黄金3秒法则

| 时间段 | 结构 | 内容 | 占比 |
|--------|------|------|------|
| 0-3秒 | 钩子 | 最强悬念/冲突/画面 | 引入 |
| 3-20秒 | 铺垫 | 人物关系+场景建立 | 引入 |
| 20-45秒 | 冲突 | 核心矛盾浮现+激烈化 | 发展 |
| 45-75秒 | 高潮 | 反转/打脸/真相揭露 | 爆点 |
| 75-90秒 | 悬念 | 留钩子给下集 | 收尾 |

### 常用钩子模板

| 钩子类型 | 示例画面 | 示例对白 |
|---------|---------|---------|
| 震惊反转 | 主角落魄画面闪切身份揭露 | "你以为我是谁？" |
| 情感冲击 | 哭泣/愤怒/决绝表情特写 | "我再也不相信你了。" |
| 悬念设问 | 神秘人/未揭示的真相 | "你知道三年前发生了什么吗？" |
| 对抗爆发 | 正面对峙/打斗/摔杯 | "今天，你欠我的都要还！" |
| 时间紧迫 | 倒计时/追车/奔走 | "你只有24小时。" |

### 情绪-转场对照表

| 前场景→后场景 | 推荐转场 | 视觉效果 |
|-------------|---------|---------|
| 平静→冲突 | fade_black | 黑场过渡，营造紧张感 |
| 冲突→升级 | slide_left | 推进感 |
| 升级→高潮 | flash_white | 闪白，冲击力 |
| 高潮→悬念 | fade_black | 渐暗，回味 |
| 回忆→现实 | dissolve | 溶解，梦幻感 |
| 现实→回忆 | flash_white | 闪白打断 |

## 6大短剧类型速查

| 类型 | 核心情绪 | 推荐画风 | 典型时长 | BGM情绪 |
|------|---------|---------|---------|---------|
| 都市爱情 | 甜蜜/虐心 | anime | 1-3分钟/集 | romantic |
| 古装宫斗 | 紧张/权谋 | qcomic | 2-4分钟/集 | mysterious |
| 悬疑推理 | 惊悚/烧脑 | realistic | 2-3分钟/集 | tense |
| 校园青春 | 青涩/热血 | cute | 1-2分钟/集 | happy |

| 玄幻修仙 | 壮阔/热血 | anime | 2-3分钟/集 | mysterious |

## 对白编写规则

1. **每句对白≤20字**：短剧节奏快，长句观众跟不上
2. **每场景对白≤4句**：场景短促有力
3. **避免解释性对白**：用画面和旁白交代背景
4. **情感标记**：每句对白标注emotion（angry/sad/cheerful/serious/romantic/calm）
5. **显示模式**：激烈对白用subtitle，轻松对话用bubble

## 提示词生成完整流水线

```
用户提示词 "霸道总裁爱上灰姑娘的都市短剧"
    ↓
script_generator.py → 剧本骨架JSON
    ↓
LLM 运行时填充：对白内容 + 画面描述 + 旁白
    ↓
short_drama_renderer.py → 图片提示词
    ↓
ImageGen → 场景关键帧图片
    ↓
Manim → 动画层（对白/气泡/旁白/转场）
    ↓
tts_engine.py → 多角色配音
    ↓
FFmpeg → 最终视频 (1080x1920 MP4)
```

也可以跳过自动生成，直接提供完整脚本让 `script_parser.py` 解析。
