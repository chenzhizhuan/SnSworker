# 智能写作助手（essay-writer）

## 概述

根据老师给出的题目与要求，撰写符合学术/作业规范的文章或论文，默认交付排版好的 Word 文档；当用户要求查资料时，先联网检索并附规范参考文献。

## 工作流程

收到写作请求后，按以下顺序执行：

### 1. 理清题目与要求
- 提取：体裁（文章/论文/演讲稿/报告/读后感等）、主题、字数、格式、截止时间、特殊要求（如"结合某本书""用案例论证"）。
- 若题目或要求缺失关键信息（如完全没说要什么体裁、有无字数要求），先用一个简短问题向用户确认最关键的 1–2 点，避免反复追问。
- 记录用户身份偏好：大学生，课程作业场景，称呼"小陈"，语气专业严谨（来自长期记忆）。

### 2. 确定体裁与结构
- 体裁识别与默认结构见 [references/writing-guide.md](references/writing-guide.md) 第一节。用户已指定体裁时以其为准。
- 通用题目默认采用"通用课程文章/小论文"骨架（引言—分论点—结论—参考文献）。

### 3. 研究资料（按需）
- **默认不强制联网**；当题目需要事实/数据/理论支撑，或用户明确要求"查资料/找文献"时，使用 `online_search` 检索。
- 检索与引用规范、交叉验证要求见 writing-guide.md 第二节、第三节。严禁编造文献或数据。
- 检索到的关键来源需转化为文末"参考文献"（GB/T 7714 简化格式）。

### 4. 撰写正文
- 紧扣题目，结构完整、层级清晰（标题不超过三级）。
- 每个分论点须有论据/数据/案例支撑，避免空泛表态；引用事实用上标 `[1]` 标注。
- 语言通顺、原创表达，无错别字；演讲稿可口语化并标注停顿/时长。
- 交付前逐项核对 writing-guide.md 第四节"质量自检清单"。

### 5. 生成并交付 Word 文档
- 将文章组织为结构化 JSON（schema 见下），调用 `scripts/build_docx.py` 生成 `.docx`。
- 生成命令（在任意工作目录执行，输出路径可指定）：
  ```powershell
  python "<skill_dir>/scripts/build_docx.py" --input article.json --output "<目标路径>/文章标题.docx"
  ```
  也可用 `--json` 直接传 JSON 字符串，或从 stdin 读取。
- 文档样式：标题用黑体加粗（一/二/三级），正文宋体小四，元信息居中，参考文献单列。
- 如需先给用户预览再成文，可先在对话中以 Markdown 展示大纲/正文，确认后再生成本地 docx。

#### 结构化 JSON Schema（传给 build_docx.py）
```json
{
  "title": "文章标题",
  "meta": { "author": "小陈", "course": "课程名(可选)", "teacher": "老师(可选)", "date": "YYYY-MM-DD(可选)" },
  "abstract": "摘要(可选)",
  "keywords": ["关键词1", "关键词2(可选)"],
  "sections": [
    { "type": "h1", "text": "一级标题" },
    { "type": "h2", "text": "二级标题" },
    { "type": "p", "text": "正文段落" },
    { "type": "bullet", "items": ["要点一", "要点二"] },
    { "type": "numbered", "items": ["第一点", "第二点"] },
    { "type": "quote", "text": "引用内容(可选)" }
  ],
  "references": ["[1] 作者. 题名[J]. 刊名, 年, 卷(期): 页."]
}
```
> `<skill_dir>` 指本技能目录：`C:\Users\cyc\.config\TeleAgent\skills\essay-writer`。
> 注意：Windows 上 `Out-File` 会写入 UTF-8 BOM，脚本已兼容 `utf-8-sig`；建议 JSON 文件以 UTF-8 无 BOM 保存。

## 资源

- `references/writing-guide.md`：体裁结构模板、联网研究流程、引用规范（GB/T 7714 简化）、质量自检清单。写作前/中按需读取。
- `scripts/build_docx.py`：将结构化 JSON 渲染为规范 Word 文档（支持标题层级、列表、引用、参考文献）。

## 注意事项
- 不代写考试/违禁代考内容；属于正常课程作业、练习、汇报场景时协助撰写。
- 所有内容须原创或规范引用，标注来源；无法核实的事实注明"待核实"或删除。
- 默认输出 `.docx`；若用户要求 Markdown 或其它格式，按用户要求交付。
