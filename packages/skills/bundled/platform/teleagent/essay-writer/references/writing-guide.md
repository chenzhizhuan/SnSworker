## 一、体裁识别与默认结构

当用户只给题目与要求、未指定体裁时，按"通用作业文章"默认采用"议论文/说明文"骨架；
若题目含明显体裁词（演讲稿/报告/论文/读后感等），切换对应结构。

### 1. 通用课程文章 / 小论文（默认）
- 标题（忠于题目，可适度凝练）
- 摘要 / 引言（150–300 字：背景、问题、本文观点）
- 正文（3–5 个分论点，每节：论点句 → 论证/论据 → 小结）
- 结论（回扣观点、升华或提出建议）
- 参考文献（若联网检索过资料，必须列出）

### 2. 课程论文 / 结课论文（偏学术）
- 标题、摘要、关键词（3–5 个）
- 引言（研究背景、问题提出、研究意义）
- 文献综述（简要梳理已有观点）
- 主体（理论/分析/案例，逻辑递进）
- 结论与展望
- 参考文献（GB/T 7714 规范）

### 3. 读书报告 / 学习心得
- 书目/主题概述
- 核心内容梳理
- 个人感悟与收获
- 联系实际的思考 / 行动启发

### 4. 演讲稿 / 发言稿
- 称呼开场（尊敬的老师/各位同学）
- 开场白（点题、设问或故事引入）
- 主体（2–3 个层次，口语化、有停顿提示）
- 结语（号召/致谢）
- 注明预计时长（如 5 分钟 ≈ 800–1000 字）

### 5. 实践总结 / 实训报告
- 实践背景与目的
- 过程与方法
- 成果与数据
- 问题与反思
- 收获与改进

## 二、联网研究流程（用户要求查资料时）

1. 先用 `online_search` 检索题目关键词 + 核心概念，单轮最多 2 条，必要时按时间/领域补充。
2. 优先采用权威来源：政府/高校/期刊/主流媒体/行业报告；对营销软文与未署名内容降权。
3. 记录每条信息的：来源标题、发布方、链接、年份、关键论断，避免张冠李戴。
4. 交叉验证：对同一事实至少 2 个来源佐证；争议观点如实标注"存在不同看法"。
5. 严禁编造文献、数据或引用。无法核实的内容注明"待核实"或删除。
6. 在正文用事实/数据支撑论点，并在文末"参考文献"按 GB/T 7714 列出。

## 三、引用与参考文献规范（GB/T 7714 简化版）

- 期刊：[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页.
- 报纸：[序号] 作者. 题名[N]. 报纸名, 出版日期(版次).
- 网页：[序号] 作者/机构. 题名[EB/OL]. (发布日期)[引用日期]. 链接.
- 图书：[序号] 作者. 书名[M]. 出版地: 出版社, 出版年.
- 正文引用使用上标 `[1]` 形式，与文末序号对应。
- 未实际检索资料的通用文章，可不列参考文献，但内容须为可靠常识。
