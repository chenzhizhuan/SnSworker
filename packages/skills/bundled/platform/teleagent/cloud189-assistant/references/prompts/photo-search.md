## 智能搜图提示词优化

适用场景：将用户的自然语言搜索需求转化为最佳的云盘搜图关键词。

```
你是一位专业的图片搜索优化师。用户想要在云盘中搜索照片，请将用户的自然语言描述转化为最适合图片搜索的关键词。

## 用户原始需求
{user_request}

## 任务
1. 提取核心搜索关键词（2-5个词）
2. 如果用户描述比较模糊，提供2-3组不同角度的搜索词
3. 优先用名词和场景词，避免虚词和形容词

## 输出格式（JSON）
```json
{
  "primary_keyword": "最核心的搜索词",
  "alternative_keywords": ["备选搜索词1", "备选搜索词2"],
  "search_strategy": "搜索策略说明"
}
```

## 示例
- "我要看大海的照片" → primary_keyword: "大海"
- "去年出去玩拍的照片" → primary_keyword: "旅游", alternative_keywords: ["风景", "出行"]
- "我家猫的照片" → primary_keyword: "猫"
```

## 搜索结果筛选与排序

适用场景：当搜索返回大量图片时，LLM辅助筛选和排序最符合用户意图的结果。

```
你是一位图片内容分析专家。根据用户的搜索意图，对搜索结果进行筛选和排序。

## 用户搜索意图
{user_request}

## 搜索结果元数据
{search_results}

## 筛选规则
1. 优先保留与搜索意图最相关的图片
2. 去除完全无关的图片（如截图、文档扫描件等非照片类图片）
3. 同一场景的多张照片去重，仅保留1-2张最具代表性的
4. 按相关度从高到低排序

## 输出格式（JSON）
```json
{
  "selected_indices": [0, 3, 5, 7, 12],
  "total_original": 50,
  "total_selected": 5,
  "filter_reason": "筛选说明"
}
```
```

## 图片描述生成

适用场景：为搜索结果中的图片生成简短的文字描述，辅助用户快速了解图片内容。

```
请根据图片的文件名和元信息，生成简短的中文描述（15字以内）。

## 图片信息
- 文件名：{file_name}
- 搜索关键词：{query}

## 输出
仅输出描述文字，不要输出其他内容。

示例：
- 文件名 "IMG_20240815_beach_001.jpg" → "海滩日落风景"
- 文件名 "微信图片_20250101.jpg" → "新年照片"
- 文件名 "DSC_0042.JPG" → "相机拍摄照片"
```
