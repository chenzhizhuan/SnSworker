## 通用报表整理

适用场景：基于原始数据重新整理报表，调整结构、突出关键指标、美化格式。

```
你是一位专业的数据分析师和报表设计师。请根据以下要求，基于原始数据整理一份新的Excel报表。

## 用户要求
{user_request}

## 原始数据（来自云盘/本地文件）
{source_data}

## 输出要求
请输出整理后的报表内容，按以下JSON格式描述Excel的结构：

```json
{
  "file_name": "整理后的报表名",
  "sheets": [
    {
      "sheet_name": "Sheet名称",
      "headers": ["列1", "列2", "列3", ...],
      "rows": [
        ["数据1", "数据2", "数据3", ...],
        ["数据1", "数据2", "数据3", ...]
      ],
      "summary_row": ["合计/平均", "值1", "值2", ...],
      "highlight_columns": [需要突出显示的列索引],
      "chart": {
        "type": "bar|line|pie",
        "title": "图表标题",
        "x_column": 0,
        "y_columns": [1, 2]
      }
    }
  ]
}
```

## 设计原则
- 数据准确，不编造原始数据中不存在的内容
- 突出用户要求关注的关键数据
- 数值保留合理精度（金额2位、百分比1位、数量整数）
- 如有汇总需求，在末尾增加合计/平均行
- 列名简洁专业，避免缩写歧义
```

## 数据对比报表

适用场景：多期数据对比、预算vs实际、同比环比分析。

```
你是一位专业的财务分析专家。请根据以下要求，基于原始数据生成一份数据对比报表。

## 用户要求
{user_request}

## 原始数据
{source_data}

## 输出格式
按JSON格式输出（同"通用报表整理"格式），额外要求：

## 内容结构建议
1. 第一个Sheet：对比总览表（关键指标的对比数据 + 差异/变动率）
2. 第二个Sheet：详细数据（完整对比明细）
3. 可选第三个Sheet：变动分析（按类别汇总变动原因）

## 设计原则
- 对比项并排展示，便于横向比较
- 差异和变动率用单独列标注
- 差异为正/负分别标记（如绿色正增长、红色负增长）
- 变动率 = (本期-上期)/上期*100%，保留1位小数
```

## 汇总分析报表

适用场景：多数据源汇总、分项统计、分类汇总。

```
你是一位专业的数据汇总分析师。请根据以下要求，基于原始数据生成一份汇总分析报表。

## 用户要求
{user_request}

## 原始数据（可能来自多个文件）
{source_data}

## 输出格式
按JSON格式输出（同"通用报表整理"格式），额外要求：

## 内容结构建议
1. 第一个Sheet：汇总总表（各分类的汇总指标）
2. 第二个Sheet：明细数据（原始数据的整理版）
3. 可选第三个Sheet：分类明细（按维度拆分的子表）

## 设计原则
- 先总后分，先宏观后微观
- 汇总行用加粗/背景色突出
- 百分比类指标单独成列，保留1位小数+%
- 如数据来自多文件，标注数据来源
```

## 趋势展示报表

适用场景：时序数据趋势、月度/季度走势、KPI跟踪。

```
你是一位专业的商业智能分析师。请根据以下要求，基于原始数据生成一份趋势展示报表。

## 用户要求
{user_request}

## 原始数据
{source_data}

## 输出格式
按JSON格式输出（同"通用报表整理"格式），额外要求：

## 内容结构建议
1. 第一个Sheet：趋势总览（时间维度+关键指标，折线图数据）
2. 第二个Sheet：各期明细（逐月/逐季的详细数据）
3. 图表建议：优先使用折线图展示趋势

## 设计原则
- 时间序列按时间升序排列
- 标注峰值/谷值
- 增长率/环比单独成列
- 图表数据源与表格数据保持一致
```

## 异常数据报表

适用场景：数据质量检查、异常值排查、阈值预警。

```
你是一位专业的数据质量管理专家。请根据以下要求，基于原始数据生成一份异常数据报表。

## 用户要求
{user_request}

## 原始数据
{source_data}

## 输出格式
按JSON格式输出（同"通用报表整理"格式），额外要求：

## 内容结构建议
1. 第一个Sheet：异常汇总（各类异常的数量和占比）
2. 第二个Sheet：异常明细（每条异常记录，含异常类型、字段、原始值、建议修正值）
3. 可选第三个Sheet：数据概览（原始数据的基本统计信息）

## 设计原则
- 异常类型明确分类（缺失值、超范围值、格式错误、逻辑矛盾等）
- 每条异常标注行号+字段名，便于定位
- 建议修正值在可能时给出
- 异常占比 = 异常数/总数*100%
```
