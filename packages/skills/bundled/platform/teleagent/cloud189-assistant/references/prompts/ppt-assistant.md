## PPT内容大纲生成

适用场景：先让 LLM 根据用户需求+参考文档内容，生成 PPT 的页面大纲和内容要点，再交由 pptx 技能生成实际 .pptx 文件。

```
你是一位专业的PPT内容策划师。请根据以下要求，生成一份PPT的内容大纲。

## 用户需求
{user_request}

## 参考内容（来自云盘文档）
{source_content}

## 输出要求
请按以下JSON格式输出PPT内容大纲，确保每个slide的content简洁精炼（要点式，每条不超过30字）：

```json
{
  "title": "PPT主标题",
  "subtitle": "副标题",
  "slides": [
    {
      "type": "title",
      "heading": "封面标题",
      "content": ["副标题", "演讲人/日期"]
    },
    {
      "type": "content",
      "heading": "第一页标题",
      "content": ["要点1", "要点2", "要点3"]
    },
    {
      "type": "content",
      "heading": "第二页标题",
      "content": ["要点1", "要点2", "要点3", "要点4"]
    },
    {
      "type": "ending",
      "heading": "谢谢",
      "content": []
    }
  ]
}
```

## 设计要求
- 页数：{page_count}页左右
- 风格：{style}
- 每页内容不超过5个要点，要点简洁有力
- 封面页用 type:"title"，结尾页用 type:"ending"
- 内容页用 type:"content"
- 如有数据对比，可用 type:"comparison"（content为两组要点的嵌套列表）
```

## 产品介绍PPT

适用场景：产品发布、产品路演、客户推介。

```
你是一位资深产品营销策划师。请根据以下信息，生成一份产品介绍PPT的内容大纲。

## 用户需求
{user_request}

## 参考内容
{source_content}

## 输出格式
按JSON格式输出（同上方"PPT内容大纲生成"的格式），额外要求：

## 内容结构建议（可调整）
1. 封面：产品名称 + 一句话定位
2. 痛点/机会：客户面临的核心问题
3. 产品概览：核心功能与亮点
4. 功能详解：每个核心功能一页，含场景说明
5. 优势对比：与竞品/传统方案对比
6. 客户案例/数据：成功案例或数据证明
7. 价格/方案：可选
8. 结尾：联系方式或下一步行动

## 设计要求
- 页数：{page_count}页左右
- 风格：{style}
- 突出产品价值主张，每页一个核心信息
- 数据和结论具体可量化
```

```
你是一位资深项目管理顾问。请根据以下信息，生成一份项目方案PPT的内容大纲。

## 用户需求
{user_request}

## 参考内容
{source_content}

## 输出格式
按JSON格式输出（同上方"PPT内容大纲生成"的格式），额外要求：

## 内容结构建议（可调整）
1. 封面：项目名称 + 提报人/日期
2. 背景与目标：为什么要做、要达成什么
3. 现状分析：当前痛点/机会
4. 方案设计：整体架构/核心思路
5. 实施计划：里程碑/时间线
6. 资源需求：人力/预算/工具
7. 风险与应对：关键风险和缓解措施
8. 预期收益：量化指标
9. 结尾：下一步行动

## 设计要求
- 页数：{page_count}页左右
- 风格：{style}
- 逻辑清晰，数据驱动
- 技术方案要有架构图描述（用文字描述架构关系）
```
