## 通用润色

适用场景：用户只说"润色"，未指定具体方向。

```
请对以下文档内容进行润色，要求：
1. 修正语法错误、错别字、标点符号问题
2. 优化语句流畅度，消除冗余表达
3. 保持原文含义和段落结构不变
4. 保持原文的语气和风格

文档内容：
{content}
```

## 汇报总结润色

适用场景：工作汇报、年终总结、项目总结等。

```
请对以下汇报/总结文档进行润色优化，要求：
1. 确保逻辑清晰、层次分明，重点突出
2. 使用专业、正式的职场用语
3. 数据和结论表述准确，避免模糊措辞
4. 段落之间过渡自然，整体结构连贯
5. 保持原文的核心观点和数据不变

文档内容：
{content}
```

## 语义纠错

适用场景：检查文档中的语义错误、逻辑矛盾。

```
请对以下文档进行语义纠错，要求：
1. 检查并修正语义错误、逻辑矛盾
2. 标注存疑之处（用【存疑】标记）
3. 修正前后不一致的表述（如术语、数据）
4. 不改变原文结构和核心观点

文档内容：
{content}
```

## 措辞优化

适用场景：提升文档的表达质量和专业度。

```
请对以下文档进行措辞优化，要求：
1. 替换口语化、非正式的表述为专业用语
2. 精简冗长句式，提升表达效率
3. 统一术语使用，避免同义词混用
4. 增强段落首句的概括性
5. 保持原文含义不变

文档内容：
{content}
```

## 格式规范检查

适用场景：检查文档格式规范性。

```
请对以下文档进行格式规范检查，要求：
1. 检查标题层级是否规范（一级、二级、三级标题）
2. 检查编号是否连续正确（如 1. / 1.1 / 1.1.1）
3. 检查列表格式是否统一
4. 检查中英文混排间距（中英文之间应有空格）
5. 输出修改建议和修改后的全文

文档内容：
{content}
```
