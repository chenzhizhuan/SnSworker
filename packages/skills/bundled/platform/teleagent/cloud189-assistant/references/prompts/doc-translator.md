## 通用翻译

适用场景：用户只说"翻译"，未指定具体方向。

```
请将以下文档内容翻译为{target_language}，要求：
1. 准确传达原文含义，不遗漏、不增补
2. 保持原文段落结构
3. 术语首次出现时在括号内附原文（如：机器学习 (Machine Learning)）
4. 语言自然流畅，符合{target_language}的表达习惯

原文内容：
{content}
```

## 学术论文翻译

适用场景：外文学术论文、研究报告、期刊文献。

```
请将以下学术文献翻译为{target_language}，要求：
1. 准确翻译学术术语，首次出现时在括号内附原文术语
2. 保持论文的学术严谨性和正式语气
3. 公式、符号、变量名保持原样不翻译
4. 参考文献/引用标记保持原样（如 [1], (Smith et al., 2020)）
5. 图表标题翻译，但图表编号保持原样
6. 保持原文段落结构

原文内容：
{content}
```

## 技术文档翻译

适用场景：API文档、技术手册、README、配置说明。

```
请将以下技术文档翻译为{target_language}，要求：
1. 技术术语准确翻译，首次出现附原文
2. 代码块、命令行、文件路径、配置项不翻译，保持原样
3. 保持Markdown/代码格式不变
4. 操作步骤描述清晰易懂
5. 保持原文段落和列表结构

原文内容：
{content}
```

## 逐段对照翻译

适用场景：用户需要对照原文阅读，如精读文献。

```
请将以下文档逐段翻译为{target_language}，输出格式为原文与译文交替排列：

格式要求：
【原文】第一段原文内容
【译文】第一段翻译内容

【原文】第二段原文内容
【译文】第二段翻译内容

...（依次类推）

翻译要求：
1. 准确传达原文含义
2. 术语首次出现附原文
3. 语言自然流畅

原文内容：
{content}
```

## 摘要翻译

适用场景：只翻译论文/报告的摘要部分，不需要全文翻译。

```
请从以下文档中提取摘要部分（Abstract / 摘要 / 简介），并翻译为{target_language}。

如果文档没有明确的摘要段落，请生成一段200字以内的内容概要并翻译。

翻译要求：
1. 准确传达核心观点和关键结论
2. 语言精炼、学术化
3. 术语首次出现附原文

原文内容：
{content}
```
