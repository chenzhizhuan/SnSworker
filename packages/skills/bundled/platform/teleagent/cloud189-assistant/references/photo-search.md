# 照片搜索子流程 (photo-search)

## 功能

用户输入自然语言描述，从天翼云盘全盘搜索匹配的照片。基于天翼云盘智能搜图API（searchByText），支持用关键词、场景、物体等自然语言搜索。搜索结果以缩略图形式展示，超过8张时折叠，点击查看更多展示全部。

**搜索范围**：本流程使用云盘智能搜图API，可全盘搜索照片，不受目录限制（与其他子流程仅限"我的应用/云盘智能体"目录不同）。

## 步骤

### 第一步：接收用户搜索需求

用户输入搜索要求，如"我要看大海的照片"、"找一下去年旅游的照片"。

调用 LLM 优化搜索关键词（参考 `references/prompts/photo-search.md` 中"智能搜图提示词优化"模板）：
- 提取核心搜索关键词（2-5个词）
- 模糊描述提供多组备选搜索词
- 优先用名词和场景词，避免虚词

### 第二步：调用云盘智能搜图API

```bash
python scripts/cloud189_lite.py search-images --text "<搜索关键词>" --page 1 --size 50
```

参数说明：
- `--text`：搜索关键词
- `--page`：页码（默认1）
- `--size`：每页数量（默认50，最大50）

返回 JSON 包含 `images` 数组（含 `file_id`、`file_name`、`thumbnail_url`、`preview_url`）和 `count`。

**多关键词搜索**：如果第一步生成了多组备选关键词，依次调用 search-images，合并去重结果。

### 第三步：LLM 辅助筛选（可选）

当搜索返回大量结果时，可用 LLM 辅助筛选（参考 `references/prompts/photo-search.md` 中"搜索结果筛选与排序"模板）：
- 去除非照片类图片（截图、文档扫描等）
- 同场景多张去重，仅保留代表性图片
- 按相关度排序

### 第四步：展示搜索结果

**缩略图展示规则**：

1. 搜索结果总数 ≤ 8 张：直接展示全部缩略图
2. 搜索结果总数 > 8 张：折叠展示前 8 张，底部显示"查看更多（共N张）"按钮
3. 用户点击"查看更多" → 显示全部搜索结果

**结果为空时**：
- 提示"未找到匹配的照片"
- 建议用户换一组关键词重试
- 提醒：本流程为全盘搜索，如仍搜不到，请确认照片是否已上传到天翼云盘

### 第五步：下载（可选）

用户可选择下载某张照片到本地：

```bash
python scripts/cloud189_lite.py download --file-id <file_id>
```

拿到 `download_url` 后下载到 `.temp/` 或用户指定目录。
