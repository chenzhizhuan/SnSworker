# 湘办通教程速查

## 功能概述

基于本地"湘办通使用教程合集"文件夹（85个教程文件），通过关键词索引快速定位并读取相关教程，
为用户解答湘办通平台的使用问题和故障排查，覆盖手机端与电脑端全功能模块。

## 教程根目录

所有教程文件位于工作目录下：
`湘办通使用教程合集/`

子目录结构：
- `APP版湘办通常用问题/` — 手机端常见问题（4个文件）
- `各功能模块操作手册/` — 各模块详细操作手册和培训资料（56个文件）
- `常用软件/` — 安装包和驱动下载（10个文件）
- `网页版湘办通常用问题/` — 电脑端常见问题（15个文件）

## 工作流程

### 第一步：读取索引

通过 skill_view 读取技能引用文件 `references/tutorial_index.md`（该文件是 Skill 管理的 references 引用文件，不在工作目录下），获取全部教程文件的分类索引表。

> **重要**：索引文件是 Skill 的 references 引用文件，不是工作目录下的物理文件。如果无法通过 skill_view 读取索引，可改用 glob 列出工作目录下 `湘办通使用教程合集/` 的全部文件，按文件名关键词进行匹配。

### 第二步：关键词匹配

根据用户问题提取关键词，在索引表的"关键词"列中查找最匹配的条目。匹配规则：
- 精确匹配优先：用户问题中的关键词直接命中索引关键词
- 语义匹配其次：如"登不上去"→"登录"、"打不开"→"访问/域名"、"钱报不了"→"报销"
- 可结合平台筛选：用户提到"手机/APP"→筛选"手机端"；用户提到"电脑/网页"→筛选"电脑端"
- 一个问题可能匹配多个条目，全部记录

### 第三步：读取教程文件

按匹配结果读取对应教程文件。文件读取优先级：
1. `.docx` / `.pdf` — 可直接提取文本和图文内容，优先读取
2. `.pptx` — 可提取幻灯片文本和图片描述
3. `.wps` / `.et` / `.doc` — 尝试读取，可能无法解析时仅提供文件名和路径
4. `.zip` / `.rar` — 压缩包无法读取内容，仅告知用户文件路径和用途

读取时需拼接完整路径：
`工作目录\湘办通使用教程合集\{子目录}\{文件名}`

### 文件内容提取方法（PowerShell + Python）

教程文件多为 `.pptx` / `.docx` / `.pdf` 格式，使用内置 Python 环境提取文本：

**PPTX 文件**（使用 python-pptx）：
```python
from pptx import Presentation
p = Presentation(r'完整文件路径')
for i, sl in enumerate(p.slides):
    texts = [sh.text_frame.text for sh in sl.shapes if sh.has_text_frame and sh.text_frame.text.strip()]
    if texts:
        print(f'--- Slide {i+1} ---')
        print('\n'.join(texts))
```

**DOCX 文件**（使用 python-docx）：
```python
import docx
d = docx.Document(r'完整文件路径')
for p in d.paragraphs:
    if p.text.strip():
        print(p.text)
# 如有表格
for t in d.tables:
    for row in t.rows:
        print(' | '.join(c.text.strip() for c in row.cells))
```

**PDF 文件**（使用 pdfplumber）：
```python
import pdfplumber
p = pdfplumber.open(r'完整文件路径')
for i, pg in enumerate(p.pages):
    t = pg.extract_text()
    if t:
        print(f'--- Page {i+1} ---')
        print(t)
```

> 提示：大文件可用 `Select-Object -First N` 截断输出，或按页码范围读取特定部分。

### 第四步：整理回答

基于读取到的教程内容，为用户整理出清晰的解答：
1. 简要说明问题原因或背景
2. 列出具体操作步骤（如教程中有图文描述，转化为文字说明步骤）
3. 补充注意事项或常见报错处理
4. 如果教程文件包含截图/图片但无法直接展示，说明"教程原文档中第X步配有截图，建议打开原文件查看"
5. 提供教程文件路径，方便用户自行打开查看图文

## 注意事项

- 教程文件格式多样（pdf、pptx、docx、wps、et、doc、zip、rar），部分格式可能无法完全解析
- 对于无法读取的文件，告知用户文件路径，建议用对应软件打开
- 同一问题可能有多个教程文件覆盖（如VPN操作手册在多个目录有副本），优先读取内容最完整的版本
- 回答时优先引用教程原文的步骤和说明，不要自行编造操作流程

## 截图/图片问题处理

用户经常发送湘办通界面截图（报错弹窗、费用明细、工单等）来询问问题。处理流程：

1. **识别图片**：使用 image_understanding 工具，prompt 要求逐字提取所有文字（标题、按钮、菜单、报错信息、弹窗内容、表单字段等）
2. **提取关键词**：从识别出的文字中提取问题关键词（如"连接服务器失败"→VPN、"费用已超过发票金额"→住宿明细/报销）
3. **匹配教程**：按关键词在索引中匹配教程文件
4. **读取+回答**：读取教程文件，结合截图内容给出针对性解答

## 复杂问题：多文件交叉查询

部分问题（如"无扰督查收不到督办事项"）涉及多个环节，需同时读取多份教程文件交叉验证：

- 先用关键词匹配索引中所有相关条目（如无扰督查可能匹配 U01-U04 四个文件）
- 并行读取多份文件（可同时执行多个 PowerShell 命令）
- 综合多份文件内容，按排查优先级整理回答（如：先查推送→再查角色关联→再查网络端口→再查上级下达）
