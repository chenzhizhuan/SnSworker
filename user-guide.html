快速上手：5 分钟发出第一个任务

不需要先学完所有功能。走完下面 3 步，你就完成了从「装软件」到「AI 干活」的最短路径。

第 1 步 · 下载并安装

1

从内部发布渠道下载安装包

Windows 选 x64 安装包（.exe）；macOS 选 dmg 安装包（文件名形如 智算方舟-1.0.x-arm64.dmg）：Apple 芯片（M 系列）选 arm64，Intel 芯片选 x64。安装包由运维统一打包发布。

2

Windows：双击安装，遇到拦截点「仍要运行」

首次运行可能弹出蓝色「Windows 已保护你的电脑」提示：点击 更多信息 → 仍要运行，然后跟着安装向导走完即可。

3

macOS：拖入应用程序 + 终端去隔离

双击 dmg 打开安装窗口 → 把「智算方舟」图标拖进右侧 Applications（应用程序）文件夹 → 然后在「终端」里执行下面这条指令（去除 macOS 隔离属性，否则首次打开会被拦）：输入你的 Mac 开机密码（输入时不显示，回车即可），执行后从启动台打开应用。

终端指令（一键复制）sudo xattr -rd com.apple.quarantine "/Applications/智算方舟.app"

没执行这条指令的备选办法：首次打开若提示「无法验证开发者」，在「系统设置 → 隐私与安全性」中点「仍要打开」。建议优先用终端指令——一次解除，后续更新不再弹。

4

客户端会自动更新

启动后如弹出「正在下载更新」窗口（如 v1.0.8 → v1.0.9），无需任何操作：下载完成后会自动安装并重启，你的登录状态和会话都保留。

第 3 步 · 发出你的第一个任务

FIG.01登录后的「新任务」页面：默认工作空间「小智」已就位，输入框即任务入口实机 · v1.0.9
1

点「办件事」→ 新任务

左侧窄栏点办件事进入任务域，默认就在「新任务」页。页面显示「今天想和小智 一起完成什么？」，小智就是默认工作空间（你的第一位 AI 同事），任务描述直接写在输入框：「输入你的任务，小智 会帮你完成…」。

2

说清三件事：做什么 + 有什么要求 + 最后要什么

不用学复杂的提示词。输入框下方有 文档 / 表格 / 浏览器快捷入口，点击可以把产物类型直接带上；也可以把云文档直接拖进对话作为素材。

3

模式与审批档

输入框左下两个选择器：模式保持默认「执行」（直接做出结果）；审批档建议选「请求批准」（AI 动手改东西前先展示给你确认；如果显示的是别的档位，点开旁审批入口切换）。第一次用就用「请求批准」看清 AI 每一步，熟练后再放宽。

4

允许操作 → 看结果 → 继续改

AI 规划好操作后逐条向你确认；完成后打开生成的文档查看。结果不满意不用重发任务，直接在同一对话里继续说，例如「把三个目标改得更具体」。

示例指令 · 可直接复制请创建一份名为「我的工作启动清单」的文档，包含： 1. 今天开工前要确认的三个事项； 2. 三个今天能完成的小目标； 3. 每个目标对应的一步具体行动； 4. 一份下班前自查的完成情况清单。
记住这条最短路径：工号登录 → 确认组织 → 办件事·新任务 → 写清要求 → 允许操作 → 看结果 → 继续改。先拿今天真要做的一件小事练手。

MODE · 模式怎么选

执行：默认。直接做出结果：写文档、改文件、处理资料。
规划：只读调研后产出结构化方案，你在方案卡片上点「执行」才动手。目标没想清时用它。
PMO：以项目管理者身份拆解任务、调度多个子 Agent 协作，输入框提示「描述目标，我来拆解任务并调度子 Agent...」
问一句（窄栏入口）：纯问答，只调研分析不动手。

APPROVAL · 审批档怎么选

请求批准：工作区内自动放行，出界/敏感/破坏性操作先问你。
自动通过：除风险红线外自动批，适合信任后的批量重复活。
全部允许：只拦灾难级命令。仅在明确风险可控时用。
切换方式：输入框旁审批档入口，一键升降档；PMO 群会话固定「请求批准」。

工作空间：什么时候新建一个

工作空间就是一位 AI 同事的身份卡：有自己的人设与规则、记忆、技能携带集，会随共同完成的任务不断积累对你的理解。当某类工作反复出现且口径固定（周报、招标分析、数据整理），就为它建一个专属工作空间，把要求和经验固化进去；组织级统一管理走窄栏数字助手入口（新建、改名、设定人设与技能携带集）。TA 记错了就直说「忘记这条、记住那个」，记忆面板可逐条纠正，也能导出 Markdown / JSON 备份。

任务续接：把干到一半的活交给同事

在任务对话里点「共享给同事」，选「交给同事继续」后发送：对方在协作沟通里收到任务卡片，点开即见完整来龙去脉，接手后成为他自己的任务继续推进。发送时会冻结当时的对话上下文快照——之后你这边的对话怎么继续，都不影响交出去的那份，两边互不干扰。

适合场景：任务干到一半要交接、请假兜底、多人接力同一份材料。比起截图＋发文件＋口头交代背景，对方拿到的是可直接续跑的完整现场。

GET STARTED · 三步上手，今天就开始

STEP 01

说清目标

用自然语言讲清楚：要什么、给谁看、什么格式。越具体，结果越好——这一条比任何技巧都管用。

STEP 02

选对入口

要答案 → 问一句；要成果 → 办件事；多人协作 → 做项目；同类专项工作固定用一个专属工作空间（数字助手）。

STEP 03

审核沉淀

检查产物、追问修正；数据、日期、金额、条款亲自把关；满意后存入资料空间，成为团队可复用的资产。

场景 A · 问一句：最快的提问入口

FIG.04问一句：独立的纯问答入口，提示「提个问题，我来查找和分析…」实机 · v1.0.9

窄栏「问一句」是一级菜单第一项，也是全应用最快的提问入口：查政策口径、问软件用法、让 AI 查找并分析资料，只调研分析、不动手，不会改动你的任何内容。答案要落地成文档或表格时，再切到「办件事」发任务（见下方场景 B–D）。输入框还支持语音输入：按 Ctrl+Shift+M（可在设置里改快捷键）直接开说，识别结果可先编辑再发送。

04

投标实战：一条链跑完「分析 → 编写 → 审查」

公司已内置投标链条三个配套技能，对应投标的三个环节，按顺序使用：上一步的输出就是下一步的输入。直接在任务里描述需求即可触发对应技能。

第一环

招标文件分析

读懂招标文件：提取资格条件、否决条款、评分标准，产出响应矩阵和投标文件框架。

输入：招标文件 PDF/Word
输出：清单 + 矩阵 + 框架
第二环

标书编写师

基于响应矩阵和框架逐章编写正文，交付结构完整、带目录的投标文件。

输入：矩阵 + 框架 + 素材
输出：投标文件 docx
第三环

标书合规审查

交标前最后防线：废标风险、评分点覆盖、报价一致性、产品证书一致性逐项核查。

输入：草稿 + 招标文件
输出：审查报告 / 清单

三步走：从发起任务到拿到成果

发起

你怎么交代任务

上传招标文件（拖进对话，或先传资料空间再引用）；说清项目名称、你负责的章节与时间要求；选对助手与权限——长任务可放开权限减少打断。

推进

AI 会来找你确认

确认分工（哪些你写、哪些别人提供）；确认逐章大纲（点头后才写正文）；缺料会列清单问你，不自行编造；分析报告、初稿随出随看，可追问调整。

收尾

你要做的事

按待补清单照单补材料；核对审查结果，改完可回炉复审；数据、日期、金额、条款亲自把关；成果归档资料空间，全团队复用。

人工的角色就三件事：确认、补料、把关——AI 起草分析编写，人做决策。链条全部跑完的交付物共四份、均为可直接使用的 Word：分析报告、投标文件框架、标书正文、审查报告。

场景 L · 招标文件分析（决定投不投、怎么投）

目标：拿到招标文件后，先把「废标红线」和「得分点」全部拆出来，再决定投入多少资源。

1

在「办件事」里新建任务，上传完整招标文件（PDF/Word），说「帮我做招标文件分析」。

2

AI 会逐条拆解并输出四份结构化结果：资格条件清单（我司是否满足）、否决条款清单（风险等级 + 需准备材料）、评分标准矩阵（分值 + 响应策略）、投标文件框架（章节结构）。

3

逐条确认标了「需人工确认」的项（AI 不会替你臆断），补齐材料后再进入编写环节。

示例指令上传了本项目的招标文件，请做完整的招标文件分析：重点提取否决条款和评分标准，输出响应矩阵和投标文件框架。资质和业绩相关的项，凡是文件里依据不足的都标「需人工确认」。

延伸：还没拿到招标文件、先想找商机？直接说「帮我搜索最近一周 XX 领域的招标公告」会触发政企招投标助手，汇总成网页台账。想每天自动巡检，就把这句话交给自动化（场景 G）定时执行。产出的框架和矩阵建议存到资料空间（云文档），下一环直接拖进对话接着用。

场景 M · 标书编写师（写出能拿分的正文）

目标：基于分析结果逐章编写，拿到一份结构完整、带目录、可直接排版交付的投标文件。

1

把响应矩阵、投标文件框架发给 AI（从资料空间拖进对话，或接着分析任务的对话继续），如有公司历史中标标书、方案素材一并上传——AI 会优先参考你认可的历史稿，而不是套通用模板。

2

先让 AI 出章节大纲并确认，确认后再逐章编写正文；每章写完可单独提修改意见。指定页数时 AI 会按章核对页数并补足实质内容。

3

需要把营业执照、资质证书、业绩合同等商务资料贴进对应章节时，直接上传并说明「贴到标书对应位置」，AI 会按内容类型插入框架对应章节。

4

交付物是 .docx 完整投标文件：保留框架章节编号、封面后带完整目录、黑体宋体规范排版。信息化/系统集成类项目自动启用行业专版（信创、等保等口径）。

示例指令这是招标文件分析输出的响应矩阵和投标文件框架，另附我们去年中标的同类项目标书。请先按框架出章节大纲给我确认，确认后编写第 3 章「技术方案」，目标 20 页，响应策略按矩阵里标注的来，不要出现「根据招标文件要求」这类索引式表述。
铁律：资料不足时 AI 会标「待补充素材」或「需人工确认」并列清单问你，绝不编造公司资质、案例、人员与数据——这是投标红线。交付前 AI 还会按评分矩阵自查评分点覆盖率（已覆盖 X/Y、未覆盖项列出），自查结果随正文一并进入合规审查。

场景 N · 标书合规审查（交标前必做）

目标：交标前把「会废标的问题」和「丢分的问题」全部找出来。

1

把正文草稿 + 招标文件（以及分析输出的资格清单、否决条款清单、评分矩阵）交给 AI，发起合规审查。

2

AI 逐项核查：资格与否决条款覆盖、评分点响应完整度、报价一致性（投标函/开标一览表/正文交叉核对）、产品与证书一致性（型号、证书编号、有效期、持有人）、格式与内容质量（索引式表述、重复内容检查）。

3

按审查报告逐条整改，改完必须回炉复审，确认风险清零后再定稿交付。

示例指令对这份投标文件草稿做交标前的合规审查：招标文件和资格/否决/评分三份清单都附上了。重点核查报价前后一致性和产品证书有效期，输出按「风险等级 + 位置 + 问题 + 整改建议」列清单。
团队分工建议：为三个环节各建一个专属工作空间（数字助手入口新建），把各自的人设、口径固化进去；三环产物（矩阵、框架、草稿、审查报告）存到资料空间，随时拖回对话复用。
05

问题排查：按现象找下一步

先按下面对照现象自查，多数问题 1 分钟能解决；仍未解决再找运维（附录有渠道），带上报错截图。

登录不上？
  1. 核对用户名是工号（如 SJ0851）：注意大小写和前缀（SJ / J / JY），不要输成姓名拼音或手机号。
  2. 核对密码：用管理员预设的初始密码；如果自己改过，用改后的密码。
  3. 密码多次输错可能触发锁定：等几分钟再试，或直接找管理员解锁/重置。
  4. 「忘记密码」自助找回仅对绑定了邮箱或手机号的账号可用；工号账号未绑定时，请找管理员重置。
  5. 确认装的是内部安装包：外部网站下载的版本连的是官方公共服务，工号登录不了。检查方法：登录页副标题应显示「登录您的 智算方舟 账户」。
仍未解决：截图登录页完整报错 + 你的工号 + 发生时间，联系运维。
提示「无额度」或被限流？
  1. 先确认左上角组织正确（个人 / 公司组织额度分开算）。
  2. 额度跟组织与成员规则走：超额会有明确提示；确需提高找管理员在运营管理台调整。
  3. 限流通常是短时间内请求过于密集：稍等几分钟再试，不要连续重试。
  4. 重新登录一次，让额度状态刷新。
仍未解决：截图额度提示 + 你的工号，联系运维核对。
AI 说「当前模式只读」或让我切换模式？
  1. 你可能在「问一句」（纯问答）或「规划」模式里让它改东西：这两类模式本来就只读。
  2. 按 AI 的提示，到输入框左下角的模式选择器切回「执行」再发一次。
  3. 规划模式产出的方案卡片上有「执行」按钮，点它即可自动进入执行，不必手动切。
模式能力一览见第 2 章「模式怎么选」。
提示「这个工作空间的执行设备不在当前设备」？
  1. 这是正常提示：该工作空间绑定的执行电脑不是当前这台。对话类任务不受影响，照常下发。
  2. 涉及本地文件读写的任务：回到绑定的那台电脑操作，或把所需文件上传为附件 / 存入资料空间（云文档不受设备限制）。
  3. 需要换绑执行设备：找管理员在后台调整，或在目标电脑上重新创建工作空间。
仍未解决：说明是哪台设备、哪个工作空间，联系运维。
文档或表格一直「同步中」？
  1. 「连接中」「同步中」不代表已保存到云端：先保留未同步的重要内容，别关页面。
  2. 确认网络和账号正常；跨设备查看时核对打开的是同一份资源（资料空间里搜索确认，看「所有者」和「最近更新时间」列）。
  3. 等状态变为「已同步」后，再到另一台设备核对内容一致。
仍未解决：不要反复刷新，截图同步状态，联系运维。
消息、附件或任务发送失败？
  1. 先看失败的是哪一条：核对接收对象、当前组织，以及附件是否已上传完成。
  2. 消息失败：检查连接后重试同一条，不要反复新发相同内容。
  3. 任务失败：先读错误提示——附件上传失败、模型认证失败、无额度、限流要分别处理；确认原任务状态后再决定是否重试。
仍未解决：截图失败提示 + 时间点，联系运维。
AI 说做完了，但生成的文件找不到？
  1. 回到原任务的对话查看产物卡片（文档/表格），点开确认内容和保存位置。
  2. 云文档去资料空间搜索（「全部 / 最近」里按文件名找，列表带所有者和更新时间）。
  3. 保存到本地的核对工作目录里目标文件夹和文件名。
  4. 导出后打开文件确认是最新版本；找不到就在原对话里让 AI 重新给出文件位置或再次导出。
仍未解决：把任务名和文件名发给运维协助定位。
AI 一直在等我确认，或提示没有权限？
  1. 「请求批准」档下这是正常流程：查看它准备执行的操作、目标和权限提示，判断后点允许或拒绝。
  2. 确认频率过高时，用输入框旁的审批档入口升到「自动通过」；PMO 群会话固定请求批准，属预期行为。
  3. 文档只能看不能改：请文档所有者核对你的访问权限——被分享 ≠ 有编辑权。
仍未解决：截图权限提示内容，联系运维。
弹出「正在下载更新」窗口？
  1. 这是正常的自动更新（如 v1.0.8 → v1.0.9）：下载完成后客户端会自动安装并重启，无需任何操作。
  2. 想了解更新内容：点弹窗右下角「查看版本详情」。
  3. 更新后登录状态和会话都保留，无需重新登录；若个别会话没加载出来，重启一次客户端。
更新卡住不动：截图弹窗进度，联系运维。
自动化的定时任务没跑？
  1. 到办件事侧栏「自动化」面板看任务状态：草稿/已暂停的任务不会自动执行（列表显示「已暂停，不会自动执行」）。
  2. 看「下次执行时间」列确认排期；到点没跑，点行内「立即执行」验证任务本身是否正常。
  3. 该任务所属工作空间的执行设备离线时定时任务也会挂起：保持绑定电脑的客户端在线。
仍未解决：把任务名和状态截图发给运维。
示例指令的「复制」按钮点了没反应？
  1. 先看按钮反馈：正常点击后会变成「已复制 ✓」约 1.5 秒，然后变回「复制」。
  2. 个别浏览器禁用了剪贴板权限：在地址栏左侧站点设置里允许「剪贴板」，或换 Chrome / Edge 打开。
  3. 兜底永远有效：直接选中指令文字，Ctrl+C 手动复制（所有指令都是纯文本，选了就能复制）。
复制到的内容提示：粘贴到任务输入框后可按需改写，指令只是起点不是模板。
